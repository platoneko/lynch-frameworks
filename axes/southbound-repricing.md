# _AXIS.southbound-repricing — 南向定价权情景轴

> 轴类型：`shared_scenario_axis`（**隔层轴 / 弱轴**）| 更新：2026-09-27 | 挂载票：`000338.SZ` · `600036.SH` · `6655.HK` · `1766.HK` · `1072.HK` · `600011.SH`
> 口径：**南向资金月度净流入（HKD）所标示的港股边际定价权状态**；轴只锁**倍数层**，不锁分子

共享情景轴（`AGENTS.md`「锚点语义」§共享情景轴）。**本轴与金铜梯、AI capex 轴的形态不同**：它不给挂载票任何分子，只回答一个问题——**该票的 H 股倍数应该取自身 own-year 分位的哪一档**。分子（盈利）由各票自己的业务驱动因子决定，五票之间**不共享分子**。

**本轴正在被 `AGENTS.md`「永续增长口径」削弱。** 该节规定倍数由永续增长率生成、**不取历史 PE 分位**，且明示优先于 skill A2e-2b。对已改用 Gordon 的挂载票（`6655.HK`、`1072.HK`），本轴的「取哪一档分位」机制已经失效，剩下的作用只有两条：§3 的**双报契约**（各票 MUST 报出 A/H 两套区间），以及 §4 的**跨票方向校验**。轴仍是弱轴，但弱在什么地方变了——**新挂载票 MUST NOT 用本轴去证成一个倍数档位**。

本文不是框架，不进标的池（落在 `frameworks/axes/`，不由 `list_framework_paths` 扫入）。

### L 档不是「南向停止」

271 亿/月仍是净流入。**南向转为净流出的情景不在任何机构口径里**，按 `AGENTS.md`「L = 已实测过的坏」它尚未被实测，故**不进 L**——它属于挂载票 `deep_discount` 档的解释材料。挂载票 **MUST NOT** 把「南向净流出」写进自己的 L 档命名机制。

## 3. 传导规则（挂载票 §3 MUST 写出）

轴只锁**倍数取哪一档分位**：

```
本票锚点 = 本票分子（自身业务驱动，MUST NOT 引用本轴）
         × 本票 own-year 倍数带的 { 低沿 | 中位 | 高沿 }
                                    ↑ 档位由本轴状态指示
```

三条硬约束：

1. **锚 H 的票，倍数带 MUST 用 H 股自身的 own-year 序列**，**MUST NOT** 套用 A 股倍数带。H 股长期折价 26–42%，套 A 股带会让整条价带系统性上偏（实测：华新 A 股 own-year PE 中位 11.42，H 股仅 5.82）。
2. **轴 MUST NOT 进入任何挂载票的分子**。南向资金买什么不改变企业赚多少。
3. 各票 §3 **MUST** 双报 A/H 两套五档区间（2026-09-27 定：原「并报出当期 H/A 比值」已删——它是本票现价的函数，`AGENTS.md`「现价 — 禁写契约」；跨票方向校验改读本文 §1 的带日期序列）。

### 这是弱轴——它不覆盖倍数的全部

倍数的档位同时受**本票林奇分类的倍数政策**（`cyclical` 反向 / `fast_grower` 同向，见 skill A2e-5）支配，而该政策**优先于本轴**。轴只在「同一分位分布里取哪一档」这一层给出跨票一致的指示；当两者冲突时（例：`cyclical` 票在轴 H 档但周期在峰值，倍数政策要求压倍数），**MUST 服从倍数政策并在该票 §3 注明背离**。
