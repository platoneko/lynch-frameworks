# _AXIS.sic — 碳化硅（衬底 → 外延 → 功率器件）同业尺轴

> 轴类型：`peer_ruler_axis` | 更新：2026-10-03 | 挂载票：— ｜ 参照：WOLF.US · 2631.HK
> 口径：**碳化硅这一块业务**（衬底、外延、功率器件同一条链）的估值尺子——腿拆法、腿 \(g_2\)、腿经济性取法、期权份数与单位的取法；不按公司划分，挂在哪家公司的碳化硅业务上都用同一把尺

同业尺轴（valuation-rules「数据优先级与同业同尺」）：只锁**尺**，不锁**世界**——没有三档、没有共识行、不做加总校验。组员 §3 Inputs 中取自本轴的行，来源单元格写 `_AXIS.sic`，由各自 `eval/` 跨文件逐值校验，单改一边即红。各票的输入（共识、账面、产能、实测或推断出的利润率、兑现年、篮子）留在各票，本轴只引用其 Assumptions 行，不另存数字。

## 1. 尺（组员一致）

- **腿拆法**：一条腿 `sic`（碳化硅衬底 + 外延 + 功率器件）。碳化硅就是整家公司时整公司单腿（`WOLF.US`：衬底与器件共用同一批 200mm 产能与同一个利用率瓶颈；`2631.HK`：官方分部「半导体材料」100%）；碳化硅只是一部分业务的公司，把碳化硅切成 `sic` 腿，其余业务按各自的尺另算
- **底牌**：碳化硅腿今天没有可算的放量后分子（两家组员都是），底牌退到资产 PB 三档（清算 / 不作废 / 一个账面，0.55 / 0.80 / 1.00 × 本票账面）；放量成功走 \(V_{opt}\)。底牌不由本轴改
- **篮子取法**：器件与材料制造默认**篮 4 常规经营 10%**——行业周期、单产品、未盈利、小盘、高 β 都不抬 r（2026-10-03 篮 7 收窄）。只有举证「价格由市场报价决定、公司不定价」才落篮 6；只有对手方 / 国别命中（最近财年单一客户 ≥50% 或前两大 ≥70%、高国别风险）才落篮 7，且留篮 7 必须过篮子对判定（会变的状态 → 终值篮 4 + 显式 \(k\)，样板 `BE.US`）。碳化硅衬底 / 器件目前**没有**交易所或合同引用的公开报价（上海有色网只有 4/6 寸会员调查价、无 8 寸；集邦为付费报告；龙头成交为一对一议价 + 长协）→ 不满足篮 6。篮子是各票的输入（对手方数据各票各查），不进本轴 Inputs
- **腿 \(g_2\)**：功率半导体 / 碳化硅同业横截面反解（§2），同一把 Gordon 尺；簇中位截到 \(G_{cap}\)。成功世界 ROE < r 时 \(g\) 越大倍数越低，照算不改 \(g\)
- **期权份数**：本票**具名**满产产能换算成收入（产能 × 单价，或公司以收入表述的产能）；不用行业池 × 份额
- **期权单位经济（满产利润率）**：MUST 配满产（valuation-rules「未建模期权」，2026-10-03）。取数序：① 最远可见年卖方——**收入规模与满产份数匹配的那一档**（更远年只有单家点估计也取，标层级；爬坡中段年份的共识利润率 MUST NOT 乘满产收入，反例 `2631.HK` 2028E 12% × 119 万片）→ ② 公开数据推断：≥2 期拆固定 / 变动成本外推到满产收入 → ③ 自身实测高利用率年份只作交叉 / 下限（800V 直流 / 固态变压器等数据中心电源会让高功率器件的比重远高于过去，历史年代表不了满产时的产品结构）。结论**以区间报出**，底牌期权取区间内有来源的一点并写理由，区间两端进敏感性
- **成功世界 ROE**：分母只放**经营资本**（账面 − 净现金；可转债按本票股数口径处理——完全稀释时转债视同转股、只扣非转股债）；达产仍需的、已具名的扩产投入（未投募资里指定给满产份数那部分）在成功世界里计入经营资本、同额从加回现金里扣掉；其余净现金 / 未投募资在成功世界价值里单独加回（不折现）
- **估值与折现**：兑现年按本票尺估值 `perpetual_pe(g2, ROE_成功, r)`（r = 本票篮子 r），经营价值按同一 r 折回本票分子年，加回现金，减底牌 H 得 \(V_{opt}\)；**借量不借价**——任何同业或一次性事件的价格（法院估值、IPO 定价、战略入股作价）只作交叉
- **兑现年**：本票具名的达产年（公司文件里的达产 / 募资用毕年份，取最新一份）；没有具名年份 → 对齐年份 + 2，标「无时点锚·拍值」
- **\(p_k\)**：0 / 0.25 / 1.0（eval 常量，不进 Inputs；\(p_M\) 无概率锚·拍值，观测代理各票自定）
- **对齐年份**：`t_align` 2028（组员最远 ≥2 家共识年：`2631.HK` 2028E 11 家；`WOLF.US` FY2028E 2 家）；无借用过渡年（组员底牌都不用盈利分子）

同一把 Gordon 尺：前瞻 PE = 收盘 ÷ 下一财年共识 EPS，前瞻 ROE = 该 EPS × 股本 ÷ 最新季度归母权益；先按实付派息率选分支，再判域；只取单调区（ROE − r ≥ 3pp）、良态、\(r-g\ge2\%\) 的样本。
