- **② 腿 \(g_2\)**：电池制造横截面在组员估值所用的篮 6 r 13% 下反解（`implied_g`，Longbridge 2026-09-30 收盘、前瞻四季度 EPS = 2026Q2 实测 + 2026Q3E / Q4E / 2027Q1E 共识、2026Q2 BPS）：宁德时代 前瞻 PE 12.93×、ROE 27.3% → **7.34%**（有效）；亿纬锂能 前瞻 PE 15.23×、ROE 14.2%，ROE 距 r 不足 3pp（倍数对 g 无信息）→ 剔除；国轩高科 前瞻 ROE 约 3%（< r，倍数够不着）→ 剔除。有效样本 n = 1、是液态电池龙头而非固态纯腿，**单样本、相邻层，标层级**；原值 **截到 \(G_{cap}\) 6%**。只在项目 ROE > r 的档起作用；ROE ≤ r 的档按规则落 \(1/r\)
- **③ 对齐年份**：无组员腿级共识；取组员自身最远共识年（`1772.HK` 2027）
- **④ 借用过渡年表**：无（腿不进底牌）
- **⑤ 腿经济性**（推断数字落在被推断票，本轴只放取法与同业读数）：
  - **单价**：卖方层只有东吴一条全固态路径（上表），**无固液混合单价的卖方预测**。估值取 `ssb_px_ss` = 路径远端 **0.8 元/Wh（2035E）** 作**稳态单价**：兑现年的利润按 Gordon 资本化成永续，路径在 2027–2030 是首发溢价（5 → 1.5 元/Wh，逐年下滑），拿兑现年单价当永续单价会把一段下滑中的溢价读成永久——与「MUST NOT 拿爬坡中段年份的利润率乘满产收入」同理。兑现年单价（2029E 1.8、2030E 1.5）只作敏感性。交叉：液态锂电电芯约 0.38–0.46 元/Wh（东吴同篇储能电芯 12% 毛利率口径 0.38；`1772.HK` 电池腿 2025 / 2026H1 收入 ÷ 出货的上界 0.39–0.46），稳态单价约为液态的 2 倍
  - **满产营业利润率（相邻业务层）**：同业对本腿**既无卖方利润率预测，也无可用实测**（无人量产全固态；清陶固液混合在爬坡亏损期），按规则退到**相邻业务——液态锂离子电芯制造**。**相似**：同一下游（电动车、储能、无人机 / 机器人）、同一批客户，电芯制造的前段（极片）、组装、化成工序与资本结构相同；组员都是液态电池厂在同一工厂体系里扩固态。**不同**：电解质由液态换成固态（硫化物 / 氧化物），新增干法 / 等静压等工序，良率曲线未知；硫化物电解质与硫化锂当前单价高（东吴同表 2027E 400 万元/吨），材料成本占比高于液态；首发期单价溢价可能给出高于液态的利润率，本轴不给这部分 credit。取数（Longbridge 年报利润表，报表营业利润 ÷ 营业收入，2022–25 四年均值）：L = 弱者 国轩高科 **1.73%**（−1.55 / 1.45 / 3.42 / 3.59）；H = 强者 宁德时代 **14.13%**（8.73 / 12.78 / 17.03 / 17.97）减新进入者折扣 **3pp**（原因：固态良率与车规认证都未完成、规模远小于龙头；幅度为拍值）= **11.13%**；M = 中点 **6.43%**。交叉：亿纬锂能 5.78%（含思摩尔投资收益，偏高）；`1772.HK` 电池腿 2026H1 板块业绩率 4.9%
  - **经营资本**：成功世界 ROE 的分母 = 本票本腿具名项目的投资预算（100%），不用宿主公司权益
- **⑥ \(V_{opt}\) 份数与单位**：份数取数序 ① 本票卖方对本腿的远期量（出货 / 收入；≥2 家拼路径，1 家作单家路径）→ ② 本票具名产能或有公开出处的计划 × `ssb_px_ss`。**分档**：本票有卖方的量 → L / M 用它；满产（具名产能 × 稳态单价）→ H；本票没有卖方的量时只进 H，L / M 不另造量、\(p_L = p_M = 0\)（valuation-rules「未建模期权」分档，2026-10-05）。单位经济 = ⑤ 的利润率按档、本票税率、本票对项目主体的持股；兑现年按本票具名的满产年，无具名取对齐年份 + 2；兑现年按本票篮子 r 估值（项目 ROE ≤ r → \(1/r\)；ROE > r → `perpetual_pe`(本轴 \(g_2\), ROE, r)），折回本票分子年；**MUST** 扣本票应担未投资本（按投入年份折到分子年）。正负按规则原文：\(V_{opt}\) = 兑现后价值 − 未投资本，规则未设 0 下限，负值照记并披露。**MUST NOT** 借任何同业倍数；**MUST NOT** TAM × 份额
- **升级门槛**：任一组员披露本腿出货与收入 → 实测单价替换东吴路径；≥2 家卖方给出固态单价或利润率 → 替换相邻层；任一组员全固态量产满一年 → 实测利润率替代相邻层；出现固液混合单价的卖方预测 → 按组员产品结构分开取价
