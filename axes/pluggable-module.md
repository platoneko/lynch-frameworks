## 1. 组员与拆法

- **腿的边界**：模块组装的生意是「量 × 速率换代 × 自研硅光 / 外购激光的毛利」——驱动是超大厂 AI 网络的端口数与 2–4 年一代的换代节奏，单价逐年下降，利润看激光芯片采购与硅光自研比例；与上游激光芯片（产能约束、短缺租金，`_AXIS.inp-laser`）是两门生意。NPO / CPO 光引擎是本腿之后的形态，交付方部分重叠（模块厂可交付 NPO 引擎），但驱动（板级 / 共封装、ELS、测试产能）与时点不同，**不并入本腿**
- **`300308.SZ`：整公司 = 本腿**。光通信收发模块及器件 2025 年 97.5%、2026H1 98.6%（财报分部）；近封装 NPO 不是报表分部，在本票走 \(V_{opt}\)（`300308.SZ` A13），不进本腿
- **`COHR.US`：候选，本次不迁移**。数通收发器装在 Datacenter & Communications 分部里，与激光 / 器件外销、OCS、电信传输混在一起；10-K Note 3 明言不按产品披露收入，公开数据推断的最低要求第一条（腿收入有披露）不满足 → 拆不出，BLOCKED（详见 `_AXIS.inp-laser` §1）
- **`FN.US`：候选，不入轴**。FN 是光通信的中立代工厂，赚加工费：毛利率九年 11–13%、无定价权、客户订单 ≤13 周（`FN.US` 属性 B）；数通可插拔只占其收入约 21%（`FN.US` A21），且它组装的是客户的设计、利润不看激光采购。单位经济与驱动都不同于自有品牌的模块厂 → 不是本腿；`FN.US` 不改，其 A21 的可插拔敏感行已引用本腿的 2%
- **篮子取法**：模块是公司自报价的器件，盈利不是商品价函数（非篮 6）；客户集中未达单客户 ≥50% / 前两大 ≥70% 不进篮 7；国别风险（出口管制、FCC、关税）按篮 4 判据进 L 情景与证伪点，不抬 r。篮子是各票输入，不进本轴 Inputs
- **对齐年份**：`t_align` 2028（`300308.SZ` 最远共识年 FY2028：UBS / 花旗两家点估计，进 \(g_1\)）；无借用过渡年
- **借用过渡年表**：无
- **腿经济性**：组员整公司 = 本腿，腿经济性 = 本票公司口径，无推断、无拍值
- **\(V_{opt}\) 份数与单位**：本腿之内的增长不进期权（已在分子 / 过渡 / \(g_2\)）；NPO / CPO 等下一形态的期权按「未建模期权」取份数（本票具名的量），其永续 \(g\) 属于未来的 NPO 环节，**不取本轴 \(g_2\)**（现行 `300308.SZ` 的 NPO 期权 g 6% 借自旧光通信混簇读数，建议另建 NPO 引擎环节的尺轴后改挂，本轴只作建议）

## 2. 腿 \(g_2\) 横截面（2026-09-30 收盘，yfinance `+1y` 共识；r = 10%）

- **结果**：入簇 **1** 家（新易盛 0.87%）。按规则 \(n\le1\) 的簇只作互证，不能单独作来源
- **来源层级与取值：\(g_2\) = 2.0%，自定（用户 2026-09-29 拍板，见 `300308.SZ` A16），同业互证**。规则顺序：同业横截面（\(n=1\)，只作互证）→ 共享情景轴（`_AXIS.ai-capex` / `_AXIS.optical-comms` 不给 \(g\)）→ 具名宏观（美国长期名义增速约 4%）。用户此前判断「可插拔 2027–28 年后到头，4% 也是周期顶部上的看法」，取 2%（低于具名宏观，规则偏离）。本轴按环节、分市场复核后的同行证据：唯一入簇的同周期位置龙头新易盛 0.87%，低于 2%、远低于 4%；跟随者（光迅、联特、博创、AAOI）全部越顶，是爬坡 / 追赶增长被单一前瞻年读成永续（`300308.SZ` 属性 F）。故同行校验指向「低于 4%」，不支持 4%；取 2% 而非 0.87% 见下条；2% 仍是自定值，偏离照常在组员 Outputs 披露
- **不取 0.87% 的理由**：唯一入簇样本在 A 股，A 股龙头的倍数里压着中国厂特有的政策风险（下节），在跨市场固定的篮子 r 下这部分会被读成更低的 \(g\)——对本腿任何非中国组员是偏低方向；且单家不足以定值，保留用户拍板的 2%
- **同世界门**：`300308.SZ` FY27 → FY28 两家点估计上行，\(g_2>0\) 可用（\(g_2\le0\) 被门禁止）
- **复核**：非组员同周期位置的模块厂 ≥2 家入簇（典型：光迅 / 剑桥覆盖到 ≥2 家且读数落进上限）→ 按簇中位改本轴；或 ≥2 家卖方给出组员 FY29 主业预测 → 重审

## 3. 国别

- **读数**：A 股非组员龙头 0.87%（新易盛）、港股无非组员干净样本（剑桥 H 不可达）、美股无干净样本（AAOI 越顶、COHR 混业、FN 不同腿）
- **差异体现为什么**：
  - **A / H 同股**：剑桥科技 A 3.22% vs H 不可达（同一份盈利），是小盘 A / H 溢价的市场结构，不是 \(g\) 差——只在研究对话的隐含 r 对账里读，不进 \(g_2\)（组员中际旭创两地读数的比较同样只在对话里看）
  - **中国厂 vs 美国厂**：美国 FCC 设备认证规则（2026-09-11 发布）与 S.5548 点名中国模块厂，可能从 3.2T 起分代限制（`300308.SZ` A14）——这是**二元的份额事件**，对中国组员进 L 情景与证伪点，对美国厂（`COHR.US` 属性 F：「利好本票、利空同业」）只作 H 之上的解释项，都不是永续增速的差异；A 股龙头的低读数里有这部分政策折价，AAOI 的越顶读数里有「美国本土产能」的政策期权，二者方向相反、都不是 \(g_2\)
  - **关税 / 客户集中于美国云厂**：同腿各国厂商卖给同一批超大厂、同一代产品，需求端增速相同；客户集中按篮 4 判据进 L 情景
- **结论：国别差异只作输入差异 / 披露，本腿不按国别分 \(g_2\)**，同腿同 \(g_2\)（valuation-rules「同业组内同一条腿 MUST 取同一个 \(g_2\)」）

## 4. 证伪条件

- **共封装替代**：2027–2028 年主力客户 scale-up 与 scale-out 新平台都以 CPO 为主、模块厂不在光引擎名单 → 本腿 \(g_2\) 下修复核（`300308.SZ` A22）
- **激光芯片松动**：`_AXIS.inp-laser` 通道一（中国 InP 激光上量）触发 = 本腿降本、毛利率腿上修，是本腿组员的 H 侧证据，不改本轴
- **监管全面落地**：中国组员被列入覆盖清单且 800G / 1.6T 新型号同受限 → 中国组员事件增量（L 成为工作情景）；若同时出现美国 / 东南亚模块厂 ≥2 家入簇 → 本轴按新簇重算

## 5. 镜像（只披露）

- 本腿的激光采购成本 ≡ `_AXIS.inp-laser` 的短缺租金；本腿组员的份额流失（监管）≡ 美国 / 东南亚模块厂的份额获得。各票条件情景，不据此缩减任一票输入
