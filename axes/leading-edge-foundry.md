# _AXIS.leading-edge-foundry — 先进逻辑晶圆代工

> 轴类型：`peer_ruler_axis` | 更新：2026-10-05（H 满产份数改为产能 × 晶圆价；同日核验：L 尺 8.5% → 7.0%；同日 H 份数改为满产与卖方高路径取大） | 挂载票：— ｜ 参照：INTC.US | 候选：TSM.US（尺的提供方：本轴借它的实测营业利润率作上界；其框架未按本轴拆腿，输入不变）

同业尺轴（`contracts.md`「同业尺轴」）：锁先进逻辑节点（≤ 3nm 级 / Intel 18A · 14A）外部晶圆代工 + 配套先进封装这一块业务的估值尺子，不带三档、不写共识行、不做加总校验。组员 Inputs 中取自本轴的行，来源单元格写 `_AXIS.leading-edge-foundry`，由各自 `eval/` 逐值校验，单改一边即红。成熟特种代工（SiGe / RF / 电源）不属本轴（驱动与单位经济不同，见 `GFS.US`）。

## 1. 尺（组员一致）

- **① 从宿主公司拆出本腿**：本腿 = 宿主的代工分部（内部 + 外部收入）。宿主的产品腿按内部转移价向代工腿付晶圆钱，产品腿利润已扣过它；两腿 + 公司未分摊 + 其他 = 合并利润，不重复。内部转移价若高于市场价，同业利润率尺会高估代工腿；`INTC.US` 的政策原文已核：分部间销售「按意在近似市场价的价格」入账、闲置产能费留在代工（10-K FY2025 Note 3，A9），实际偏离不可见。
- **② 腿 \(g_2\)**：代工簇横截面反解中位 **2.48%**（UMC / TSM / PSMC / X-FAB，r = 10%，2026-09-14；读数真源 `GFS.US` A5，与其 `g2_rest_src` 同一簇读数）。成熟与先进混簇，口径不完全对；升级门槛：先进逻辑代工 ≥2 家良态同日反解 → 替换。**只在腿 ROE > r 时用**；ROE < r 时 Gordon 落 \(1/r\)（\(g = 0\)，增长不创造价值）。**H 档 g2 = 台积电自己的反解 5.66%**（用户裁决 2026-10-04；valuation-rules「未建模期权」例外：H 世界是「追上具名同业」时，H 档 g2 取该同业自身反解，允许单样本、截到 G_cap；读数同 `GFS.US` A5 同日横截面中的 TSM 一行，2026-09-14；单样本层，已标）；L / M 仍用簇 2.48%。
- **③ 对齐年份**：**2030**——组员本腿最远有 ≥2 家卖方点估计的年份（`INTC.US` 外部代工收入：高盛、KeyBanc、美银，各家最新报告）；无带区间共识年。
- **④ 借用过渡年表**：无（组员只有 `INTC.US` 一家；其外部收入路径是本票自己的卖方拼接，见 `INTC.US` A6，不是借用）。
- **⑤ 腿经济性（稳态营业利润率尺；来源层级 = 同业实测利润率，valuation-rules「未建模期权」2026-10-04）**：本腿没有任何卖方或现任公司口径的代工整体利润率时，取两家同业多年实测营业利润率作上下界，按档定位：
  - **L 贴弱者** = 三星非存储（代工 + System LSI）好年份均值 **7.0%**（2021 5%、2022 9%；大信证券 2021-10 预测，卖方层，见 §2）——良率与客户结构停在三星水平
  - **H = 强者 − 具名折扣** = 台积电十年实测均值 **42.4%** − 良率 / 规模折扣 **12.4pp** = **30.0%**——折扣原因：良率与客户规模落后台积电，位置约在三星—台积电差距的 2/3（折扣幅度为拍值，±5pp 敏感）；交叉：低于台积电十年最差年 35.2%（2019）再减美国厂成本稀释 2–4pp
  - **M = 中点** = **18.5%**
  - **ROE 分母 = 本腿自己的经营资本**（不用宿主公司权益：重资产腿用公司 ROE 会搭轻资产腿高回报的便车）；本腿资本无分部披露时用宿主 PP&E 净值作代理并在组员 Assumptions 说明
  - **48D 抵免（美国对半导体制造投资返还 35%）不进尺**：同业实测利润率里没有它；它降低美国资产入账成本，与美国建厂成本劣势（台积电亚利桑那拖低毛利 2–4pp）大体相抵 → 不加不减，方向记为「尺略偏保守」
- **⑥ \(V_{opt}\) 份数与单位的取法**：H 档份数 = 本腿**满产**收入与卖方高路径（同一价格口径）的**较大者**（用户裁决 2026-10-05）；满产 = 在用 + 在建 + 具名项目的分厂分节点月投片 × 强者同级节点晶圆价 × (1 − 价格折扣) + 封装（价格折扣 = 与强者同成本时把强者利润率压到 H 利润率所需的降价幅度 \(1-(1-m_{强者})/(1-m_H)\)，与 ⑤ 的良率折扣是同一件事，不另设；按最后一座具名厂投产年达产；只有预算没有片数的具名项目按「预算 ÷ 宿主自己的建厂成本率」换算片数，公司具名的单厂片数在其内；比较时卖方高路径里随产品售价长的内部收入停在首年水平；高路径胜时，按同一折后晶圆价求它所需超出全部具名厂的晶圆产能，按宿主自己的建厂成本率折成资本（无具名预算，100% 归宿主），与具名未投资本一起扣减并进 H 的 ROE 分母；强者的营收 ÷ PP&E 净值只作交叉，`INTC.US` A6b，2026-10-05 起取代「宿主自身满载年周转率 × 产能底数」——其分子是内部转移价）；L / M 份数 = 本腿收入路径——内部收入随宿主产品腿、外部收入按「未建模期权」取数序（卖方远期量交叉拼接，每家只取最新一份报告 → 公司具名量；公司目标高出卖方高路径的部分只进 H）；单位经济 = ⑤ 的三档利润率；只计盈亏平衡**以上**的利润，按 ⑤ 的 ROE 与 ② 的 \(g_2\) 在对齐年份估值，用宿主篮子 r 折回分子年；已建成的产能不扣，只扣尚未投入的具名资本。
- **⑦ 镜像（只披露）**：`INTC.US` 高路径 2030 外部代工 $40B（美银 2026-08）≈ 台积电 2025 年营收的 33%；`TSM.US` 的 `deep_discount` 场景已写「先进制程被 Intel 14A / 三星分流」。各自是本票的条件情景，加总不作约束。
