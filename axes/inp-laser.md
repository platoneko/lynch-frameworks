## 1. 组员与拆法

- **腿的边界**：激光 / 光器件芯片的生意是「材料稀缺工艺的产能 × 良率 × 单价」——驱动是激光芯片产线的产能约束与器件换代（EML → CW / ELS），单位经济是芯片毛利；与模块组装（量增价降、利润看激光采购，`_AXIS.pluggable-module`）是两门生意。一家公司同时有两块时，按腿拆；拆不出时按下面两条处理
- **`LITE.US`：整公司挂本轴（拆不出，说明）**。公司自 FY26 起单一报告分部、无任何分部利润（10-K Note 17）；产品口径 FY26 Components $2,005.6M（66.5%，激光芯片 / 激光组件 / 线路子系统 / 波长管理）vs Systems $1,008.4M（33.5%，云收发器 / OCS / 工业激光），且芯片腿供给自家收发器腿，分开估值要发明内部转移价（`LITE.US` A10）。按收入与毛利结构，激光 / 器件是利润权重最大的一块（FY26 收入增量 78% 的 Components 增量来自激光芯片与组件，毛利率跳台阶来自自有激光厂稼动率，`LITE.US` 属性 B）→ 整公司用本轴的尺。**系统性偏差方向**：Systems 里的收发器部分按模块轴应取更低的 \(g_2\)，整公司按本轴 → 偏高；`LITE.US` 敏感区按「Systems 收入占比 × 模块轴 \(g_2\)」报偏差上限（收入比例拍值，Systems 里还有 OCS 与工业激光，故是上限）
- **`COHR.US`：候选，本次不迁移**。Datacenter & Communications 分部（FY26 收入 $5,274.6M）同时装着数通收发器、激光 / 器件外销（VCSEL / EEL / 泵浦 / 元件）、OCS 与电信传输；10-K Note 3 明言「不按产品类型披露收入」，季报只给数据中心 / 通信两个终端口径（都混着收发器与器件）。公开数据推断的最低要求第一条（腿收入有披露）不满足；且公司电话会称 InP 激光**大半自用**、EML 还在向外部增购（FY26 Q2），外销激光腿的规模没有可引用的量。→ 两腿拆不出，按规则 BLOCKED，不迁移；升级门槛 = 公司披露收发器 / 器件收入拆分（或 ≥2 家卖方给出分产品收入）
- **篮子取法**：激光 / 器件芯片按篮 4 常规经营 10%——公司自报价的器件，盈利不是商品价函数（非篮 6）；对手方集中未达单客户 ≥50% / 前两大 ≥70% 不进篮 7。篮子是各票输入，不进本轴 Inputs
- **对齐年份**：`t_align` 2028（组员最远 ≥2 家共识年：`LITE.US` FY2028E 22 家；候选 `COHR.US` FY2028E 19 家）；无借用过渡年
- **借用过渡年表**：无（组员自身的最远共识年已到对齐年份）
- **腿经济性**：组员整公司挂本轴，腿经济性 = 本票公司口径，无推断、无拍值；`COHR.US` 拆出前不适用
- **\(V_{opt}\) 份数与单位**：份数只来自本票具名的量（新 InP 厂、可换算收入的产能、公司收入目标减共识已含）；产能未披露时 1 座厂 = 今日每座 InP 厂的实测产出（快照·下限，样板 `LITE.US` A22）；单位经济取对齐年份腿级共识，缺则本票公司级共识净利率（拍值）；按本票的尺（篮子 r、本轴 \(g_2\)、本票 H 档 ROE）在兑现年估值，用篮子 r 折回分子年；**借量不借价**

## 2. 腿 \(g_2\) 横截面（2026-09-30 收盘，yfinance `+1y` 共识；r = 10%）

同一把 Gordon 尺：前瞻 PE = 收盘 ÷ 下一财年（`+1y`）共识 EPS，前瞻 ROE = 该 EPS ÷ 最新季度每股净资产；全部样本实付派息 < 80% 且盈利上行 → 留存分支 `implied_g_retaining`；只取单调区（ROE − r ≥ 3pp）、良态、\(r-g\ge2\%\)、\(g\le G_{cap}\)、`+1y` ≥2 家、主业是本腿、且**不是本轴组员**（组员自己的价格不进自己的 \(g_2\)，只作互证）的样本。同日取 2026-09-30：A 股 10-01 起国庆休市，四个市场共同的最后交易日。

- **结果**：入簇样本 **0**。每个市场、每一家本腿公司的反解都在 \(G_{cap}\) 6% 之上（美股非组员无本腿样本；台 7.95–8.69%、A 9.32%），没有一家落在上限以内
- **读法与取值**：反解越顶的部分是**短缺期的前瞻倍数抬升**——EML 需求超供给 >30%、泵浦售罄（`LITE.US` A8）这类有限期的短缺租金，市场在单一前瞻年上付的是多年高增长，那是过渡层的东西，**不进永续**（valuation-rules「增长的表达顺序」）。按规则逐家剔除、不截顶入簇；簇空后落到「具名宏观上限」层：**\(g_2\) = \(G_{cap}\)（篮 4）= 6.0%**——即 4% 长期名义增速 + 2pp 可见期后的跑道（valuation-rules「6% 的含义」）。取上限而不取 4% 稳态值的理由：本腿全部读数方向一致地高于上限，取 4% 等于断言同业证据指向 4% 以下，与每一个读数方向相反；上限之上的部分由组员按「增长的表达顺序」放进分子 / 过渡层 / 候选带（`LITE.US` 候选带 H′、Greensboro 期权），不放进永续
- **与旧读数的关系**：此前 `LITE.US` A16 用的是「光通信混簇」（FN / CIEN / AVGO / MRVL / ANET / CRDO / COHR，2026-09-11，中位 6.64% 截到 6%）——交换机、DSP、代工、模块混在一起，不是同一块业务；本轴改按环节取样后结论不变（仍是上限 6%），但来源层级从「同业反解截顶」变为「同业全部越顶 → 具名宏观上限」
- **未采用的读法**（只披露）：4% 稳态值（`FN.US` A10 / `300308.SZ` A16 在空簇时用过的那一层）——`LITE.US` 三档变为敏感区所列值，M 降幅越过 25%，要过纠正对账门；用户若认为「簇空即退 4%」应统一适用，本轴与 `LITE.US` 一起改
- **同世界门**：组员自身 ≥2 家共识方向向上（`LITE.US` FY27 → FY28 +54%），\(g_2>0\) 可用
- **复核**：任一本腿非组员公司出现 ≥2 家覆盖且反解落进 \(G_{cap}\) 以内（典型：短缺缓解后倍数回落）→ 入簇重算；入簇 ≥2 家且中位 < 6% 连续两季 → 按中位改本轴，组员 eval 同步变红

## 3. 国别

- **读数**：同腿非组员读数 台 7.95–8.69% / A 9.32%（1 家）/ 美 无非组员样本（MTSI 主业不符，其 7.55% 与 COHR 6.35% 也都越顶）/ 港 无样本——中国大陆与台湾的激光芯片厂反解更高，市场在它们身上付的是国产替代 / 追赶的多年高增长（源杰 `+1y` 较当年 +64%、联亚 +99%）
- **判断：国别差异是过渡层与情景输入的差异，不是 \(g_2\) 的差异**。三条理由：① 全部读数都越顶，被截掉的正是国别间不同的那部分（追赶速度），永续层没有可分辨的国别差；② 篮子 r 跨市场固定（valuation-rules「篮子 r 跨市场固定」），A 股 / 台股估值结构的差异在研究对话的隐含 r 对账里读，不进 \(g_2\)；③ 出口管制 / 关税是二元事件，按篮 4 判据进 L 情景与证伪点（下节通道一），不进 r、也不进 \(g_2\)
- **故本腿不按国别分 \(g_2\)**，同腿同 \(g_2\)

## 4. 证伪条件（两条独立打击通道，MUST 分开写、MUST NOT 互相否证）

产业推演见 `_local/wiki/optical-comms-value-chain.md` §6.3。两条通道打击的都是本腿的**短缺租金与份额**，但机制不同，可以互不证伪地各自成立：

1. **通道一 · 同路线抢份额：中国 InP 基激光芯片上量**。观察对象是中国厂的 **EML / CW 激光芯片（器件）**可认证量产（源杰等），**不是**中国 InP **衬底**扩产（衬底变松只缓解拿片，不证伪本条）。触发：中国厂 EML / CW 进入头部模块厂 800G / 1.6T 主力料号、或组员电话会承认价格让步 / 份额流失 → 组员 L 情景（净利率腿 + 份额腿）成为工作情景；对应 `LITE.US` A8 / A12
2. **通道二 · 换路线：GaAs 晶圆级激光阵列通过认证**。单器件激光功率逼近 400 mW 上限后，扩带宽要加激光器数量；GaAs 300mm 晶圆上的集成阵列（Lightmatter，每芯片 128 颗）若进入商用 NPO / CPO 引擎的量产 BOM，ELS 就不再是 InP 器件题，短缺租金因**换路线**而非中国厂上量消失（同一机制也削弱瓶颈 A 衬底需求）。观察：OCI MSA 光源章节器件选型、商用 NPO（2027）/ CPO（2028–29）引擎 BOM 里 ELS 是 InP CW 还是 GaAs 阵列、Lightmatter 招股书激光供应链；对应 `LITE.US` A13

两条任一触发 → 组员各自事件增量（L 情景 / 期权证伪），本轴复核横截面是否已回落进上限以内；**管理层「未见中国 InP 器件厂实质影响」MUST NOT 用来否证通道二**。
