# _PEER.specialty-foundry — 特种代工 · 硅光

> 组员：`TSEM.US` · `GFS.US` | 更新：2026-10-03 | 规则：valuation-rules「数据优先级与同业同尺」（2026-10-03）

## 1. 尺（组内一致）

- **腿拆法**：两腿——`sipho`（硅光 PIC 代工）/ `rest`（成熟特种代工：SiGe、RF、电源、传感器、手机 / 汽车 / IoT 等）。SiGe 留在 `rest`（两家都只单独披露硅光口径；GFS 的 CID 终端口径含 SiGe，不作腿）
- **腿利润占比**：硅光营业利润 = 硅光收入 × (`gm_sipho` − 本票营业费用率) ÷ 公司税前经济利润；`rest` = 余数（两腿闭合到本票共识）。L 用 FY2026 收入，M 用 FY2027 路径，H 沿用 M 的占比（共识区间按比例摊）
- **资本占比**：硅光收入占比（分子年）——组内共享**规则**（数据优先级：腿级资本无披露、推断给不出点值时，规则优先于数值）；敏感性 × 1.35 / × 1.62（= TSEM 推断的 50% / 60% ÷ 37%）
- **腿过渡（2028，M/H）**：硅光 \(g_1\) = 本腿收入增速（腿利润率按推断值不变）；`rest` \(g_1\) = 闭合到公司 \(g_1\)（2028E / 2027E 共识）的余数——公司利润率扩张全部落在余数腿，eval 打印
- **腿 \(g_2\)**：`sipho` = 光通信横截面反解 6.64%（`LITE.US` A16）截到 \(G_{cap}\) 6%；`rest` = 代工簇横截面反解 2.48%（`GFS.US` A5：UMC 7.48 / TSM 5.66 / PSMC −1.26 / X-FAB −0.69，2026-09-14）
- **ROE**：腿利润 ÷ (本票 2027 年初经营 BPS × 资本占比)；账面按本票口径滚动（GFS A20 / TSEM A16）
- **\(V_{opt}\)**：份数来自本票具名的量（公司收入目标、可换算的产能）；单位经济 = `gm_sipho` − 本票营业费用率、税后；按硅光腿的尺（\(g_2\) 6%、H 档硅光腿 ROE、篮子 r）在兑现年估值，按篮子 r 折回 FY2027
- **对齐年份**：`t_align` 2028（两家最远共识年同为 2028，只有点估计，进 \(g_1\)；无借用过渡年）
