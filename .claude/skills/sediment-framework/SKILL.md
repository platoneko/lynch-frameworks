## 硬约束（违反则停下来问用户）

1. **对话优先 / 落盘门闩（最重要）**  
   - **MUST** 与用户多轮对齐；**一次只问一块**（分类 → **业务地图** → thesis/主尺 → 专属属性 → 假设 → 价带公式）。  
   - **MUST NOT** 在用户明确授权落盘前创建或覆盖 `frameworks/<TICKER>.md` / 写 `eval/`。  
   - 授权话术示例：「可以落盘」「写成文件」「确认，写吧」。仅说「继续 / 嗯 / 好」≠ 授权落盘。  
   - 取数、Wisburg、给选项、贴临时表格都可以；**写仓库文件不行**。
2. **只写本仓库**（授权后）：`frameworks/<TICKER>.md`；可选 `eval/<TICKER>.py` 薄壳。不要写 invest-data；**不要**写 `universe.yaml`。
3. **林奇分类**：`lynch_primary` 必填；`lynch_secondary` 可选；二者都必须 ∈ 六类英文枚举：  
   `slow_grower` | `stalwart` | `fast_grower` | `cyclical` | `turnaround` | `asset_play`  
   **禁止**把「代工厂重估」「扣净现金」等专属叙事写成 secondary——那些只进 §1 / Assumptions。  
   分类与主尺索引写在框架**题头两行引用块**（见下方题头约定），不另建名册。
4. **业务地图必须有材料**：讨论是否分部 / SOTP 前，**MUST** 先拉近期财报分部（或 10-K/10-Q Note）与至少一份相关研报/纪要线索；**MUST NOT** 仅凭常识空拆业务。材料不足时标 `待补` 并问用户是否继续粗拆或先补数。
5. **单文件时间线**：不建 `v1.md`/`v2.md`。更新时改现行块；Changelog **只追加、且仅用于事件追踪**。
   - **初建日不写 Changelog 条目**（§4 可留空说明）。
   - **框架纠正不写 Changelog**：口径错误、主尺/公式修订、证据链补强、skill 对齐格式、印证矩阵重算等——只改 §0–§3（及 eval），**MUST NOT** 记过程叙事进 §4。
   - **事件追踪才写 Changelog**：财报后假设状态变化、里程碑触发、概率/输入被外部事件改写等。以**自然日**为单位，同一天多次合并为同一节 `### YYYY-MM-DD`，不按小时拆节。
6. **不整页推翻**：已有框架时先读全文再谈增量；大改也在同文件内改现行块。事件追踪才 append Changelog；框架纠正不写。
7. **数字必须可追溯**：§3 Inputs 写来源与 as-of；缺数据就标 `待补`，不要编造。
8. **倍数 / 锚点必须多维印证**：提出或修订任何估值倍数（整公司或分腿 PE/PB/PS、NAV 折价带）或由之推出的 \(L/M/H\) 前，**MUST** 先展示下方「倍数印证矩阵」至少覆盖的维度；**MUST NOT** 只凭感觉给 pe_L/M/H。缺维则标 `待补` 并问用户是否用残缺矩阵继续。
9. **档位构造必须跨票可比**：锚点语义真源在 `AGENTS.md`「锚点语义」；构造规则见下方 **A2e**。落盘前 **MUST** 满足：L 按 `lynch_primary` 分档构造、地板兜底时同时报情景值、分档年份与折现口径显式声明、§3 报出三个可比性读数、同驱动因子多票共享情景轴。**MUST NOT** 让三档的散布来自构造手法。
10. **不做交易指令**：可以谈价带规则，不要写「现在买入/清仓」。
11. **Ticker 文件名规范化**（见下方专节）：美股 **MUST** 带 `.US`（`WOLF.US` 而非 `WOLF`）；港股/A 股 **MUST** 保留市场后缀；文件名 = 题头 `# TICKER` = `eval/<TICKER>.py`。

## 触发后先判定模式

| 用户意图 | 模式 |
|----------|------|
| 新 ticker / 「给 XX 写框架」且尚无文件 | **初建（对话）** |
| 「纠正口径」「修公式」「证据链改写」「skill 对齐」等框架本身修订 | **框架纠正（对话）** — 改现行块，**不写 Changelog** |
| 「财报后更新」「假设加强/证伪」「里程碑触发」 | **事件增量（对话）** — 改现行块 **并** append Changelog |
| 只改分类或题头主尺一行 | **题头修补（对话后落盘）** |

若 `frameworks/<TICKER>.md` 已存在却说「重写」，先确认：是 **框架纠正**（改尺/口径，无 Changelog）还是 **事件增量**（外部事实改写假设）；除非用户明确要求清空历史段落，已有 Changelog **保留不删**。

### Ticker / 文件名规范化（落盘前 MUST 统一）

文件名、题头 `# TICKER — …`、`eval/<TICKER>.py` **三者同一字符串**。仓库 ticker 与 Longbridge 等多市场符号对齐（均带市场后缀）；yfinance 等裸代码 API **只在调用时剥后缀**，**MUST NOT** 把裸代码写进文件名。

| 市场 | 规则 | 例（正确） | 禁止 |
|------|------|------------|------|
| 美股 | **MUST** 带 `.US`（不用 `.NYSE` / `.NASDAQ`） | `WOLF.US`、`INTC.US`、`AVGO.US` | `WOLF`、`INTC`（裸代码） |
| 港股 | 保留 `.HK`；代码按交易所位数（常 4 位补零） | `0700.HK`、`2631.HK`、`2899.HK` | `700.HK`（缺零）、`0700`（丢后缀） |
| A 股 | 保留交易所后缀 `.SH` / `.SZ`（或仓库既有习惯，全仓一致） | `601899.SH` | `601899`、`601899.SS`（除非全仓已统一用 `.SS`） |

落盘前若用户口述裸美股代码（`WOLF` / `BE`），**先补成 `*.US` 再写路径**；已存在缺后缀文件时按框架纠正改名（`mv` + 改题头 / eval 指针），**不写 Changelog**。

## 步骤 A — 初建（对话 → 授权 → 落盘）

### A1. 静默准备（可工具，不落盘）

- 读 `frameworks/_TEMPLATE.md`；可扫 `frameworks/*.md` 看题头约定
- 若已有同名框架 → 按意图改走步骤 B（框架纠正）或 C（事件增量）
- **预取业务地图材料**（不落盘；供 A2 第 2 块用，见 A2b「业务地图」行）：
  - 最近一期财报 / 10-Q·10-K 的 **segment / 分部收入·营业利润**（或公司口径的 CCG/DCAI 类披露）
  - 至少 1 份卖方研报或纪要里与 **分部 / SOTP / 分部 PE·PB** 相关的段落
- **原始披露优先（MUST）**：涉及**分部利润、资本结构（永续债/优先股/少数股东）、章程条款、减值明细、分红政策**时，**MUST** 直接取定期报告原文（下载 PDF → `pdftotext -layout` → 定位附注/MD&A）。搜索摘要与新闻**只能用于定位文档**，**MUST NOT** 作为落盘数字的来源。
  - 这些字段只存在于 MD&A 叙述与报表附注里，二手转述会掉精度或漏项。实测代价（`600011.SH` 初建）：光伏半年利润被新闻写成「106.4 亿」（实为 12.22 亿）、六腿只搜到四腿（漏水电与生物质）、把「永续债+优先股」当两项（公司实际**无优先股**）——共 6 处错值，全部在读原文后才纠正。
  - **口径字段 MUST 引附注原句**：分子用「归属于母公司股东」还是「归属于**普通股**股东」，两者可能差 20% 以上（本例 FY2025 差 27.74 亿 / 24%），且数据商字段常混用。
- **不要**此时创建 `frameworks/<TICKER>.md`

### A2. 对话对齐（核心；一次一块）

按顺序推进，每块得到用户明确态度再下一块：

1. **林奇主类**（及是否要次类双属性）— 给 2–3 选项 + 你的倾向理由  
2. **业务地图 → 是否分部估值**（**MUST 启发式主动引导**，不可等用户先提 SOTP）  
   - 先贴一张**有来源的**临时业务表（收入/利润或资产占比 + as-of + 来源：财报 Note / 卖方分部表 / 纪要）  
   - 对照下方「分部启发式」打分：命中 ≥2 条 → **默认倾向**给 SOTP 或分部尺选项；0–1 条 → 默认整公司尺，但仍列出「若拆会怎么拆」供否决  
   - 对照下方 **「银行 / 存款类主尺启发式」（A2c-2）**：命中 → 主尺骨架**第一选项**放 **Gordon PB-ROE**（仍列 2–3 项供否决，**不要擅自定案**）  
   - 给用户 **2–3 个主尺骨架选项**（例：整公司 PE / 不对称 SOTP / 核心盈利+资产期权；**银行票见 A2c-2**），**不要擅自定案**  
   - 若选分部：与用户对齐「哪些块进盈利尺、哪些块进资产/期权尺、L 是否允许某块为 0」  
3. **一句话 thesis** 与 **主尺公式**（承接上一步；写出映射到 \(L/M/H\) 的口径）  
4. **专属属性**（这票特殊在哪；至少一条；分部差异可写在这里）  
5. **可证伪假设**（日后进 Assumptions 表）  
6. **锚点 \(L < M < H\) 怎么从 Inputs 算出来**（**MUST 先印证倍数，再报价带**）  
   - 分腿票 **MUST** 先按 **A2e-5b** 声明每腿倍数机制（Gordon vs EV/EBIT）；准年金腿默认 EV/EBIT，与合约化 \(r=7\%\) **二选一、禁双计**  
   - 先贴「倍数印证矩阵」（见 A2d）再给 pe / `ev_ebit` / 折价带选项；用户锁带后才算本票 \(L/M/H\)、切点 A/B、五档区间与 zone。  
   - **构造 MUST 走 A2e**：L 按林奇主类分档、H 只取同年成功上沿、年份与折现显式、落进已有情景轴的票先对齐轴。  
   - **每个锚点 MUST 用一句话注释「定价了什么」**（哪档倍数/折价/利润年/是否计入某期权；与相邻档差在哪）。禁止只报三个光秃数字。  
   - **禁止用现价倒推 \(L/M/H\)**（禁止「市价熊 / 使 L≈P」一类循环定锚）。L 的下行须写成**可命名且有实证的**基本面折价（例：上一轮周期谷底 pe、消化年收入、港股/互联流动性折价、FCF 与 Capex 承压、监管），来源进 Assumptions；现价只用于事后归 zone 与交叉校验。  
   - 划分规则与锚点语义真源在 `AGENTS.md`，标的文档**填数字区间**，勿复制规则长文。

过程中可按需取数（见 A2b），把数字当讨论材料，**先口头/表格给用户看**。

用户含糊时给选项，不要擅自定主尺。  
六块都对齐后：贴一份「拟落盘摘要」（对照模板 §0–§3），问：**是否授权写入仓库？**

### A2c. 分部启发式（业务地图用）

讨论第 2 块时 **MUST** 用材料对照下表，向用户展示「命中了哪些信号」再给选项（启发式 ≠ 强制 SOTP）：

| 信号 | 为何倾向拆 |
|------|------------|
| 财报有清晰 operating segment，且 ≥2 块各自 ≥~15–20% 收入或利润 | 合并倍数掩盖结构 |
| 各块驱动因子不同（周期 vs 成长、产能利用率 vs ASP、监管 vs 消费） | 同一 PE/PB 不合理 |
| 林奇属性可能按块不同（例：产品 `cyclical` + 代工 `asset_play`） | 公司级单一分类不够用主尺 |
| 卖方已有 SOTP / 分部 PE·PB / NAV 拆表 | 市场在分部定价，框架应对齐可辩口径 |
| 一块在亏或投资期、另一块已赚（合并 EPS 失真） | 盈利尺与资产/期权尺宜分开 |
| 大额在建工程、隐蔽资产、分拆/出售期权集中在一块 | 适合 asset_play 子尺，不宜塞进核心 EPS |
| 增发/capex/补贴叙事主要服务某一块 | 解释市价锚时需要该块独立价值 |

**反信号（倾向整公司）**：单一主业、分部只是地区拆分、公开数据无法分开估值且用户接受合并口径。  
**缺材料**：先补财报分部或研报；用户仍要往前走时，业务表标 `待补`，主尺选项里明确「粗拆、数字后补」。

### A2c-2. 银行 / 存款类主尺启发式（Gordon PB-ROE）

讨论第 2–3 块时，若材料命中下表 **≥2 条**（或用户明确说这是银行/存款类金融机构），**MUST** 把主尺骨架排成：

1. **（推荐）Gordon PB-ROE**：\(P = BPS \times (ROE_x - g)/(r - g)\)；倍数由 ROE 档生成；历史 own-year PB **仅护栏**  
2. DDM / 股息折现（交叉或备选）  
3. 历史 PB 分位 × BPS（**默认不推荐**进底牌——回答的是交易折价习惯，不是经营状态）

启发式 ≠ 强制落盘；**仍须用户确认**。未命中则本条不触发。

| 信号 | 为何倾向 Gordon PB-ROE |
|------|------------------------|
| 主业为吸收存款 / 发放贷款，关键驱动含 **NIM、净利息收入、拨备/信用成本、资本充足率** | 约束赚钱的是监管资本与账面权益，不是工业「投入资本」叙事 |
| 卖方 ≥2 家主用 **PB-ROE / 目标 PB / DDM**，无有意义的 SOTP | 市场语言与 fair PB 同构；工业 PE 主尺易偏 |
| 分部多为零售/对公/资金等**共用一张资产负债表**（反 SOTP） | 整公司尺；ROE 压缩整张表 |
| 林奇倾向 `slow_grower` / `stalwart`（ROE 下行或个位数增长、回报靠股息） | 稳定银行用「当期 ROE 长期化」比「恐慌年 PB」更贴 M/L 语义 |

**构造要点（命中后对话第 6 块 MUST 对齐）**：

- **M** = 报表可观测 ROE（加权/平均权益；**MUST NOT** 用 EPS÷期末 BPS 虚高）长期化 + 可命名的长期 \(g\)（新体制已实现增速，**MUST NOT** 把高 ROE 旧体制 CAGR 在 \(r-g<2\%\) 时硬塞进来）  
- **L** = ROE 退到**已实测**的坏（例：拨备覆盖率回到自身近端高点的回补冲击），**MUST NOT** 把历史恐慌 PB 低沿当 L 的生成项  
- **H** = 可命名的薄改善（例：NIM 走平），Gordon PB 越出自身实测顶 → 护栏截断或回对话  
- **卖方 TP** 只进 Outputs 映射 / 交叉，**MUST NOT** 反解进 fair PB  
- **MUST NOT** 用工业 **ROIC / WACC / FCF** 与银行 ROE 交叉成「应几乎同估值」——存款利息是生意成本，非常规资本结构剥离（样板与原理见仓内已落盘 `600036.SH`；科普 `_local/wiki/gordon-pe-roic-scope.md` 仅人读，非落盘真源）

**样板**：`frameworks/600036.SH.md`（`formula_id`: `cmb_gordon_pb_roe_v2`）；`eval/lib/gordon.py` 的 `justified_pb` / `perpetual_pe`。

### A2d. 倍数印证矩阵（价带 / pe 用）

讨论第 6 块或任何「请定 pe 带」时，**MUST** 先用一张短表（可合并列）展示下列维度，再给 L/M/H 倍数选项。维度是**印证材料**，不是第二套主尺。

| 维度 | 要回答的问题 | 最低材料 |
|------|--------------|----------|

**落盘**：印证结论进 Assumptions（状态 + 证据列）或 §3 含义/来源列；不要把整张矩阵原文堆进框架。用户否决某维时，在假设里写明「未采用：原因」。

### A2e. 档位构造（L/M/H 口径；落盘前 MUST 逐条过）

锚点**语义**真源在 `AGENTS.md`「锚点语义」；本节规定**怎么造**。目标只有一条：三档的散布 **MUST** 可归因到基本面或林奇分类，**MUST NOT** 来自作者手法——否则 `conservative` 在两票之间一个读作「便宜」、一个读作「生意不成立」，而日报把它们并排推送。

**当前算不出的东西 MUST NOT 进三档**——概率、未建模的期权都走 7) 的 zone+V 表。散布可归因的前提，是三档里只有算得出的量。

#### 1) L 按 `lynch_primary` 分档

| lynch_primary | L 的分子 | L 的倍数 | MUST 给的实证坐标（≥1） |
|---------------|----------|----------|--------------------------|
| `cyclical` / `turnaround` / `fast_grower` | **退到实测过的坏**：上一轮周期谷底盈利、消化年（收入冻结或零增长）、共识区间下沿 | **按 A2e-5 的倍数政策**，不在此处规定 | 本票自己印过的价及日期 / 上一轮谷底的实际 EPS 与当时倍数 / 街上最低 TP |
| `stalwart` / `slow_grower` | 共识下沿即可——分子本就稳，主要风险是 de-rate | 同上（该类默认同向，可退到自身历史 p10） | 该分位对应的历史日期与当时价 |
| `asset_play` | — | — | L = 资产地板；盈利尺**仍须报出**作参照 |

**本表只管分子。倍数由 A2e-5 按主类决定**——尤其 `cyclical`：分子已退到谷底时再压倍数是把周期算两遍，该类默认 flat 或反向。**MUST NOT** 因为本表写着「L」就默认倍数也要往下走。

**MUST NOT** 对 `cyclical` / `turnaround` / `fast_grower` 只压倍数不动分子——那是 `conservative` 档的中段，不是 L。次类会显著改变下行形状时（例 `stalwart` / `cyclical`），按更苛刻的那一类构造并在 §1 说明。

**地板与情景**：资产地板（PB / 净现金 / 清算值）允许兜底 \(L=\max(scenario\_L,\ floor)\)，但兜底时——

- §3 **MUST** 同时报出 `scenario_L` 与 `floor`，并标明哪个胜出
- zone 表的 `conservative` 行 **MUST** 写明该档读的是**资产口径**而非情景口径
- **触发回问**：若地板胜出且 \(scenario\_L / M < 0.3\)，说明盈利尺在 L 档已失效——**MUST** 回到对话判定：是 L 情景设得比「实测过的坏」更极端，还是该票根本不该用盈利尺当主尺

#### 2) H 只取「同年的成功上沿」，且必须是一个能独立描述的世界

**总原则：每一档 MUST 是一个可独立命名的世界状态，不是对相邻档的调整。**
自检问句：*不提 M，能把这一档说清楚吗？* 若 H 只能描述成「M 再给高一点倍数」，它就不是一档。

- 分子取共识 / 指引上沿（写明来源与家数）
- 倍数**按 A2e-5 的政策**（`cyclical` 默认 flat 或反向）。**MUST NOT** 因为这是 H 就默认倍数要往上抬
- **MUST NOT** 把「多一年的复利」或「未建模的第二段增长」塞进 H——那属于 `stretched` 档的解释，或须显式建模后走框架修订
- **结局二元、当前没有分子的业务 MUST NOT 进 H**——它属于 \(V_{opt}\) 与 zone+V 表（见 7）。判据是**分子存不存在，不是倍数带宽宽不宽**
- H 的分子年份若晚于 L/M，走下一条

反例（真实发生）：`INTC.US` 把 Foundry 的 `mid_success`（PB 3.10× × 2027E 代工 BVPS × 折现）直接计入 \(H\)。foundry success 确实是一个「能独立描述的世界」，按本条正文**完全合规**——但该腿当期年化亏 $9.05B，它值 0 还是值 66.6/股取决于一个二元结局，PB 三档给出的不是「同一笔盈利的乐观/悲观读法」，而是**两个不同的世界**。对照同票的 CPU 腿：有当期实际盈利（`eps_product` 3.21），PE 带 12–18 作用在一个已经存在的分子上 → 进底牌 H，那才是本条的适用对象。

##### 2a) 三档分子 MUST 同源同口径

L 与 H **MUST** 取自**同一个分布的两端**（同一条分析师区间的下沿/上沿、同一条情景轴的两端、同一组卖方模型的低/高），**MUST NOT** 一端用共识区间、另一端换成公司指引或单家口径。

- 反例（真实发生）：`NVDA.US` 原构造 L = 分析师区间下沿 $4,164 亿、H = 公司指引 $6,990 亿。两端不同源，H 的分子只比 M 高 **3.8%**，倍数随即接管了区分 M/H 的职责
- **供给约束的数字 MUST NOT 作 H 的分子**：公司指引若被明示为「受供应限制 / 产能限制」，那是**产能上限**而非**需求上限**，用作上沿会系统性低估 H 的分子。可作**档内坐标**（写明它落在哪两档之间）

##### 2b) 三档倍数 MUST 同源同分位

倍数带的三档 **MUST** 来自**同一个分布的三个分位**（自身历史 PE 的低/中/高分位，或同业实测簇的低/中/高），**MUST NOT** 一档取历史中位、另一档反解自卖方最高目标价。

- **目标价倍数是市场判断，不是生意判断**：卖方 TP 隐含的倍数回答的是「市场应该给多少」，属**市场事件**；把它放进 H 等于用一次重估充当一个盈利年。TP 只进 A2d 印证与 §3 交叉校验，**MUST NOT** 作 `pe_h` 的依据
- 反例（真实发生）：`NVDA.US` 原 `pe_h = 25` 反解自 HSBC TP 365，而 `pe_m = 20` 取自历史带——两个不同性质的分布混用

##### 2c) flat-multiple 阶梯检验（**MUST**，且 MUST 进 eval）

把三档倍数全部置为 `pe_m` 重算，报出 flat 口径的 \(L/M/H\)：

- 三档 **MUST** 在**分子上**就已成阶梯（\(eps_L < eps_M < eps_H\)），且 flat 口径下 \(L<M<H\) 仍成立
- 若某档在 flat 口径下塌进相邻档或倒序，**该档没有独立的分子，构造不成立**——**MUST** 回到对话重设分子，**MUST NOT** 靠倍数把它撑开
- 反例（真实发生）：`NVDA.US` 原构造把 `pe_h` 按林奇反向压到 18× 时 H = 287.76 **低于 M**，即原 H 完全靠倍数撑

**「不给指引」不是冻住分子的理由。** 公司不发 EPS/FCF 指引时，分子仍有两条零预测的退路，**MUST** 先用尽再谈豁免：

1. **共识区间的两端**——共识存在且带区间时（例：51 家、13.50–17.21），那就是 2a 要的同源两端
2. **自身已实现的历史极值**——利润率、分部 margin、单位经济的**实测**谷底/高点写在自己的财报里，用它们不需要预测任何事。范例：`GOOG.US` 的 Cloud OI margin 一年内 **20.7% → 35.6%**（同一份 10-Q），拿 20.7% 作 L 档分子是实测，不是预测

##### 2c-ex) `stalwart` / `slow_grower` 的有条件豁免

该两类的分子确实稳，**de-rate 主导的价带可以接受**——但 **MUST** 同时满足三条，缺一即回到 2c 正文：

1. 倍数三档仍**同源同分位**（2b 不豁免）
2. H 的倍数 **MUST NOT 越过自身历史实测高点**——越顶就不再是「已建模的成功上沿」，而是 `stretched` 的内容
3. **任何一档的倍数 MUST NOT 承载未建模的业务故事**。有新业务值钱，**MUST** 按可算程度走下列三条出路之一，**MUST NOT** 糊进分母，也 **MUST NOT** 用「暂代 / 权宜」的倍数溢价替代：
   1. **算得出分子** → 做成一条**腿**，进底牌
   2. **算不出分子、但有实测上限锚** → 落 \(V_{opt}\)，进 zone+V 表（见 7）
   3. **连上限锚都给不出** → 标 `待补`，留在 `stretched` 的解释里

豁免生效时，§3 **MUST** 声明「本票为 de-rate 主导价带」并报出 flat-multiple 阶梯的宽度。

**注意豁免的不对称**：「分子本就稳」论证的是**下行**（市场把它当成熟股重估，是可独立命名的世界状态）。它**推不出上行也可以只靠倍数**——再评级是市场事件，不是生意状态。故豁免下 H 的门槛（第 2、3 条）比 L 严。

##### 2d) 违反了要修，不是标注了就算

A2e-5 的「两端不同质」是**红线**，不是披露项。发现某档的差距主要来自倍数而非分子时，**MUST** 按 2a/2b/2c 重设该档的分子并走框架纠正；**MUST NOT** 只在 §3 写一句警告就保留原锚点。

#### 3) 分子年份与折现口径 MUST 显式

三档**建议**同一 `anchor_year`。允许漂移，但漂移时：

- 题头 `主尺：` 一行与 §3 Inputs **MUST** 写明各档分子年份（例：`L/M 用 FY2029、H 用 FY2030`）
- §3 **MUST** 额外给一条「**归一到同一年**」的对照带：把偏离档按 `r_disc` 折回 `anchor_year`，报出同年口径的 \(L/M/H\) 与 \(H/M\)——跨票比 \(H/M\) 时用这条，不用原带
- **禁止把换年藏进情景系数**：若某档系数实际等于「换用下一年共识」，**MUST** 在中间量表里点名（例：`k_h` 实际 = FY2028 共识扣税后 SBC，而非 FY2027 的情景放大）

折现口径 **MUST** 显式，二选一：

- `anchor_year ≥ 当前财年 + 2` → 折现回今日，`r_disc` 与折现年数进 Inputs
- 选择不折现 → **MUST** 显式声明理由并给出折现后的对照带（范例：`BE.US` 以 pe 硬顶 ≤30 代替折现约束，并注明折现后整带下移 17–20%）

#### 4) 同驱动因子多票 MUST 共享情景轴

多票落在同一条宏观或产业驱动因子上时（金铜价格梯、AI capex 路径、利率路径…）：

- **MUST** 共用同一条情景梯，梯值写进各票 Inputs，由各自 `eval/` **跨文件逐格校验**（单改一边即红）
- 各票只保留自己对该梯的**敏感度**（弹性、腿占比），**MUST NOT** 各造各的下行
- 轴落盘为 `frameworks/_AXIS.<轴名>.md`：三档值 + 每档具名来源与 as-of + 传导规则 + 跨票加总校验；`_` 前缀使其不进标的池
- 新票落进已有轴时，A2 第 6 块 **MUST** 先展示该轴的现行三档取值，再谈本票弹性

**轴只锁共享的那一层。** 两种形态要分清：

| 形态 | 例 | 轴到分子的距离 |
|------|----|----------------|
| **直驱** | `_AXIS` 未落盘的金铜梯（`601899.SH` / `603993.SH`） | 价格就是收入乘数，轴几乎直接给出三档分子 |
| **隔层** | `_AXIS.ai-capex.md`（COHR / GLW / LITE / AEHR） | 分子 = 轴 × **本票份额** × 单价/组合调整；轴本身只 ±10%，各票下行主要来自第二层 |
| **零和** | `_AXIS.cowos-capacity.md`（NVDA / AVGO / TSM） | 轴是**有上限的可分配量**；一票的坏就是对手票的好，份额之和恒 = 100% |

隔层轴的第二层（份额被替代、ASP 下行、内制、客户集中度）**MUST** 由各票逐条命名并进 Assumptions，**MUST NOT** 塞回轴里冒充宏观下行；且各票 §3 **MUST** 报出**隐含份额**，供轴文件做跨票加总校验。

零和轴额外要求：**挂载票 MUST NOT 各自假设「自己被抢份额」**——那会使份额之和 < 100%。轴文件 MUST 给出「状态 → 各票档位」的映射表，且互为竞争关系的两票，其 L 与 H **MUST** 引用**同一状态**的配额值（一方的 L 对应另一方的 H），由 `eval/` 跨文件校验。

**轴的口径 MUST 匹配真实约束。** 选轴前先问：这组票是被**总量**卡住，还是被**分配**卡住？需求 > 供应时，分配才是变量，用总量轴会掩盖它。轴也 MUST 声明**覆盖边界**——轴外需求（本例：neocloud / 主权 / 前沿实验室）各票须分离报告，不得默认被轴代表。

**卖方共识窄的轴不要伪装成极端情景**：若某档在所有卖方口径里仍是高增长（AI capex L 档 +32% 即是），它就不是「最坏」——真正的转向属于 `deep_discount` 的解释材料，**MUST NOT** 写进 L 的命名机制。

#### 5) 倍数政策 MUST 显式，且 MUST 与分子分解开

主尺形如「分子 × 倍数」时，\(L/M\) 是**两个杠杆的乘积**：

\[
\frac{L}{M}=\underbrace{\frac{eps_L}{eps_M}}_{\text{分子比}}\times\underbrace{\frac{pe_L}{pe_M}}_{\text{倍数比}}
\]

**不分解就不可比。** 实测：`NVDA.US` 分子比 **0.51**、`LITE.US` **0.52`——两票的盈利情景几乎相同，但 \(L/M\) 是 0.51 vs 0.35，差距**全部**来自倍数政策（1.00 vs 0.68）。拿未分解的 \(L/M\) 跨票比较等于比较作者的倍数习惯。

**跨票比较 MUST 用分子比**；\(L/M\) 只作本票内部读数。

倍数政策按 `lynch_primary` 给默认，偏离 **MUST** 写理由：

| lynch_primary | 默认倍数政策 | 理由 |
|---------------|--------------|------|
| `cyclical` | **反向或 flat**（\(pe_L \ge pe_M \ge pe_H\)，或三档相同） | 林奇规则：**谷底盈利配高倍数、峰值盈利配低倍数**。分子已退到谷底还再压倍数，是把同一件事算两遍。范例：`603993.SH` 逆周期 15/13/12，A10 有自身 5 年 PE 与盈利强反向的实证 |
| `fast_grower` / `stalwart` | 同向可接受（\(pe_L < pe_M < pe_H\)） | 增长失速确实伴随 de-rate，是两个相关但不同的事实——但仍 **MUST** 分解报出 |
| `turnaround` | 同向可接受 | 同上 |

**红线**：

- **分子比 = 1.00**（分子三档不动、纯倍数带）对 `cyclical` / `turnaround` / `fast_grower` 是 A2e-1 违反——那不是情景，是估值区间
- **两端不同质**：若 L 的差距主要来自分子、H 的差距主要来自倍数（或反之），**MUST** 在 §3 点明——两端不是同一种陈述，不能当作对称价带读。实测：`NVDA.US` 的 H 有 25% 来自倍数、仅 5% 来自盈利
- 地板兜底档的分子比无意义（地板不是盈利尺算出来的），**MUST** 标注而非报数

##### 5b) 倍数生成机制：Gordon vs EV/EBIT（与合约化 \(r=7\%\) 二选一）

A2e-5 管「三档倍数同向 / flat / 反向」；本条管「**倍数从哪来**」。语义指针在 `AGENTS.md`「永续增长口径」准年金例外；对话定锚（A2 第 6 块）时分腿票 **MUST** 先过本条再填 `pe_*` 或 `ev_ebit_*`。

**决策树（按序）**：

1. EBIT≈可分配现金，且卖方/同业用 EV/EBIT（或「其它业务 m×」）给这类资产？→ 偏 **EV/EBIT**
2. 否则：能命名可证伪的永续 \(g\) 与 \(r\) 档？→ **Gordon**
3. 两者都能：主尺用更贴卖方的那把，另一把 **只** 进 §3 交叉校验 / 敏感性
4. 两者都不能：标 `待补`，或落 \(V_{opt}\)，**MUST NOT** 硬编 \(g\) 或硬抄一个 m

**默认分工**：

| 腿质地 | 默认主尺 | 债性/风险怎么表达 |
|--------|----------|-------------------|
| 经营腿（芯片、设备、云…） | **Gordon**（\(r\) 默认 10%，条件性 13%） | \(g\) + \(r\) 档 |
| **银行 / 存款类金融机构**（命中 **A2c-2**） | **Gordon PB-ROE**（\(P=BPS\times(ROE-g)/(r-g)\)；\(r\) 默认 10%） | ROE 三档情景 + \(g\)；历史 PB 仅护栏 |
| 专利授权 / 特许权等准年金 | **EV/EBIT 带** | 倍数锚（卖方其它业务 / IDCC 类）；**不必**再开 \(r=7\%\) |
| 合约化但卖方无 m× 锚（如照付不议 LTA） | **Gordon + \(r=7\%\)**（opt-in 合约化档） | 仅当主尺仍为 Gordon |

**与合约化 \(r=7\%\) 的关系（禁双计）**：

- \(r=7\%\) 是 Gordon **参数档**（「已决定用 Gordon 时 \(r\) 取几」），不是第二套主尺
- 准年金腿主尺 = EV/EBIT 时：债性由 m 的锚表达；**MUST NOT** 再为该腿设 \(r=7\%\) 生成 PE；Gordon+\(r=7\%,\ g=\ldots\) 只许交叉
- 准年金腿主尺 = Gordon 时：若满足合约化判据 → \(r=7\%\)；**MUST** 在 A2d 写明可能系统性低于卖方倍数
- **MUST NOT** 同一腿既用 \(r=7\%\) 抬 PE、又用「年金溢价」抬 EV/EBIT

**EV/EBIT 锚法**：三档 m **MUST** 同源（同一条年金锚梯的低/中/高，例 9/12/16），**MUST NOT** 一档抄美银、另一档反解自 TP。忽略净债时跨尺对照 \(PE \approx m/(1-t)\)（或 \(m \approx PE\times(1-t)\)）。对 EV/EBIT 腿，A2e-2b「同分位」读作「同一锚梯三档」，不适用自身历史 PE 分位；该腿 **退出**「倍数由 Gordon 生成」的强制（`AGENTS.md` 准年金例外）。

**主尺唯一**：每腿 §3 Formula / Inputs **MUST** 声明 `Gordon` 或 `EV/EBIT`；选定后另一把不得进入底牌该腿。样板：`NOK.US` Technology Standards；`QCOM.US` QTL（`qtl_evebit`）。

**量级直觉（交叉用，不定锚）**：\(r=7\%,\ g=0\) 的 Gordon PE ≈ 14.3× ↔ 税 13% 时 EV/EBIT ≈ 12×——与常见年金 M 档同量级；实测负 \(g\) 的 Gordon 系统性低于卖方时，优先考虑改主尺为 EV/EBIT，而非把 \(r\) 拧到 5%。

#### 6) 可比性读数（§3 MUST 报）

- \(L/M\)、\(H/M\)、\((H-L)/2M\)（= `neutral` 档宽占 M 的比例）
- **各自的分子比与倍数比**（见上条）；地板胜出档标注 `n/a`
- 年份漂移时另报**同年口径**的 \(H/M\)
- \(V_{opt}/M\)（无期权时报 0；见 7）

**这几个比值只在底牌口径下跨票可比。** 把期权混进锚点的票（尤其做过概率加权的）**MUST** 先按 7) 拆成底牌 + zone+V 表再取数——否则读出来的是「作者塞了多少期权」，不是基本面差异。

用 `python3 scripts/calibration.py` 取全仓分布对照；显著偏离同类票时 **MUST** 写明理由——是基本面/分类差异，还是构造该收。

#### 7) 期权与 zone+V 表（\(V_{opt}\)）

语义真源在 `AGENTS.md`；本条规定**怎么造**。目标：已具名但**当前算不出**的业务，既不进底牌污染 zone 判定，也不被丢进上不封顶的 `stretched` 而信息全失。

##### 7a) 双表

| 表 | 内容 | 用途 |
|---|---|---|
| **表一 · 底牌** | \(L/M/H\)，**零概率输入**，期权一律计 0 | zone 由它派生；四个跨票读数都读它 |
| **表二 · zone+V** | 每行 \(\text{底牌}_k + p_k \cdot V_{opt}\) | 期权计价后的读数，**不参与任何判定** |

**概率 MUST NOT 出现在底牌、切点、zone 边界与 \(L/M\)·\(H/M\)·\((H-L)/2M\)·\(V_{opt}/M\) 的计算路径里**（硬红线，eval MUST 校验）。\(p\) 类字段 **MUST NOT** 写进 §3 Inputs。

##### 7b) 什么落 \(V_{opt}\)

```
算得出分子（哪怕前景高度不确定） → 底牌 L/M/H；不确定性由 L 与 H 的距离承载
算不出分子、有已实测的上限锚     → V_opt
连上限锚都给不出                 → 标 `待补`，留在 stretched 的解释里
```

**判据是「当前能不能算出来」，不是「终局定没定」。** `turnaround` 的恢复盈利 **MUST** 进 H（锚是转机前自己印过的盈利，属实测数据）；\(V_{opt}\) **MUST NOT** 用来装「不想算」的东西，每票 **MUST** 在 §1 写明落此的理由。

##### 7c) 定锚纪律

1. \(V_{opt}\) **MUST** 来自**已实测跑出来过的轨迹**——自身其他分部、或同业同类业务的已实现规模。**MUST NOT** 用 TAM × 份额 × 概率的三层猜测。这与 L 档取「自身实测过的坏」是同一手法的反向使用。
   **份数可以模糊，单位经济不可以。**「TAM × 份额」禁的是用未实测的盘子发明上限规模；不禁「再复制几次自己已经跑出来的单位」。份数未签、卖方没给台数时，上限默认 **k=1 × 自身已实现单位**（例：`GOOG.US` 再造一条今天的 Cloud 腿；`603871.SH` 再签一条卡萨规模的特许权），模糊落在 \(p_k\)（7d 允许拍值）。**MUST NOT** 把「份数未在合同里」读成「没有上限锚、\(V_{opt}\) 必须为 0」——那会让 7b 的中间分支空转，而 7b 正是为这种模糊准备的。
   **仍属 TAM × 份额、仍禁止**：行业 TAM × 拍的份额；「稳步推进」× 自拍的单条利润（不用已实现单位）；把不同质的具名项目（海港 MoU、海外仓、少数股权）按同一条收费权加总。
2. 每个组成项 **MUST** 在 §1 具名，写出**升级门槛**（通常是「财报或 ≥2 家卖方给出可复算的细分收入 + 贡献利润」）与证伪触发器
3. 期权做成腿进底牌时 **MUST** 同时从 \(V_{opt}\) 移出（防双计）
4. **已在腿内、仅被折价的资产 MUST NOT 计入 \(V_{opt}\)**——折价带承载的就是该资产的不确定性，把「折价掉的那部分」当期权是同一笔资产算两次
5. \(V_{opt}\) **MUST NOT** 与任何形式的倍数溢价并存
6. \(V_{opt}\) 默认 0，但每票 §3 **MUST** 显式回答（填 0 合法且常见，纯 `cyclical` / `slow_grower` 通常为 0）

##### 7d) zone+V 表的形态

每行 \(\text{底牌}_k + p_k \cdot V_{opt}\)，列：`档 | 底牌 | p_k | p_k·V_opt | 修正后 | 期权隐含场景`。

- **三档 \(p_k\) MUST 全部显式给出**。\(p_H\) 默认 **1.0**（\(H\) 的世界里期权按实测上限满兑现），偏离 **MUST** 论证；\(p_L\) 通常 0，但两者都不是硬性规定
- **举证两级**：有可观测锚的 **MUST** 在 §1 具名该锚；无锚的**允许拍**，但 **MUST** 标注「无概率锚·拍值」并给量级依据。标注 **MUST** 可一眼分辨哪行有锚
- **场景列 MUST 按「兑现比例」写，不按「概率」写**——\(p_L=0\) 说的不是「概率为零」，而是「\(L\) 的那个世界里这条期权不兑现」。写成可证伪的量级（如「做到今天 Cloud 腿的四分之一，年化分部 OI ~$77 亿」），拍出来的那行才有可检验的落点
- 该列 **MUST NOT** 复述 \(L/M/H\) 的隐含场景（zone 表已写）

*实测例（有锚）*：`INTC.US` \(p_M\) 锚 = 外部代工营收 $293M/季 vs 花旗 2028E $100 亿——需两年 8.5 倍且依赖尚未签约的客户，可观测、可证伪。  
*实测例（无锚·拍值）*：`GOOG.US` \(p_M=0.25\)，依据 = 与 `INTC.US` 有锚值同量级 + A17 升级门槛与证伪触发器均未触发，故取低位。

##### 7e) 占比是披露项，不是失败条件

\(V_{opt}/M\) 大 **MUST NOT** 报红。双表结构下它污染不了任何判定；占比高只说明这张票的价值多数压在一个当前算不出的二元结局上，那是事实。超 **100%** 时 §0 **MUST** 一句话点明本票为**期权主导型**并指向升级门槛。**MUST NOT** 因占比高而回头把期权加权进 \(M\)。

*实测例*：`INTC.US` 拆表后 \(V_{opt}/M = 66.6/36.8 =\) **181%** → 标期权主导型，不报错。

##### 7f) 拆已把概率混进锚点的票

拆法是机械的：**期权归零得底牌，期权原值（含既有折现）入 \(V_{opt}\)**，原 \(p_i\) 承载的信息改由表二的按档 \(p_k\) 表达。**验收标准：表二三档逐档对上拆前的 \(L/M/H\)。**

*实测例*：`INTC.US` 拆前 27.2 / 71.2 / 113.1（\(L/M\) 0.38、\(H/M\) 1.59，全仓异常值）→ 底牌 27.2 / 36.8 / 46.4（0.74 / 1.26，回到正常区间），表二 \(p_k=0/0.52/1.0\) 得 27.2 / 71.2 / 113.0——**逐档对上，信息一点没丢，丢掉的只是「这三个数同时兼任 zone 判定基准」**。

**拆完 MUST 重跑 2c 检验。** 期权移出后，底牌可能暴露为纯倍数带——期权那一大截跨度原先掩盖了它。`INTC.US` 实测：底牌三档分子**同为** `eps_product` 3.21，阶梯 100% 来自 CPU PE 带 12/15/18（\(mid\) 是算术平均），**分子比 = 1.00**，直接违反 2c；且该票主类 `turnaround`、次类 `cyclical`，**不在 2c-ex 豁免范围内**，A2e-1 更明禁「对 `cyclical`/`turnaround`/`fast_grower` 只压倍数不动分子」。此时 **MUST** 按 A2e-1 重设 CPU 腿的三档分子（上一轮周期谷底 EPS / 共识区间下沿等），走框架修订，**MUST NOT** 因为「拆表验收已通过」就放过。

##### 7g) §Outputs 的结构（三张表）

各票 §Outputs **MUST** 统一为下列骨架，**MUST NOT** 让同一件事在 bullet、档位构造表、zone 表里各写一遍：

```
- L / M / H · 切点 A / B · V_opt（为 0 时不打印该项）
[表1]                档位构造（SOTP 按腿分列 / 单尺票按分子 × 倍数分列）
[表2]                zone 表
[表3 · 仅 V_opt > 0] zone+V 表
- 现价 → zone（+ 若 P > 底牌 H，市价隐含 p = (P−H)/V_opt）
- 敏感性
```

- **表1 · 档位构造**：每行一档。**SOTP 票按腿分列**，样板 `frameworks/1810.HK.md`，单元格是 **$/股 + 括号内倍数**（`2.45（8×）`、`2.86（0.6× PS）`），末列合计；**单尺票按 `尺类型 | 分子年份 | 分子口径 | 倍数（来源分位） | 值` 分列**。括号里的倍数是这张表存在的理由——就地可读，不必跳回 Inputs。**MUST 砍掉「这一档定价了什么」列**（与表2 重复）
- **表2**：五档 × 价格区间 × 隐含场景。**这是全文唯一写 \(L/M/H\) 隐含场景的地方**
- **表3**：见 7d

**判据一句话**：Outputs 只放「从 Inputs 重算得到的数」与「读这些数所必需的场景注解」。解释公式怎么来的（分子年份、折现、倍数政策、共享情景轴）**MUST** 回 §3 Formula；记录版本变化的 **MUST** 移出 Outputs。可比性读数与敏感性**保留**——它们是可算的输出且 `calibration.py` 消费。
