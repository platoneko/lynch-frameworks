# 启发式与印证矩阵（A2c / A2c-2 / A2d）

由 `SKILL.md` 在对话第 2 块（业务地图）或第 6 块（定倍数）时懒加载。启发式 ≠ 强制落盘；仍须用户确认主尺骨架。

---

## A2c. 分部启发式

讨论第 2 块时 **MUST** 用材料对照下表，向用户展示「命中了哪些信号」再给选项：

| 信号 | 为何倾向拆 |
|------|------------|
| 财报有清晰 operating segment，且 ≥2 块各自 ≥~15–20% 收入或利润 | 合并倍数掩盖结构 |
| 各块驱动因子不同（周期 vs 成长、产能利用率 vs ASP、监管 vs 消费） | 同一 PE/PB 胡说 |
| 林奇属性可能按块不同（例：产品 `cyclical` + 代工 `asset_play`） | 公司级单一分类不够用主尺 |
| 卖方已有 SOTP / 分部 PE·PB / NAV 拆表 | 市场在分部定价，框架应对齐可辩口径 |
| 一块在亏或投资期、另一块已赚（合并 EPS 失真） | 盈利尺与资产/期权尺宜分开 |
| 大额在建工程、隐蔽资产、分拆/出售期权集中在一块 | 适合 asset_play 子尺，不宜塞进核心 EPS |
| 增发/capex/补贴叙事主要服务某一块 | 解释市价锚时需要该块独立价值 |

**反信号（倾向整公司）**：单一主业、分部只是地区拆分、公开数据无法分开估值且用户接受合并口径。  
**缺材料**：先补财报分部或研报；用户仍要往前走时，业务表标 `待补`，主尺选项里明确「粗拆、数字后补」。

命中 ≥2 条 → 默认倾向 SOTP/分部尺选项；0–1 条 → 默认整公司尺，仍列出「若拆会怎么拆」供否决。

## A2c-2. 银行 / 存款类主尺启发式（Gordon PB-ROE）

材料命中下表 **≥2 条**（或用户明确说银行/存款类金融机构）时，主尺骨架 **MUST** 排成：

1. **（推荐）Gordon PB-ROE**：\(P = BPS \times (ROE_x - g)/(r - g)\)；倍数由 ROE 档生成；历史 own-year PB **仅护栏**
2. DDM / 股息折现（交叉或备选）
3. 历史 PB 分位 × BPS（**默认不推荐**进底牌）

未命中则本条不触发。

| 信号 | 为何倾向 Gordon PB-ROE |
|------|------------------------|
| 主业为吸收存款 / 发放贷款，关键驱动含 **NIM、净利息收入、拨备/信用成本、资本充足率** | 约束赚钱的是监管资本与账面权益 |
| 卖方 ≥2 家主用 **PB-ROE / 目标 PB / DDM**，无有意义的 SOTP | 市场语言与 fair PB 同构 |
| 分部多为零售/对公/资金等**共用一张资产负债表**（反 SOTP） | 整公司尺；ROE 压缩整张表 |
| 林奇倾向 `slow_grower` / `stalwart` | 「当期 ROE 长期化」比「恐慌年 PB」更贴 M/L |

**第 6 块 MUST 对齐**：

- **M** = 报表可观测 ROE（加权/平均权益；**MUST NOT** 用 EPS÷期末 BPS）长期化 + 可命名长期 \(g\)（**MUST NOT** 在 \(r-g<2\%\) 时硬塞旧体制高 ROE CAGR）
- **L** = ROE 退到**已实测**的坏；**MUST NOT** 把历史恐慌 PB 低沿当 L 生成项
- **H** = 可命名薄改善；Gordon PB 越出自身实测顶 → 护栏截断或回对话
- **卖方 TP** 只进 Outputs 交叉，**MUST NOT** 反解进 fair PB
- **MUST NOT** 用工业 ROIC / WACC / FCF 与银行 ROE 交叉成「应几乎同估值」

**样板**：`frameworks/600036.SH.md`；`eval/lib/gordon.py` 的 `justified_pb` / `perpetual_pe`。

## A2d. 倍数印证矩阵

定 pe / `ev_ebit` / 折价带前 **MUST** 先展示下表维度，再给 L/M/H 倍数选项。维度是印证材料，不是第二套主尺。

| 维度 | 要回答的问题 | 最低材料 |
|------|--------------|----------|
| **研报共识** | 卖方整公司或分腿用什么 PE/PB/PS？TP 隐含远期 PE？SOTP 各腿差价？ | ≥2 家近期报告；机构、as-of、倍数或 TP |
| **EPS / EBIT** | 分子哪年、哪口径？分腿利润桥？与共识偏离是否 >15%？ | 共识 + 财报；分腿桥或 `待补` |
| **ROIC（质量）** | 高/低 ROIC·ROE 是否支撑溢价/折价？相对自身与同业？ | ROE/ROA/ROIC（或可追溯代理）+ as-of |
| **股息交叉（分支校验）** | 本票与同业各在哪个 ROE 域？M 隐含派息率 vs 实付？分支是否取错？（见 `valuation-rules.md`「反解分支」）。`slow_grower` / `stalwart` / 银行 / 任何 \(g_2\) 来自反解的票 **MUST** 做；DDM 作对照带 | 年报 DPS÷归母 EPS；DPS ≥3 年 CAGR；\(1-g_2/ROE_M\) vs 实付——峰形/病态区差 >20pp 回对话；单调区只看符号 |
| **PEG（增长对价）** | PE ÷ 前瞻增速是否合理（常见 ~1–1.5）？ | 共识增速 + 候选 PE |
| **交叉约束** | 分腿加权隐含整公司 PE 是否落在历史分位 / 卖方簇附近？ | 历史 PE 带或估值 rank |
| **档位可比性** | \(L/M\)、\(H/M\)、\((H-L)/2M\) 在仓库分布何处？ | `python3 scripts/calibration.py` + 同类票 |

**落盘**：结论进 Assumptions 或 §3 来源列；勿堆整张矩阵。用户否决某维时写「未采用：原因」。
