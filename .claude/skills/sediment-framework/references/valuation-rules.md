# 估值构造口径（valuation-rules）

**本文件是 skill `sediment-framework` 的语义真源**：锚点各定价什么、倍数怎么由增长生成、增长怎么分层表达、期权与候选带的判据、共享轴的构造要求，以及这些规则互相顶时的裁决顺序。**怎么操作**见 `SKILL.md`（A2d / A2e / A2f）；**仓库级契约**（五档 zone 划分、Outputs 行格式、日报与 eval 库读什么）在仓库根 `AGENTS.md`。2026-09-14 自 `AGENTS.md` 迁出，内容未改；`eval/lib/gordon.py` 等代码引用本文。

### 价带偏离反思（zone 触发）

现价归 zone 后，**两端 zone MUST 触发反思**（操作见 skill `sediment-framework` **A2f**）；中间三档不强制。反思回答的是「框架漏了什么 / 算重了什么」，**MUST NOT** 用现价倒推改 \(L/M/H\)。

| 现行 zone | 风险方向 | MUST 回答 |
|-----------|----------|-----------|
| `stretched`（\(P > H\)） | 本仓可能**漏项 / 低估** | 本仓是否显著低于卖方；卖方框架多计入了什么；哪些已具名价值尚未量化入账，并给出可估输入 |
| `deep_discount`（\(P < L\)） | 本仓可能**双算 / 参数过激** | 结构性双计检查（同一笔资产或债性出现两次）；增长口径按「永续增长口径」重跑；至少一把不同质估值尺交叉验证 |

### 锚点语义（L/M/H 各定价什么）

zone 的中文名只有在三档语义一致时才跨票可比。**怎么造**见 skill `sediment-framework` A2e；**是什么**在这里定。

| 锚点 | 定价 |
|------|------|
| **M** | 「当期已知事实长期化」：分子取当期可观测或共识基线，倍数取自身历史中位或同业簇中位；不预设改善也不预设恶化 |
| **L** | 「已**实测过**的坏」：分子与倍数各自退到有实证的下行位置，不是想象的坏。构造按 `lynch_primary` 分档 |
| **H** | 「**已建模**的成功上沿」：分子取共识/指引上沿，倍数取自身历史高分位或同业簇上沿；**MUST NOT** 含多一年的复利或未建模的第二段增长 |

### 永续增长口径（\(r/g\)）

**经营腿：倍数由增长率生成，不取历史 PE 分位。** 历史 own-year PE 把**当年市场对增长的看法**烘进了倍数：低增长或负增长预期的年份自然给低 PE，周期底分母塌缩的年份自然给高 PE（实测：`600499.SH` 在锂价高点印 7.7×、锂价谷底印 17.2×）。拿它的分位做三档，等于把过去的增长状态搬到今天再乘今天的分子。历史带**降级为护栏**：生成的倍数越出自身实测带即红，回对话。本条**优先于** skill A2e-2b 的「倍数三档取自同一分布的三个分位」。

**准年金腿例外（与 \(r=7\%\) 二选一，禁双计）**：专利授权 / 特许权等 EBIT≈现金、卖方惯用 EV/EBIT（或「其它业务 m×」）定价的腿，**MAY** 以 EV/EBIT 带作该腿主尺，而不由 Gordon 生成倍数。选用树、默认分工、与合约化 \(r\) 的互斥关系见 skill `sediment-framework` **A2e-5b**。同一腿 **MUST NOT** 既用 \(r=7\%\) 抬 Gordon PE、又用「年金溢价」抬 EV/EBIT——债性只收一次。

**股息折现（DDM）主尺例外（2026-09-15 定）**：满足下列任一触发、且公司有**书面派息政策 / 下限**时，该票 **MAY** 改以 DDM 为主尺——(a) 留存分支 Gordon 生成的倍数落在**自身实测带外**、且任何 \(g\in[0,6\%]\) 都到不了带（典型：单调区 \(ROE\gg r\) 的国企 H 股印 6–8×，市价说的是 \(r\approx13\)–15%）；(b) **峰形 / 病态区的周期红利票**（派息 ≥ 40%、中枢 \(ROE\le r+3\)pp），中枢分子在④的同等盈利配对上**没有 ≥6 个良态月份**——市场从未在中枢盈利上交易过 Gordon 描述的那个稳态，PE 尺在这里没有实测证据，股息流才是回报主轴（同日补；实测：`000543.SZ` v4 峰形区 Gordon 出数 6.45× 却无一月配对，仍被当主尺定案）。触发后：\(P=D_1/(r-g_d)\)，\(D_1\) = 政策派息率 × 分子 EPS（三档同源，分子仍按 ② / 中枢分子规则构造），\(r\) 同档；\(g_d\) 来源优先序：同业 DDM 同尺同日反解 → 自身跨周期（≥5 年）实测 DPS CAGR → 自身实测带在股息尺上的带边反解 → 自定「无同业锚」；\(g_d\le6\%\)；DDM 隐含 PE **MUST** 落在自身实测带内。Gordon-PE 留存分支降为交叉，并 **MUST** 披露「市场隐含边际 ROE = \(g_d\) ÷ 留存率」与账面 ROE 之差——这就是市场不给留存记 credit 的量。样板：`0883.HK`。

对**仍走 Gordon** 的腿，每档 **MUST** 命名一个**永续增长率**（分腿时按该档利润权重合成），倍数由 Gordon 生成：

\[
b_x=\frac{g_x}{ROE_x},\qquad PE_x=\frac{\min(1,\ 1-b_x)}{r-g_x},\qquad r=10\%
\]

- **\(r\) 按现金流质地分三档，默认 10%**：零增长标的在默认档 = **10×**。\(r\) **MUST NOT** 按票选，只按**腿的现金流性质**选；同一性质跨票 **MUST** 同档，由 `eval/` 跨文件校验。**MUST NOT** 用它调价——判据是合约事实，不是"感觉更安全"

  | \(r\) | 判据（**MUST** 可验证，Assumptions 里引条款与到期日） | 例 |
  |------|------|------|
  | **7%** | **合约化现金流**（仅当该腿主尺仍为 Gordon）：付款方、费率、期限写在**已签合约**里，且收入不依赖产能利用率、商品价格或需求量 | 照付不议 LTA、特许经营权；专利许可若**未**改走 EV/EBIT 主尺时亦适用 |
  | **10%** | **默认**。常规经营现金流 | 绝大多数经营腿 |
  | **13%** | **条件性现金流**：收入依赖尚未落定的融资、尚未签约的客户，或由或有负债支撑 | 实验室依赖型 ASIC 订单、未签约代工产能 |

  专利/授权腿若已按 A2e-5b 选用 **EV/EBIT 主尺**（样板：`NOK.US` Technology Standards、`QCOM.US` QTL），债性由倍数锚表达，**MUST NOT** 再为该腿设 \(r=7\%\) 生成 PE；Gordon+\(r=7\%\) 只许进交叉校验。

  **为什么不是统一 \(r\)**（外部主流口径，非本仓自创）：
  - Brealey / Myers / Allen《Principles of Corporate Finance》「Company and Project Costs of Capital」：对风险不同的项目用**单一公司级折现率**，会**高估风险高的、低估风险低的**——本仓的债性腿正落在被低估的一侧
  - Damodaran 的 divisional cost of capital：SOTP 估值 **MUST** 按分部风险各自定折现率（UTC 案例即「DCF parts valuation, cost of capital **by business**」）
  - Koller / Goedhart / Wessels（McKinsey)《Valuation》：单一 WACC 不反映各业务单元的风险差异
  - Royalty Pharma 10-K 的 royalty 资产计量：**逐笔资产各自定折现率**，且**基于收入的** royalty 折现率**低于**基于利润的——因为收入型 royalty 的风险更低。这与按设备计费的专利许可是同一类现金流

  护栏：非默认档 **MUST** 在 Assumptions 引具体合约条款；`scripts/calibration.py` **MUST** 报出每票用到的 **\(r\) 档**（`r档` 列），使跨票差异在分布里可见——否则某票的 \(L/M\) 会被误读成情景差异，实为折现率差异；换档属**仓库级框架纠正**，**MUST NOT** 在单票事件增量里顺手改
- **增长要靠留存资本换**：\(PE=1/(r-g)\) 隐含 100% 派息，等价于假设增量资本回报率无穷大，对 \(g>0\) 系统性高估倍数、反解价格时系统性低估 \(g\)。前瞻 \(ROE_x = NI_x / equity\) **MUST** 进 Inputs（用 `equity` 一个字段，三档各自推导）
- **派息率封顶 100%**：\(g\le 0\) 时两式重合——**MUST NOT** 假设一门萎缩的生意返还超过盈利的资本
- **反解分支 MUST 由派息率钉定（2026-09-15 定）**。倍数反解出 \(g\) 的形状随 \(ROE\) 相对 \(r\) 的位置而变，**MUST** 先判本票（及每个同业）在哪个域，再谈读数：

  | 域 | \(PE(g)\) 形状 | 反解读数 | 机械判 |
  |----|----------------|----------|--------|
  | **峰形区** \(ROE<r\)（且 \(r-ROE\ge3\)pp） | 峰：\(g=0\) 处 \(1/r\)，两侧下行 | \(1/r\) 以下每个倍数**两个** \(g\)：全派息 + 萎缩（`implied_g`）或留存 \(g/ROE\) + 增长（`implied_g_retaining`）；**派息率选分支**。\(1/r\) 以上**不可达** | `check_branch` 符号 + 幅度（模型派息率 \(1-g_2/ROE_M\) 与实付差 ≤ 20pp）；`implied_g` 对 \(PE>1/r\) 返回 conditioned=False → BLOCKED |
  | **病态区** \(|ROE-r|<3\)pp | 几乎平：任何 \(g\in[0,6\%]\) 倍数都贴 \(1/r\) | 两条分支的 \(g\) **都不是读数**；派息率仍能选分支，但 \(g_2\) 数值须来自派息政策 / 实测，结论对 \(g\) 不敏感须按 A13 显式陈述 | `check_branch` 同上；\(g_2\) 越 cap 时截顶并注原值，**倍数改用 `capped_payout_pe`（实付派息率 ÷ \((r-6\%)\)）**——见「永续 \(g\) 上限」条 |
  | **单调区** \(ROE>r\)（\(ROE-r\ge3\)pp） | 单调上升；\(g=0\) 处 \(1/r\) | **没有第二条分支**。\(PE<1/r\) 只能读成全派息萎缩——公司若实际留存，该价在 \(r=10\%\) 下**不可达**，说的是 \(r\) 不是 \(g\) → BLOCKED（`implied_g_retaining` conditioned=False）。\(PE>1/r\) 为留存公式，正常 | `check_branch` **只做符号**；幅度差不作红线——高 ROE 账面上任何 \(g\le6\%\) 的模型派息率都 ≥ 85%，差值量的是**账面 ROE ≠ 边际 ROE**（永续债 / 杠杆 / 净现金），用 `payout_gap` 披露并回对话审 ROE 输入 |

  **选分支**：反解本票或同业时 **MUST** 先取该公司实付派息率——实际留存（< 80%）且实测盈利 / DPS 方向为正 → 留存分支；≥ 80% 派息或实测萎缩 → 全派息分支；留存却萎缩 → BLOCKED 回对话。同业簇**逐家**判域、逐家选分支；留存分支反解 \(g>6\%\) 或不可达的样本 **剔除并标 BLOCKED，MUST NOT 截顶入簇**；剔除后 \(n\le1\) 的簇只作互证，来源改自身派息政策 × \(ROE_M\)（越 cap 则截顶注原值）。**同业 MUST 与本票同域**：把峰形区同业的负 \(g\) 搬到单调区本票上（`600011.SH` 自身 ROE 16% 套火电簇 −1.53%）是跨域移植，只作交叉。全派息分支在某同业上成立（`1898.HK` 的兖矿：派 62%、利润 −37%/yr、共识向下）不等于对本票可用——仍须过同世界门。eval **MUST** 调 `check_branch(g2, ROE_M, r, payout)`。
  实测（2026-09-15 四票审计）：`1766.HK` v2 派息 50%、DPS CAGR +6% 被同业全派息分支反解成 −3.67%（隐含股息率 13.7%），5% 股息率的 `slow_grower` 被推成 `stretched` 并按 A2f「接受溢价」收口——每道机械检查都过了，因为没有一道看派息率；`000543.SZ`（派 40%，差 60pp）与 `600011.SH`（派 54%，差 46pp）同病，修正后 zone 各降一档；`GLW.US` 汽车件同业 GNTX / APTV / BWA / LEA 全在单调区，APTV / LEA 的负 \(g\) 是不可达读数；`1898.HK` 的兖煤澳 12.62× 在 ROE 3.3% 下不可达，却被 `implied_g` 算成 −1.48%（派息 145%）入簇
- **\(ROE \approx r\) 时增长不创造价值**，倍数钉在 \(1/r\) 附近。此时从价格反解 \(g\) 不稳定，\(g\) 与 \(r\) 互相顶替（实测：`6655.HK` ROE 10.7%，8.54× 既可读成 \(g=-1.7\%\) 也可读成 \(r=11.7\%\)）。这种票 **MUST** 先按上条用派息率钉定分支，再在 §3 把**剩余**的 \(r\) / \(g\) 歧义写成显式陈述，**MUST NOT** 只报其中一个读数，也 **MUST NOT** 把「歧义已陈述」当成分支已选对
- **\(g\) 贴着极点 \(r\) 时同样病态（第二条不良条件）**：`implied_g` 的 `well_conditioned` 只测 \(|ROE-r|>3\%\) 与 \(g<\min(r,ROE)\)，**测不到** \(g\) 逼近极点 \(r\) 的那一侧。\(r-g<2\%\) 时倍数对 \(g\) 的导数发散——实测（ROE 16%、\(r=10\%\)）：云倍数 **25.0× / 28.0× / 31.8× / 36.0×** 反解出的 \(g\) 分别是 **8.00% / 8.28% / 8.53% / 8.74%**，**倍数摆动 44%，\(g\) 只移动 0.74pp**。故 \(r-g<2\%\) 时，由倍数反解的 \(g\) **MUST NOT** 用作锚点，只能作**市价隐含**参照报出
- \(g\) **MUST** 是可命名的世界状态（「产能建完即止」「已公告管线兑现」），**MUST NOT** 用爬坡期同比外推；共享驱动因子的多票走情景轴
- **永续 \(g\) 上限 6%**（\(r=10\%\) 时 \(r-g\ge4\%\)；`eval/lib/gordon.py` 的 `G_CAP` / `check_g_cap`）：\(g_2\) **MUST** ≤ 上限。超出上限的增长 **MUST** 走两段式放进有共识年份的 \(g_1\)，**MUST NOT** 留在永续。**红利票的截顶 MUST 连倍数一起截（2026-09-15 定）**：峰形 / 病态区（\(ROE\le r+3\)pp）的派息票，政策 \(g=(1-\text{实付派息率})\times ROE_M\) 越 cap 时，公司仍按未截顶的 \(g\) 留存，被截掉的那部分留存既不记增长 credit、也没有返还——Gordon 的隐含派息率 \(1-6\%/ROE\) 比实付高出的那几个 pp 是凭空多算的股息。此时倍数 **MUST** 取实付派息率下的股息尺 \(PE=\text{实付派息率}/(r-6\%)\)（`capped_payout_pe`），不取 `perpetual_pe`；未越 cap 时两者恒等。实测（`1898.HK` v4）：派 30%、ROE 10.2%、政策 \(g\) 6.65% 截到 6% → Gordon 隐含派 41% 给 10.3×、M 15.24（= 市场从未印过的 12.2× FY25）；实付 30% 给 7.5×、M ≈ 11.1 = 现价——差的 33% 就是那 11pp 凭空的股息。单调区 \(ROE\gg r\) 的成长票不适用（其超额留存按 ROE 再投资，cap 本身已是保守）。\(r-g\) 在 2–4% 之间倍数对 \(g\) 的弹性已超过 25 倍（1pp ≈ 30% 的价，实测 `MRVL.US`），那是调参不是估值
- **稳态倍数上限由 \(g\) 上限派生，不另设数字**：\(PE_\infty\le(1-6\%/ROE)/(r-6\%)\)（ROE 30% ≈ 20×、50% ≈ 22×）。高于此的倍数只能来自两段式段一，段一 \(n\) ≤ 有共识的年数（`check_transition_years`）
- **增长的表达顺序**：已披露 EPS → 共识 EPS 区间三点 → 有共识的远期年（\(g_1\)，\(n\) = 共识年数）→ 稳态 \(g_2\)。上一层装得下的 **MUST NOT** 塞进下一层；没有共识的远期年只能进 \(V_{opt}\)、候选带或 `stretched` 解释
- **\(g_2\) 来源优先序**：同业横截面反解（同一把 Gordon 尺、同日；`GOOG.US` A7 样板）→ 共享情景轴 → 具名宏观上限；自定 \(g_2\) **MUST** 标「无同业锚」。反解值超过上限时截到上限并在 Inputs 注明原值
- 口径实现见 `eval/lib/gordon.py`；每票 eval **MUST** 校验 \(r-g>0\)、\(payout\in(0,1]\)、\(g\le0\) 档封顶生效、\(g_2\le\) 上限、反解来源的 \(g_2\) 过 `check_branch`（派息率与分支一致）；`scripts/calibration.py` 报 `g2` 列（读 `g2*` 字段的最大值）使跨票可见

#### 构造规则冲突的裁决顺序（MUST；2026-09-14 定）

上面的规则在周期票上会互相顶（实测：约四分之一的池子）：「倍数由 \(g\) 生成」对上「越出自身实测带即红」；A2e-1「L 分子退到谷底」对上 Gordon「分子是稳态基数」；「\(g\) 来源优先序」反解出 \(g_2\le0\) 对上市场从未印过 \(1/r\) 以下的倍数。冲突时 **MUST** 按序裁决（高 → 低）：

| # | 优先级 | 内容 |
|---|--------|------|
| 1 | **算术硬上限** | \(g_2\le6\%\)；\(r\in\{7,10,13\}\%\)；\(r-g\ge2\%\)；段二派息 \(\in(0,1]\)。不可越，也不可为达成下面任何一条而越 |

| 6 | **跨票可比读数** | 只披露、只对照，不驱动构造 |
| 7 | **现价** | 永远不是输入；只用于归 zone 与触发 A2f |

第 3 条是对「历史带降级为护栏」的细化：护栏不只是红灯，它同时是「市场为这门生意付过什么 \(g\)」的实测证据——带内任何倍数只要对应的 \(g\) 不越第 1 条，就是合法的。真正被挡下的只剩「用任何合法 \(g\) 都到不了带」的票，那才需要人来判断是生意变了还是尺不对。

**\(g_2\) 的杠杆 MUST 显式（2026-09-14 定）**：\(g\) 每动 1pp 常使 M 动 5–10%，而 \(g_2\) 与稳态分子都没有披露值——所以 §3 **MUST** 报 \(g_2\) 在证据区间两端（至少 ±1pp；有配对证据时取证据区间）下的三档与 zone。**zone 在证据区间内不变才可定案**；变了 → BLOCKED 回对话，**MUST NOT** 在区间里挑一个 \(g\) 让 zone 好看。M 的不确定区间如实写进 §3，不假装是一个点。

**纠正对账门（2026-09-15 定）**：框架纠正使 M 变动 **>25%** 或 zone **跨 ≥2 档**时，§3 **MUST** 先列对账表再定案，每行一个独立坐标：① 上一版 M；② \(E_M/r\)（中枢分子 × \(1/r\)）；③ \(D_M/(r-g_d)\)（派息政策 × 中枢分子的股息尺）；④ 市场在 ≈\(E_M\)（±12%）的实测月份付过的价；⑤ 同业同尺同日；⑥ 资产口径（BPS × 自身实测 PB 带下沿——M 跌到市场从未印过的 PB 之下，是尺错的信号）。新 M 落在**全部**坐标之外 >20% → BLOCKED——五个独立坐标都不同意的数，更可能是尺错而不是市场错。同表 **MUST** 把中性带 \([A,B)\) 换算成对 TTM、中枢、FY+1 共识三个分子的 PE 读数报出（日报读的是价，作者读的必须是倍数）：一家派息 40–60% 的电力 / 煤炭票，中性带落在 TTM 5–7× 是荒诞信号，不是「保守」。实测（`000543.SZ` v4）：M 3.78 低于全部对账坐标最低值 5.0 达 24%，中性带 [3.69, 5.47) = TTM **4.5–6.7×**——应被拦下，却被写成 `stretched`。

**BLOCKED 的语义（2026-09-15 定）**：BLOCKED = **不落盘、保留上一版、报告原因**。用户的「按推荐来 / 不用对话」授权覆盖的是常规构造选择（分子年份、权重、\(g\) 的来源层级、\(V_{opt}\) 单位…），**不覆盖任何 BLOCKED**；无人值守 / 端到端运行遇到 BLOCKED **MUST** 停在该票并报告，**MUST NOT** 以「授权定案 + 披露脆弱」的形式写入——披露不能把一个规则拦下的数变成可发布的数。同一条适用于证据区间内 zone 翻转、桥复现失败、任何 \(g\le6\%\) 到不了带、对账门不过。

#### 周期票的中枢分子与 PE < 1/r 的读法（2026-09-15 定）

- **`cyclical` 的 M 分子 MUST 是中枢盈利**：由驱动因子轴 / 情景梯的 M 档桥出（该 M 档须是多年实测均值或 ≥2 家长期 deck，**不是当前有利价位**），或自身一个完整周期（≥5 年、含上一轮谷底与峰值）的实测 EPS 均值；两者都有时互相印证，差 >20% 回对话；regime 断裂（亏损年）使均值无意义时只用轴桥并注明。当期 / TTM / 最近共识若高于中枢 **>15%**，它们是 `optimistic` / `stretched` 侧的坐标，**MUST NOT** 作 M 分子。
- **中枢的坐标系 MUST 是共享轴，不是各票自造（2026-09-15 定）**：驱动因子已有 `frameworks/axes/` 下的轴（煤价 `_AXIS.coal-price`、油价 `_AXIS.brent-oil`…）或仓内有 ≥2 票同在一条周期上时，中枢 **MUST** 取轴的 M 档经本票传导映射得到；**MUST NOT** 一票用基准价、一票用自身实现售价、一票用单位燃料成本各算各的中枢（实测：`1898.HK` 499 / `000543.SZ` 832 / `600011.SH` 288 三个坐标系描述同一条煤价周期）。轴的 M 档窗口在轴文件上定一次，挂载票只报自己的传导与残差。
- **桥 MUST 复现实测年，否则桥错（2026-09-15 定）**：轴 → 本票 EPS 的桥（单位成本斜率、售价拟合、分部毛利率梯…）**MUST** 用该年自己的第二层输入（电价 / 销量 / 产量）回代，复现 **≥2 个已发生年份 ±20%**；复现不了的桥不是「中枢偏保守」，是桥错——本票在该轴上 **BLOCKED**，**MUST NOT** 退回自造坐标。**价差生意**（电厂、炼厂、冶炼）**MUST** 显式写出第二层（电价含滞后联动、加工费）及其中枢假设；单边价格斜率 + 冻结另一边只在证明「被冻结的一边本身就在其中枢」时可用，且要披露冻结带来的方向性偏差。实测（`000543.SZ` v4）：煤价七年均值 832 经单位燃料斜率、电价冻结 FY2025 桥出中枢 EPS 0.50，回代 FY2024（煤 855）得 0.42、实印 0.91；回代 FY2023（煤 965）得 0.04、实印 0.63——桥连一个已发生年份都过不了，M 却被它砍掉 40%，再经 ROE 6.3% 压倍数到 7.55×，价折半、zone 跨两档。已废。
- **中枢分子配中枢倍数，不配峰值月份的带底**：M 倍数由中枢 ROE + 派息政策 \(g\) 生成；裁决顺序③的护栏对中枢分子 **MUST** 按④的「同等盈利」口径比对——市场可见 TTM EPS 落在中枢 ±12% 的月份——**MUST NOT** 拿整条 TTM PE 带的最低点（那是峰值盈利上印的）当中枢分子的带边：中枢分子 × 峰值倍数是把周期算两遍。同等盈利月份 < 6 个时，保留派息政策生成值并披露，随后 **MUST** 过下方「纠正对账门」。
- **PE < 1/r 的第一读法是分子在周期高位**。ROE ≤ r+3pp 且公司留存时，市场给 10× 以下的第一假设 **MUST** 是「当前 EPS 高于中枢 / 未来更低」：先算当期 EPS ÷ 中枢 EPS，>1.15 即证实、M 改中枢；只有该比值 ≤ 1.15 才轮到「留存回报 < r」（峰形区留存分支）或「r 高于 10%」（单调区，BLOCKED）的读法。**MUST NOT** 用留存分支的正 g 把 M 推回 10× 去解释一个 7–9× 的市价——那是把「盈利会回落」误读成「盈利会增长」。实测：`1898.HK` / `000543.SZ` / `600011.SH` 与两只港股通红利 ETF 的能源腿在 2026-09-15 的第一次纠正只换了分支、没归中枢，M 仍是共识 / 当期 EPS。
- 与 ②-b 的关系：②-b 的两条件用**中枢 M** 检验；共识均值高于中枢 M 超过 20% 且当期在高位时，不是 M 错，是共识还停在峰值——挂证伪触发器（下季共识回落即确认）。

#### 两段式过渡（opt-in）

标的处在**可命名的过渡期**时，框架 **MAY** 把倍数改成两段式：分子年之后的 \(n\) 年按过渡增速 \(g_1\)、其后按永续 \(g_2\)（实现 `two_stage_pe`）。

**估值时点（2026-09-14 定）**：`two_stage_pe` 与 `perpetual_pe` 同一口径——分子 = **下一期**盈利（\(t=1\)），过渡从分子年往后跑 \(E_1\to E_{n+1}\)，尾段在 \(t=n\) 取值；`two_stage_pe(n=0) ≡ perpetual_pe`。此前 `two_stage_pe` 把分子当**当期**（\(t=0\)），使启用过渡的档比同票不启用的档晚一年取值（`AVGO.US` M 档 AI 腿因此高 5.7%）；已切换，实现见 `eval/lib/gordon.py`，`recovery_two_stage_pe` 同步。**表1 报倍数 MUST 用过渡后年份的分子**（skill A2e-3）。

- **MUST 显式开启，MUST NOT 由林奇分类自动触发**：若 `fast_grower` 一律吃两段式，会**静默改写已迁移票的锚点**（`6655.HK` 就带 `fast_grower` 次类）。切换口径是仓库级框架纠正，不是分类的副作用
- \(g_1\) 与 \(n\) **MUST** 各有一个**具名、可溯源的锚**（`GOOG.US` 的 \(n\) 锚是 Cloud backlog 覆盖 **3.4 年** NTM 收入）；**MUST NOT** 用「再高增长几年」这类无锚假设
- 框架 **MUST** 写明**哪些档启用过渡、哪些档不启用**：一个把世界状态定义成生意恶化的档，不能同时背着高速过渡增长——那是自相矛盾，不是保守
- 段一派息率 **不封底于 0**：\(1-g_1/ROE<0\) 表示这段增长靠**外部融资**，**MUST** 显式报为「发股融资的增长」；截到 0 等于白送一段增长
- 段二仍**封顶 100%**（永续状态不返还超过盈利的资本）
- 不启用过渡的档直接调 `perpetual_pe`（与 `two_stage_pe(n=0)` 恒等，两者现在同一时点）；**MUST** 在口径块写明哪些档启用过渡

**谷底档（`cyclical` / `turnaround` 的 L）：实测回归段 + 中枢 Gordon**（2026-09-14 定，实现 `recovery_two_stage_pe`）。**适用范围（同日补）**：只当 L 的分子是**本票自己历史上印过的谷底年**（例：`000543.SZ` FY2022 EPS、`INTC.US` FY2023 重述 OI 那类自身时间序列上的点）。L 的分子若是**共享情景轴的 L 档梯值**（金 3,942 / 铜 9,431 平台、BMI 2028 底、铝价差 L 档、磷价 L 档…）或任何**情景 regime**，那不是谷底而是一个可命名的世界状态（「低位 regime 持续」）——配**稳态 \(g_2\)**，本票实测谷底 × \(1/r\) 只作 `deep_discount` 压力坐标。把回归段套在轴梯值上会让 L 收敛到 M（实测：铝四票 L/M 0.92–0.98，`conservative` 只剩 1 元宽，五票现价全落 `deep_discount`）——那不是「实测过的坏」，是「回归确定发生」。谷底分子配稳态 \(g_2\) 是把周期算两遍；配 Gordon 式的复苏 \(g\) 又会被派息项吃掉（谷底 ROE 低于 \(g\) 时派息为负，实测 `000543.SZ` L 档 ROE 2.8%、`000338.SZ` 5.1%）——回升靠利用率与价格，不靠留存再投资，Gordon 的留存前提在这一段不成立。故谷底档 **MUST** 这样构造：

- 段一 = **自身实测**的谷底→中枢回归路径：\(g_1\) = 上一轮实测回归 CAGR，\(n\) = 实测回归年数——两者都是已发生的事实（A2e-2c「自身已实现的历史极值」），不是预测，故不受「\(n\le\) 共识年数」约束；来源（哪两年、哪份年报）进 Assumptions。段一派息 **100%**（`annuity_factor`，无留存扣减）
- 段二 = 中枢 Gordon：\(ROE_{mid}\)（中枢年 ROE，非谷底 ROE）+ 稳态 \(g_2\)，`perpetual_pe`，派息封顶
- 生成倍数仍受第 3 条护栏；谷底 × \(1/r\)（谷底永续）只作 `deep_discount` 行的压力坐标，不作 L
- M / H 档不走本段：M = 中枢分子 × 中枢 Gordon，H = 上沿分子 × 同一 \(g_2\)（`cyclical` 可按 A2e-5 取 \(g_H\le g_M\)）
- 样板：`600096.SH` L 档（实测回归 5.04% × 3 年 → 轴 \(g_2\) 1.5%）

### L 是情景，不是地板

**L MUST 是情景，不是地板。** 资产地板（PB / 净现金 / 清算值）是独立参照，用来说明 `deep_discount` 能跌到哪。地板允许兜底 \(L=\max(\text{scenario},\ \text{floor})\)，但兜底时 **MUST** 同时报出情景值——否则同一个 `conservative` 在两票之间一个读作「便宜」、一个读作「生意不成立」。

### 可比性的构造要求

主尺形如「分子 × 倍数」时，\(L/M\) 是**分子比 × 倍数比**的乘积，**MUST 分解报出**；**跨票比较用分子比**，未分解的 \(L/M\) 比较的是作者的倍数习惯而非情景。倍数政策按林奇主类的默认见 skill A2e-5——`cyclical` 应**反向或 flat**（林奇：谷底盈利配高倍数），同向双压是把周期算两遍。散布 **MUST** 可归因到基本面或林奇分类，**MUST NOT** 来自构造手法。

### 未建模期权（\(V_{opt}\)）

已具名但当前算不出分子的业务走 zone+V 表，不进底牌 \(L/M/H\)。上限锚必须是已实测跑出来的轨迹。**份数可以模糊，单位经济不可以**——份数未签时上限默认 k=1 × 自身已实现单位，模糊落在 \(p_k\)；**MUST NOT** 把「无卖方台数 / 份数未在合同里」读成 \(V_{opt}=0\)。禁止 TAM × 份额 × 概率。已在腿内、仅被折价的资产不得再进期权。怎么造见 skill A2e-7。

### 共识升级候选带（candidate）

底牌的**下一版**在某个 `待补` 输入到齐前的预览。判据与 \(V_{opt}\) 互补——**算不出分子 → \(V_{opt}\)；算得出、但源不足（单家 / 公司指引 / 待补）→ 候选带**。**MUST** 与底牌同一 `formula_id`，只替换标明「单家 / 待补」的那几个输入，不许换尺、换 \(g\)、换 \(r\)；**MUST NOT** 带 \(p_k\) 或概率、**MUST NOT** 与 \(V_{opt}\) 混写或叠加（可并存，各一行）；**MUST NOT** 进底牌 zone、四个跨票比值或 `calibration.py`；§2 **MUST** 写升级门槛，到齐后走框架纠正把候选带**升级为底牌并删除**，不留双带。怎么造见 skill A2e-7h。
