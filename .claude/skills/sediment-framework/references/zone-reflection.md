## 低估侧（本仓远低于现价 → 漏项风险）

0. **差距溯源（先于第 1 步；2026-09-27 定，样板 `002714.SZ` A4 / A14 / A16）**
   - **拆层**：在本仓自己的尺上，把卖方 TP 中位与市价各反解两个读数——篮子 r 下的**隐含稳态分子**；分子取本仓 M 时的**隐含 r**。隐含分子高于本仓 M 分子 ≥25% → 差在分子层，走下面三条；否则差在 r 层，走 `valuation-rules.md`「隐含 r 对账」第 3 条；两层都有先做分子层。两个读数只给检索指方向，**MUST NOT** 进 Inputs / 锚点 / 落盘（仍受下文「现价倒推」禁令约束）
   - **取样窗口审计**（`cyclical` 主类或次类 **MUST**）：列出 M 中枢取样窗口内的**供给状态变量**（产能 / 存栏 / 开工率 / 库存相对正常水平或政策目标，具名来源）。窗口全落单一状态（全过剩或全紧平衡）→ 中枢有方向性偏差，进下一条
   - **历史同形态检索**：到窗口之外找印出过隐含分子量级（±25%）的时期——更早的年报（`pdftotext`）、上一轮周期、规模更小的年代、同业。每个命中 **MUST** 写：当时的供给状态变量读数与持续时长；管理层原文对该周期的描述（优先于卖方复盘）；与今天的**结构差异**（规模、对手、成本结构、统计口径断层）。找不到 → 记「无先例」并写明查过哪些时期，进第 1 步
   - **定价者机制**：一句话写出「该状态下谁的成本定住价格」（边际产能现金成本 + 回本要求 / 龙头成本 / 政策价），并扫 `_INDEX.md` 找同机制票（例：`002714.SZ` 龙头限栏 ↔ 电解铝产能上限）。同机制票的实测只作交叉，**MUST NOT** 直接搬数
   - **出路**：命中的先例 → 候选带（`construction.md` §7h），**MUST NOT** 改底牌中枢。升级门槛 **MUST** 用供给状态变量写成可观察阈值（深度、持续季度数，与先例可比）；先例与今天的每条结构差异 **MUST** 变成一条门槛或一条具名长期风险。反方向（下一个完整周期实测偏离中枢超过阈值）同时写成底牌中枢的事件增量触发器
1. **对照卖方**：≥2 家近期 TP / SOTP / 目标 PE；报本仓 \(H\)（及 \(M\)）相对卖方 TP 中位比值
2. **差额表**：显著偏低则逐项列「卖方计入、本仓未计入」；每行写卖方怎么估、本仓现状（未建模 / \(V_{opt}\) / 刻意排除）
3. **未量化自检**：扫 §1 与对话已具名但未入 Inputs 的价值；指定出路——算得出 → 底牌腿/扩分子；源不足 → 候选带（`construction.md` §7h）；有实测上限锚 → \(V_{opt}\)；否则 `待补` + 门槛
4. **当场估一版**：能估给数字；不能估只留门槛，不编数
5. **入位并重算**：按规则入位后重算 \(L/M/H\)、\(V_{opt}\)，再归 zone
6. **循环判据（两终点同等合法）**：
   - \(P \le H+V_{opt}\) → 停
   - 仍超、差额表还有算得出且有来源的项 → 回第 2 步
   - 仍超、差额表已无此类项 → **接受溢价**：对话里写幅度与具名来源（街倍数 / 第二段叙事 / 单家数字），不落盘。市梦率票通常停此——是结论不是失败

**接受溢价举证**：停前 **MUST** 对四个合法杠杆逐个交代（入位数字，或不可用的具体原因）。已具名单家/待补 **MUST** 先做候选带；已具名实测单位 **MUST** 先落 \(V_{opt}\)。四项未逐个交代 → 接受无效，回第 3 步。`cyclical` 票接受溢价前 **MUST** 已完成第 0 步；「无先例」须列出查过的时期。

**先排除尺错，再谈溢价**：进差额表前 **MUST** 先列纠正对账门六坐标 + 中性带 TTM/中枢/FY+1 PE 读数（`valuation-rules.md`「纠正对账门」）。任一坐标显示尺错 → 走框架纠正，**MUST NOT** 接受溢价。另 **MUST** 先过 A2d 股息交叉；溢价落在 \(g_2\) ±1pp 噪音内 = 尺未定准，不是终点。

**纠正使差距扩大 MUST 说明**：写明来自哪个改动、幅度、来源层级；`无同业锚` 的 \(g_2\) 在两端 zone 票上附 ±1pp 敏感性（只报 L/M/H）。披露 ≠ 拟合——**MUST NOT** 因此抬 \(H\)。

**现价不是输入**。每轮仍过 `construction.md`。合法杠杆仅四：Gordon 生成倍数；有共识年份的具名过渡（\(g_1,n\)）；有已实现单位的 \(V_{opt}\)；候选带。  
**MUST NOT**：现价倒推、分子滚下一年、TP 反解倍数、\(n\) 超出共识年、拧 \(g\) 使 \(r-g<2\%\)、用缺口反推「需要几个单位 / 多大 \(g_1\)」、**为贴现价把票换到更低 r 的篮子**。

**峰形区票的 `stretched`**：\(ROE<r-3\)pp 时 Gordon 倍数上限 \(1/r\)，市价在其上是「不可达」——按 `valuation-rules.md`「峰形区处理」第 4 条顺序：① 归篮错（市场按成长票定价）② 终值 ROE 输入错 ③ 都排除 → 差额只能来自 \(V_{opt}\) / 候选带或接受溢价。**MUST NOT** 用正 \(g\) 推倍数（峰形区 \(g\) 越大倍数越低）。
