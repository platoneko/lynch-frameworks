### 未建模期权（\(V_{opt}\)）

已具名但当前算不出分子的业务走 zone+V 表，不进底牌 \(L/M/H\)。**单位经济不在某一年一步切到常态（用户 2026-10-16）**：兑现年的利润率与回报沿该环节的高回报期走——\(Y_1\) 前取短缺 / 瓶颈期读数，\(Y_1\) 到 \(Y_2\) 线性回落到常态，\(Y_2\) 后取常态；**MUST NOT** 用「兑现年晚于短缺结束年即取常态利润率」的阶跃（原 `_AXIS.inp-laser` §1b 写法，框架纠正时改）。\(Y_1/Y_2\) 取挂轴环节的值（「稳态回报三段 · 进轴」）。**上限锚 MUST 由公开数据闭合（2026-10-03 定；此前为「已实测轨迹」）**，分两件事取：
- **多大（份数）只来自具名的量**，取数序：① **卖方对该腿的远期量**（收入 / 出货）——≥2 家年份不重合时可交叉拼成路径（2026-10-04 定，样本 `INTC.US` 外部代工）：低路径取各年最低家、高路径取最高家、中路径逐年取两者均值，缺口年按几何插值补齐，插值年 **MUST** 标出；只有 1 家时作单家路径、标层级 → ② **本票具名的量**：公司收入目标（减去共识已含部分）、可换算成收入的产能（产能 × 单价）、已签合同。两层都有时，公司目标高出卖方高路径的部分只进 H 档。具名的量换算不成收入（例 `TSEM.US` Track 2「日本 300mm 产能 ×4」无收入基数）→ 按下一条换算，换算不了才退到 1 份今日实测腿，标「快照·下限」并写升级门槛（披露基数即按产能换算）。
- **未投产 / 不披露收入的业务不得因此记 0（2026-10-05 定，样本 `000725.SZ` 玻璃基载板、`HOCPY.US` HDD 基板新厂）**：本票没有卖方对该腿的量时，**MUST** 先找**同业的卖方预测**（同一块业务的同业：远期收入 / 出货 / 单价 / 利润率），并按「同业同尺」建或挂一条同业尺轴，轴上锁单价与利润率的取法；本票的量 = 本票具名产能（或有公开出处的计划）× 轴上的单价，单位经济取轴上的利润率，折扣（良率、规模、客户认证进度）**MUST** 写明原因与幅度。同业也没有卖方预测时，单价与利润率退到同业实测值；同业实测也没有时退到**相邻业务**（同一下游、同类工艺，样本：玻璃基载板借 ABF 载板），**MUST** 写明相似与不同之处。借的是单价与利润率（单位经济），不借倍数。**分档**：本票已有卖方的量（含单家）进 L / M，满产（产能 × 轴单价）进 H，与 `INTC.US` 同构；本票没有任何卖方的量时只进 H，\(p_L = p_M = 0\)（样本 `HOCPY.US`、`1772.HK`）。**满产只在产能受资本约束时当上限**：轻资产、加班次或外包即可扩产的公司（如 `AEHR.US`，年资本开支远小于收入增量），H 的量取需求端最高路径（卖方最高路径 + 客户具名计划），**MUST NOT** 用管理层的理论产能。**留存已经出钱的项目不另计**：项目资本落在底牌 \(g_2\) 所需的留存里（每年留存 ≈ 项目年投入）时，它带来的增长已在底牌，期权记 0 并写明，`g_2` 的证伪点挂在该项目上（样本 `HOCPY.US` 越南 / 新加坡新厂）。**计划的出处**：只见于卖方报告转述的公司计划算公开出处，**MUST** 写明券商与日期并标「转述」，公司自己确认后升级。连本票具名的产能都没有才记 0，并写升级门槛**MUST NOT** 用「对齐年份的整条腿规模」当一个扩产项目的份数——那会把一个项目读成再造整条腿
- **每块收入值多少（单位经济）**：对齐年份（同业组最远共识年；无组则本票最远共识年）上该腿的利润率与 ROE，按「数据优先级与同业同尺」腿级行取（腿级共识 → 公开数据推断 → 组内共享 → **同业实测利润率**）。最后一层（2026-10-04 定，样本 `INTC.US` 代工）：本票该腿没有任何卖方或公司口径的利润率时，取具名同业的多年实测营业利润率；本票的位置介于同业之间时按档取区间——L 贴弱者、H 取强者减具名折扣、M 取中点；折扣 **MUST** 写明原因（如良率差）与幅度。借的是利润率（单位经济），不是倍数，与下文「借量不借价」不冲突；ROE 分母仍是本腿自己的经营资本，ROE < r 时 Gordon 落 \(1/r\)。对齐年份的腿规模（取数序：腿级卖方共识 → 由公司级共识倒推，样板 `TSEM.US` A17 2028 硅光 ≈ \$2.2B → 公司具名目标）只在本票没有任何具名的量、且期权是「追上同业」时兜底作份数
- **份数按满产 / 达产计时，单位经济 MUST 配满产（2026-10-03 定）**：利润率取满产利用率下的值，取数序：最远可见年卖方共识（更远年只有单家点估计也取，标层级）→ 公开数据推断（≥2 期拆固定 / 变动成本，外推到满产收入）→ 自身已实测的高利用率年份（只作交叉 / 下限：需求结构在变的行业，历史年代表不了未来）。**MUST NOT** 拿爬坡中段年份的共识利润率乘满产收入（反例：`2631.HK` 2028E 12% × 119 万片）。成功世界 ROE 的分母只放经营资本，净现金 / 未投出的募资在成功世界价值里单独加回（同「峰形区处理」第 1 步）
- **新建产能型期权 MUST 扣未投资本（2026-10-04 定）**：份数来自在建 / 规划产能、收购、新线的期权，\(V_{opt}\) = 兑现后价值 − 尚未投入的资本（预算 − 已投，按投入年份折到分子年），与是否有「视同派出」行无关；已由「视同派出」× k 记值的部分照 D 桶双算防线只许覆盖 \(K_{spent}\)。样板 `INTC.US`、`002895.SZ`
- 高增长行业的今日规模只是途中一点，不是默认单位，只作最后的下限。**借量不借价**：**MUST NOT** 借同业的任何倍数（当期或前瞻 PE / PS / EV 倍数——同业倍数装着同业自己的预期与叙事溢价）；估值一律用本票的尺（本票篮子 r、本票 ROE 口径、所在腿的组内 \(g_2\)），在兑现年估值后用篮子 r 折回分子年。**例外（2026-10-04 定，样本 `INTC.US` 代工）**：H 档的世界定义就是「追上某家具名同业」时（如 H 利润率取该同业减折扣），H 档 \(g_2\) 取被追赶者自己的反解（单家也可，标层级，仍截到 \(G_{cap}\)）；L / M 档仍用组内 \(g_2\)。**兑现后的继续增长 = 份数**：以 \(k>1\) 表达、模糊落 \(p_k\)，**MUST NOT** 在兑现年另开两段式或抬高单份倍数；\(k\) 从共识已含部分之外起数。**份数可以模糊，单位经济不可以**；**MUST NOT** 把「无卖方台数」读成 \(V_{opt}=0\)。禁止 TAM × 份额 × 概率。已在腿内、仅被折价的资产不得再进期权。怎么造见 `construction.md` §7。

### 共识升级候选带（candidate）

底牌的**下一版**在某个 `待补` 输入到齐前的预览。判据与 \(V_{opt}\) 互补——**算不出分子 → \(V_{opt}\)；算得出、但源不足 → 候选带**。**MUST** 与底牌同一 `formula_id`，只替换「单家 / 待补」输入；**MUST NOT** 带概率、与 \(V_{opt}\) 混写、进底牌 zone / 四比值 / `calibration.py`；**MUST** 配自己的五档表（表2c，写各分界点隐含分子）；单家输入是**上沿 / 天花板**（产能 / 合同折算、公司目标、卖方乐观情景）时按水平映射到各档（H′ 封顶在来源上沿，单点来源 M′ 不动），**MUST NOT** 换算成增速乘到别档；卖方基准预测按增长型三档共用（`construction.md` §7h）；§2 **MUST** 写升级门槛，到齐后升级为底牌并删除。怎么造见 `construction.md` §7h。

### 共享情景轴（构造要求）

轴落盘为 `frameworks/axes/<轴名>.md`；文档稳定引用写逻辑 id `` `_AXIS.<轴名>` ``（路径由 `eval/lib/axes.axis_path` 解析）。内含三档值、每档具名来源与 as-of、传导规则、跨票加总校验。轴只锁**共享的那一层**——当轴到分子之间还隔着份额或单价时（`_AXIS.ai-capex` 即如此），第二层 **MUST** 由各票逐条命名并进 Assumptions，**MUST NOT** 塞回轴里冒充宏观下行。**商品轴各档 MUST 声明 regime / point 语义**（见「周期票 regime / point 双口径」）。
