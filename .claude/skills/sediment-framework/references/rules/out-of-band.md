### ③ 出带处理流程（2026-09-19 定；样本 603871 / 600096 / 601600 / SOFI / 300014 / 600111）

出带 = 生成的 M 档倍数低于自身实测带下沿。**MUST** 按下列顺序走，每步有结论才进下一步；任一步回对话即停。

| 步 | 做什么 | 判据 / 出口 |
|---|---|---|
| 0 | **先补裁决顺序 ②** | 最远「≥2 家带区间」共识年若未作分子，先换分子（三点同源），再判 ③。出带常常一半是分子年份没跟上（300014：FY2027E n=7 挂着不用） |
| 1 | **带与分子同基** | 带印在什么 EPS 上，分子就要是什么 EPS。trailing 带（own-year / TTM）对 forward 分子（FY+1/+2 共识）**不构成 ③**——利润拐点期 trailing EPS 被压扁，带下沿虚高。改用「同等盈利月份」带（TTM EPS 落在分子 ±12% 的月份 ≥ 6 个）；没有同等盈利月份（分子从未实测过）→ 带测试**不适用**，保留生成倍数、披露、过「纠正对账门」。forward PE 序列（收盘 ÷ 当时 FY+1 共识）可作替代带，但点时共识多半拿不到，拼出来的序列 **MUST** 标注每段来源（事后实际 / 快照）。**带下沿 = 当前成交**时测试退化：带边反推 = 现价倒推，**MUST NOT** 反推；这条带边读数是现价的函数，只在对话里说，不落盘 |
| 1b | **带有效性核验（自动调带的前置门，2026-09-19 定）** | 同基只是必要条件。带下沿那几个月 **MUST** 再核两项，与本票现行 M 档模型逐项对照并写进 §3：① **当时的增长预期**——那几个月市场看到的 FY+1→FY+2 共识增速（点时共识拿不到时用其后两年**实测** EPS CAGR 作代理并标注）vs 现模型的窗口 \(g_1\)/\(g_2\)；② **当时的盈利水平**——那几个月的 TTM / 前瞻 ROE vs 现模型 M 档 ROE。两项任一**高于**现模型一个量级（当时预期增速 − 现模型 ≥ 10pp/年，或当时 ROE − 现模型 ROE_M ≥ 5pp）→ 带**失真**（方向只算「当年预期高于现在」；当年预期或 ROE **低于**现模型的带只会偏低，拿它降篮是保守的，视为干净——601600 2025 年带下沿 ROE 19% < 现模型 28%，干净）（市场当年按后来落空的预期定价，GFS 2022：预期 ROE ≈20% + 多年高增长，今日 ROE 12% + 一年窗口）。**失真带不能证明 r 太高**：**MUST NOT** 据它降篮、**MUST NOT** 带边反推 \(g\) 或 r、不印带边 r；③ 判「不可判定」，尺子留在**初分篮**，走「纠正对账门」+ 披露失真理由，价带照出。带**干净**（两项都同量级）才进步 2–4。**没有同等盈利月份**（分子从未实测，300014）→ 不适用，同样走对账门 + 披露，理由写「无可比状态」。核验结果 **MUST** 成一行进 Outputs（带下沿月份 / 当时预期增速代理 / 当时 ROE / 现模型 \(g\)、ROE / 判定）。**ROE ≈ r 的提示**：若那几个月的 ROE 与今日 ROE 都贴着 r（±3pp），窗口长短几乎不改倍数，历史高倍数只能来自更低的 r——此时带视为干净，r 解释成立。**ROE 项只在 g > 0 时生效（2026-09-20 定）**：现模型永续 g = 0 时倍数是 \(1/r\)、ROE 不进公式，当年 ROE 再高也改变不了当年那个倍数说的是什么，②只看增速预期；ROE 差来自分母重建（破产重整 / 增发 / 大额留存后权益翻倍，000792 2023 年 ROE 52% vs 今 24%）而非当年盈利预期更高的，同样不算失真——判失真的是「市场当年按更高的盈利路径定价」，不是账面比率 |
| 1c | **带与底牌同口径：期权（2026-10-03 定；样本 `002895.SZ`）** | 带下沿那几个月若本票已有**当时已公告、市场看得见**的 \(V_{opt}\) 项（具名在建产能 / 项目 / 合同），带价里含着它：**MUST** 拿「底牌 + 该项 \(V_{opt}\)」（按带期已知的份数，\(p\) 取 1）对带，**MUST NOT** 拿底牌单独对带——否则差额被读成「r 太高」，期权经降篮被二次计入底牌。对带后回带 → ③ 不触发、不降篮；仍出带才进步 2。带期尚未公告的期权项不加。**同一原则管底牌里的增量**：带期已公告、当时尚未进入带期 EPS、而今天已进本票底牌分子的项目（在建产能、收购、长约；样本 `000792.SZ` 4 万吨锂盐、`VST.US` Cogentrix）——带价含它、带期 EPS 不含，带倍数被抬高；**MUST** 先从带价里扣除该项价值（按本票尺估、折到带期）再算带倍数，与底牌同口径后对带 |
| 2 | **增长率先诚实再反推** | 带边反推的 \(g\) **MUST** 与有来源的 \(g\) 对照：反推值 > 来源窗口 CAGR 且永续 → 是凑数不是估值（600111：带边 5.05% 永续 > GS 2026→2035 区间 CAGR 4.4%）。区间 CAGR 是**窗口数**（\(g_1\)，n = 预测期），不是永续；Inputs **MUST NOT** 把它标成「永续宏观上限」。结构 = 分子年 → 窗口 \(g_1\)（到预测期末）→ 终值 \(g_2\)（tier 默认：商品腿通胀、经营腿见 §4）。（2026-10-13：留存项回报率改用 RONIC——「经营价值与超额现金」②；下列账面 ROE 与 BPS 推演降为账面状态披露和 RONIC 上限核对，不再生成倍数。）ROE 取**分子年共识 EPS ÷ 该年初 BPS（= 上年末；Gordon 的 \(g=b\times ROE\) 里 ROE 是期初权益产出本期利润，\(E_{n+1}/B_n\)，期末口径会把尚未产出利润的当年留存放进分母；2026-09-21 定，此前误写「该年末」）**（该年初 BPS 推演：起点 = 最近财报实测每股净资产；**留存率 = 增长所需的 \(b_1=g_1/ROE\)**（无窗口 \(g_1\) 时取 \(g_2/ROE\)），与 `two_stage_pe` 段一同一个 \(b\)；**MUST NOT** 用实付分红率的补数（2026-09-21 定：此前写「近 3 年实测分红率均值」，在 ROE ≫ 再投资需求的票上把还债 / 堆现金的留存滚进分母、把终值 ROE 压成账面 ROE——`603993` 36% → 25%）；实付留存超出 \(b_1\) 的部分是「留存去向审计」B 桶，走 Outputs 披露行「模型视同派出、实际留存的现金 / 股」= (实付留存率 − \(b_1\)) × 窗口累计 EPS——两段式段一已按面值把它当作派出，故它是锚点的**前提**（不被高价回购 / 并购烧掉），不是锚点外的价值：**MUST NOT** 另作 SOTP 腿（双计），打折 k 只能从锚点里减；不进 BPS 推演、不进 \(b\)；从起点起只滚**尚未入账**的共识利润、**滚到分子年前一年末为止**（分子年自身的利润不进分母）——起点若是中报 BPS，当年共识 EPS 先扣已入账的 H1 实测；起点日之后才支付的上年股息从起点扣除；不含增发 / 回购 / 转股，有则单列；券商直印 ROE 只作对照，注意加权 / 期末口径）；账面 ROE ≠ 边际 ROE 的差按 §4 披露。分子年已含产能跳升时，窗口从跳升后起算，不双计 |
| 3 | **逐档降篮（仅限步 1b 判「干净」的带）** | **先查初分是否本就不满足篮子判据**（篮 6「商品价函数」对电池制造商 300014 不成立；篮 7「单押 / 国别重」要有 ≥50% 单一客户或国别收入依据）——不满足即**纠正归篮**：搬到**目标篮子判据也正向成立**的那一篮——两头都要举证：初分篮为什么不成立、目标篮的判据（篮 4 = 常规经营现金流、盈利不是商品价函数、不命中其余篮子；篮 5 = A2c-2 命中；篮 2 = 监管定价……）为什么成立，写进 Assumptions 的 r 行；目标篮判据不成立就不许搬（篮 4 是默认档，但「不是商品价函数」与「不命中篮 1 / 2 / 3 / 5 / 7」仍要逐条举证）。不经带、不受 1b 约束，仍留痕。判据成立时才走降篮：每降一档重做步 2（带边反推 \(g\) 是否 ≤ cap、是否有来源支撑）。停在第一个「诚实结构下 M 入带」的篮子，归篮理由写市场证据、初分篮留痕（见第 3 条）。下限篮 4 |
| 4 | **篮 4 仍出带 → BLOCKED** | 停下报告用户（「BLOCKED 的语义」），报告 **MUST** 同时给：① 篮 4 诚实结构下 L/M/H；② **带边 r**（解 M 倍数 = 带下沿的 r）及其并列价带（仅限步 1b 判「干净」的带；带下沿 ≠ 当前成交时才许；= 当前成交则带边 r 就是市价隐含 r，只在对话里报）。并列价带 **MUST** 独立成表（`construction.md` 7g 表2′），**MUST NOT** 揉进主 zone 表的场景列；其本质是「按市场在同等盈利月份给过的最低倍数所对应的折现率标价」，读者按此理解，不读作估值。市价隐含 r 只在对话里报，**不落盘**（2026-09-27 定；原 `zone@带边 r` 与「③ 市价隐含 r」两项已删）。带边 r **MUST NOT** 进篮子或主尺；它进「篮子地板样本清单」——同一标签（国企 / 垄断 / 战略资源 / 平台，**分开记**）的带边 r 聚在一处，是仓库级加篮或改篮子值的证据，攒够再动。用户看过原因拍板落盘 → ① 即底牌、照常出价带；出带事实写进 Outputs「③ 出带」披露行，② 成表2′，复核条件（篮子表变 / 带更新 / 共识上修）写进 Assumptions（样板 `ORCL.US` A21） |
| — | **不许的替代路径** | 换到能过的另一条带（PE 出带就改看 PB 谷底）——PB 谷底印在 ROE 最低的月份，与高 ROE 世界的 M 不同状态，PB 同状态带 = 同等 ROE 月份，与 PE 同等盈利带是同一件事换写法，不可能一进一出；PB 只作地板披露。期权 \(V_{opt}\) 不能救出带的尺（先过 ③ 再谈期权；唯一例外是步 1c：带期已公告的期权项本就在带价里，对带时同口径加回，不是「救」）。现价倒推。为凑形状拧 \(g\)。**用失真带降篮**（把市场当年落空的预期当成市场的 r）。用「阶段不同」放行一只带干净但出带的票（失真只能阻止降 r，不能救尺） |

**同等盈利月份的补充（2026-10-06 定）**——适用于步 1 及裁决顺序第 4 条的「同等盈利月份」：
- **同口径（MUST）**：历史月份的每股收益 **MUST** 与被比较的腿同口径。历史上公司含本腿以外的业务、且该业务占当年调整后净利润 > 10% 时，**MUST** 剔除该业务后计算；该业务的分部利润未披露、无法剔除 → 该年的月份不计入
- **M 档无同等盈利月份时（MUST）**：
  1. 改为检查 L 档：L 档倍数低于 L 档同等盈利月份（±12%、≥ 6 个）的最低倍数 → 视同出带，按步 1b–4 处理，步 1b 的带有效性核验对 L 档月份做
  2. L 档也无同等盈利月份 → 维持「不适用」，Outputs **MUST** 加一行披露：本腿同口径历史每股收益最接近 L 档的 3 个年度，各年的每股收益与市盈率（月度最低 / 中位 / 最高，带年份），并写明「均为低于 L 档分子的盈利水平，倍数含回升预期，不构成同等盈利证据」

### 独立成交价护栏（2026-10-06 定）

- **适用条件（全部满足）**：① 母公司取得本框架某一腿对应资产（下称「被收购资产」）股权的交易已交割；② 交割日距研究日 ≤ 5 年；③ 母公司与卖方无关联关系；④ 母公司在该交易中取得的股权比例 ≥ 20%；⑤ 对价为现金或有公开市价的证券
- **调整后成交价**（股权口径，币种按研究日汇率换算）= 母公司为该股权支付的对价 − 交割后母公司从被收购资产收到的现金分配累计 + 交割后母公司对被收购资产的追加出资累计。不按交割后的利润增长调整
- **本框架的被收购资产价值**（股权口径，母公司持股比例）= 该腿的股权价值 + 本框架中归属于被收购资产的全部 \(V_{opt}\) 项。归属清单 **MUST** 在 Assumptions 逐项列出。**MUST NOT** 用整只票的 L / M / H 比较，**MUST NOT** 只取其中一个组成部分比较
- **判定**：
  1. 该腿 H 档股权价值 + 归属 \(V_{opt}\) 全额 < 调整后成交价 → 判定构造有错，**MUST** 回对话复查分子（EBITDA 口径、维持性资本开支、税、杠杆口径）与增长表达；复查完成前不得落盘
  2. 该腿 M 档股权价值 + 归属 \(V_{opt}\) × \(p_M\) < 调整后成交价 → 允许落盘；Assumptions **MUST** 写出差额（金额与百分比）、原因（每条附具名证据），以及复核触发器
  3. 两项均 ≥ 调整后成交价 → 通过；Assumptions 写一行读数
- **限制**：成交价只用于本护栏；**MUST NOT** 作为锚点；**MUST NOT** 反解倍数或折现率；成交价高于本框架任何档位时，**MUST NOT** 据此下调任何档位

**\(g_2\) 敏感性：披露是一回事，拦不拦是另一回事（2026-09-14 定；2026-09-16 拆开）**

\(g_2\) 每动 1pp，M 通常动 5–10%，而 \(g_2\) 没有可观测值。所以：

1. **每票都要披露**：§3 写出 \(g_2\) 上下各动 1pp 时的 L/M/H（只报锚点，不写 zone；2026-09-27 定）。这只是让读者知道 M 有多宽，不是说 \(g_2\) ±1pp 真有证据。锚点因此移多少都写出来即可，**不拦**。
2. **只有一种情况要拦**：\(g_2\) 不是一个算出来的定值，而是从一堆证据里取的（比如同业簇给出 4%–6% 这么一段，或者配对月份反解出一个范围）。这时把这段范围的两头也算一遍；如果现价 zone 在这段范围里会变，说明证据定不了 zone，回对话（BLOCKED），**不许在范围里挑一个让 zone 好看的值**。研究对话里用研究当日现价判断，现价与判断结果不落盘（2026-09-27 定）。
3. \(g_2\) 是带边反解、轴给定、派息政策算出来的定值时，没有"一段范围"可言，只做第 1 条，不做第 2 条。

**纠正对账门（2026-09-15 定）**：框架纠正使 M 变动 **>25%** 或 zone **跨 ≥2 档**时（zone 在研究对话里用研究当日现价判断，现价与 zone 不落盘，2026-09-27 定），§3 **MUST** 先列对账表再定案，每行一个独立坐标：① 上一版 M；② \(E_M/r\)（中枢分子 × \(1/r\)）；③ \(D_M/(r-g_d)\)（派息政策 × 中枢分子的股息尺）；④ 市场在 ≈\(E_M\)（±12%）的实测月份付过的价；⑤ 同业同尺同日；⑥ 资产口径（BPS × 自身实测 PB 带下沿——M 跌到市场从未印过的 PB 之下，是尺错的信号）。新 M 落在**全部**坐标之外 >20% → BLOCKED——五个独立坐标都不同意的数，更可能是尺错而不是市场错。**与新 M 同式的坐标不计为独立印证**（2026-10-04 定）：新 M 本身就是股息尺 / \(E/r\) 时，对应那一格只印不计。同表 **MUST** 把中性带 \([A,B)\) 换算成对 TTM、中枢、FY+1 共识三个分子的 PE 读数报出（日报读的是价，作者读的必须是倍数）：一家派息 40–60% 的电力 / 煤炭票，中性带落在 TTM 5–7× 是荒诞信号，不是「保守」。

**BLOCKED 的语义（2026-09-15 定）**：BLOCKED = **不落盘、保留上一版、报告原因**。用户的「按推荐来 / 不用对话」授权覆盖的是常规构造选择（分子年份、权重、\(g\) 的来源层级、\(V_{opt}\) 单位…），**不覆盖任何 BLOCKED**；无人值守 / 端到端运行遇到 BLOCKED **MUST** 停在该票并报告，**MUST NOT** 以「授权定案 + 披露脆弱」的形式写入——披露不能把一个规则拦下的数变成可发布的数。同一条适用于 \(g_2\) 证据范围内 zone 翻转（上条第 2 种情况）、桥复现失败、任何 \(g\le G_{cap}\) 到不了带、对账门不过。**BLOCKED 只在落盘前用**：它是"停下来问用户"的信号。用户看过原因仍拍板落盘，文件就不再是 BLOCKED：底牌照常出 zone、参与跨带告警，没满足的规则写进 Outputs 披露行；事后 review 只能说"某条 rule 没满足"，不能给已落盘的文件贴 BLOCKED。
