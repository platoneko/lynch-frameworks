# 估值构造口径 · 锚点语义、价带偏离、可比性与数据分级

> `valuation-rules.md` 拆出的一组节，原文照搬。引用别的节「X」时先查 `../valuation-rules.md` 索引定位文件。

### 价带偏离反思（zone 触发）

现价归 zone 后，**两端 zone MUST 触发反思**（操作见 `zone-reflection.md`）；中间三档不强制。反思回答的是「框架漏了什么 / 算重了什么」，**MUST NOT** 用现价倒推改 \(L/M/H\)。**只在研究对话里跑（2026-09-27 定）**：用研究当日现价归 zone，现价与反思结论都 **MUST NOT** 写进框架；反思改动的东西只以普通框架内容出现（新腿、\(V_{opt}\)、候选带、Assumptions 行）。

| 现行 zone（研究当日） | 风险方向 | MUST 回答 |
|-----------|----------|-----------|
| `stretched`（\(P > H\)） | 本仓可能**漏项 / 低估** | 本仓是否显著低于卖方；卖方框架多计入了什么；哪些已具名价值尚未量化入账，并给出可估输入 |
| `deep_discount`（\(P < L\)） | 本仓可能**双算 / 参数过激** | 结构性双计检查（同一笔资产或债性出现两次）；增长口径按「永续增长口径」重跑；至少一把不同质估值尺交叉验证 |

### 锚点语义（L/M/H 各定价什么）

zone 的中文名只有在三档语义一致时才跨票可比。**怎么造**见 `construction.md`；**是什么**在这里定。

| 锚点 | 定价 |
|------|------|
| **M** | 「当期已知事实长期化」：分子取当期可观测或共识基线，倍数取自身历史中位或同业簇中位；不预设改善也不预设恶化 |
| **L** | 「已**实测过**的坏」：分子与倍数各自退到有实证的下行位置，不是想象的坏。构造按 `lynch_primary` 分档 |
| **H** | 「**已建模**的成功上沿」：分子取共识/指引上沿，倍数取自身历史高分位或同业簇上沿；**MUST NOT** 含多一年的复利或未建模的第二段增长 |

### L 是情景，不是地板

**L MUST 是情景，不是地板。** 资产地板（PB / 净现金 / 清算值）是独立参照，用来说明 `deep_discount` 能跌到哪。地板允许兜底 \(L=\max(\text{scenario},\ \text{floor})\)，但兜底时 **MUST** 同时报出情景值——否则同一个 `conservative` 在两票之间一个读作「便宜」、一个读作「生意不成立」。

### 可比性的构造要求

主尺形如「分子 × 倍数」时，\(L/M\) 是**分子比 × 倍数比**的乘积，**MUST 分解报出**；**跨票比较用分子比**。倍数政策默认见 `construction.md` §5——`cyclical` 应**反向或 flat**。散布 **MUST** 可归因到基本面或林奇分类，**MUST NOT** 来自构造手法。

### 数据优先级与同业同尺（2026-10-03 定）

**数据按用途分级，不是一条总序。** 研究对象多是高增长的明星股，当期利润表在调研时尚未放量、信息量最低；实绩的价值在证伪追踪里随时间显现。

| 用途 | 优先级（高 → 低） |
|---|---|
| 账面状态（权益、净现金、股本） | 最新财报实测，唯一来源 |
| 盈利分子与过渡（`fast_grower` / `stalwart` / `slow_grower` / `turnaround` 成长部分） | ≥2 家带区间共识（取最远可见年）→ 只有点估计的更远年（进 \(g_1\)）→ 借用过渡年（同业组）→ 公司指引 / 模型（候选带）；当期利润表实绩只作快照披露，**MUST NOT** 当分子覆盖共识。**薄覆盖（2026-10-04 定；样本 `002897.SZ`）**：最远带区间共识年只有 2 家、且共识隐含的利润增速（最新实测年 → 分子年 CAGR）≥ 本票最近 2 年实测利润增速的 2 倍（实测为负即触发；利润比利润，同为归母口径）→ 共识只进 H（H = 共识上沿）；M = 各腿按自身最近 2 年实测收入增速（窗口截到最新报告期）外推到同一分子年 × 最近四个季度实测利润率；L 照常；三档同为归母口径。Assumptions 写两家名称、日期与增速倍数比；升级门槛 = 第 3 家带区间预测出现，或实测利润增速（扣非口径，剔一次性项目对基数的扭曲）追到共识隐含利润增速的一半以上 |
| 盈利分子：`cyclical` | M / H 同上；L 与压力坐标用自身实测谷底 / 消化年（裁决表 ②-b） |
| 腿级经济性（无分部利润时的腿利润率 / ROE） | 卖方分部预测 → **公开数据推断**（见下）→ 组内共享规则（如「各腿经济性相同」；被推断证伪即不可用）→ 组内共享拍值 |
| \(V_{opt}\) 单位 | 见「未建模期权」 |
| 证伪追踪 | 实绩是唯一裁判：每季对照 Assumptions 与证伪触发器 |

**公开数据推断（腿级经济性）的最低要求**：① 输入只用披露数：分部 / 腿收入（财报或电话会原话，写出处）+ 公司三表；腿收入只有增速时按增速倒推基期并给敏感值；② ≥2 期联立（未知数个数 ≤ 期数），或增量利润率（Δ利润 ÷ Δ收入，仅当增量几乎全来自该腿）；③ 推断假设逐条写出（典型：各腿利润率在两期间不变——利用率改善会把一部分归到增长腿，偏高方向须注明；费用分摊口径；税率）；④ 无披露的资本占比给 ≥3 档区间，结论以**区间**报出，不取点；⑤ 结论落在**被推断票**的 Assumptions 一行 + Inputs 原始输入，演算进该票 eval（打印区间，复算校验）；同业组文件只引用该行，不另存数字。

样板：`TSEM.US` A17（2Q25 / 2Q26 两期联立 → 硅光毛利率 51.6%（敏感 55.5%），作同业尺轴 `_AXIS.sipho-wafer` 的共享值，`GFS.US` A21 借用）。

**同业同尺**：有**同一块具体业务**（腿）的票挂同一条同业尺轴（`frameworks/axes/<轴名>.md`，轴类型 `peer_ruler_axis`，行契约见 `contracts.md`「同业尺轴」；本文的「同业组」即一条尺轴的组员）。按业务划、不按公司或宽泛行业标签：没有共同驱动与共同单位经济的大类（如「成熟特种代工」）不建轴，各票该腿 \(g_2\) 各自标来源；一家公司可按腿挂多条。组内 **MUST** 一致的是**尺**：腿的拆法、每条腿的 \(g_2\)、借用过渡年表、\(V_{opt}\) 单位的取法与估值方法、共享规则 / 拍值。允许不同的只有**输入**：本票共识、账面、实测或推断出的腿经济性、兑现年、\(k\) 与 \(p_k\)。宿主公司 ROE 不同带来的同一条腿倍数不同，是输入差异，不是尺的错位。三条裁决：

1. 同业同尺只对齐尺，不改数据：**MUST NOT** 把有来源（含公开数据推断）的输入换成组内共享拍值
2. 拍值只填空白，组内共用；拍时**规则优先于数值**——先找能让公开数据把账闭合的结构性假设，找不到才拍具体数值，标「拍值」并报敏感性
3. 组内各票共识加总超出行业池**不算矛盾**：档位是本票的条件情景，不是行业联合预测；**MUST NOT** 据此缩减或改写任何一票的共识。镜像关系（一票 H ≡ 另一票 L）只作披露，由各票证伪触发器随时间裁决

**借用过渡年**：本票最远共识年早于同业组最远共识年时，按**同一条腿**借同业该腿的共识增速（腿级共识 → 由同业公司级共识倒推的腿增速），补成过渡年，最多到同业最远共识年；**MUST NOT** 借同业公司级增速套本票（腿占比不同即过度转移）。借用层进底牌，表1 **MUST** 单列借用层贡献（锚点含 / 不含借用层两值），Assumptions 写借自谁、哪条腿、哪几年、升级门槛（本票自身出现该年 ≥2 家共识 → 换回自身共识、删借用）。逐年增速不同的过渡 `multi_stage_pe` 与 `check_transition_years` 借用口径 **[待建]**；建成前借用层只以候选带行预览，不进底牌。
