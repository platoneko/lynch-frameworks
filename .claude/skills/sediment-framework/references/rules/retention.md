### 经营价值与超额现金（2026-10-13 定；**MUST** 在留存去向审计与定锚之前跑完，结论进 Assumptions）

**一句话**：每股价值 = [经营价值 + 超额现金 × λ] ÷ 股本；经营价值 = 稳态经营利润 × \((1-g/RONIC)/(r-g)\)。形态仍是留存形态 Gordon（Koller 等《Valuation》价值驱动公式），换的是三个输入的口径，公式外加超额现金一项；全部取**稳态之后**的量，稳态之前只能走显式过渡（两段式 / 回升段 / 项目窗口 / \(V_{opt}\)）。依据：Koller 价值驱动公式与终值 RONIC 收敛惯例；Damodaran 非现金 ROE 与现金单列；Faulkender & Wang (2006)、Pinkowitz, Stulz & Williamson (2006) 现金边际价值实证。银行（A2c-2 PB-ROE）、寿险腿（内含价值尺）、被动 ETF 通道、EV/EBIT 年金腿、资产 PB 尺不适用本节。

**术语替换（2026-10-13 起）**：本文件其余各处 Gordon 留存项、域判定、选分支、红利票截顶、两段式段一派息、`check_branch` 中的 \(ROE\)（\(ROE_x\) / \(ROE_M\) / \(ROE_{28}\) 等）一律读作 **RONIC**（下文 ②）；「视同派出」一律读作「**多留部分**」（下文 ④）。存量框架迁移前照旧运行，迁移按「框架纠正」逐票做。

**① 拆分（客观，只用资产负债表）**
- **扩展口径净现金** = 现金及等价物 + 交易性金融资产 / 短期理财 − 有息负债 − 租赁负债 − 拆入资金、回购借款等类债项（永续债 / 优先股按「杠杆门 · 归类」）
- **类债项（2026-10-15 补）**：已宣派 / 已除息未付股息。新建框架另扣为锁产能收取、可退还的客户预付款；随交付消化的预收款是经营负债，不扣（Koller 口径）
- **经营所需现金锚**（2026-10-15 改）= min(完整周期或最近 5–10 年内「扩展口径净现金 ÷ 收入」的最低值, 2 个月收入 ÷ 年收入) × 最近财年收入，下限 0；历史各年按当年收入同法缩放。理由：锚要随规模变；一直堆现金的公司历史最低比率本身很高，用 2 个月收入封顶
- **增长期资金缺口**（2026-10-15 补）：分子年的利润要靠估值日到分子年初（RONIC 分母时点）之间的扩产 / 并购；这段投入超出同期经营现金流的部分由现有现金出，是经营资本，不是超额现金——否则分子收它产出的利润、现金又按面值加一次，双计（用户 2026-10-15）。缺口 \(G\) = max(0, Σ窗口（资本开支 + 已宣布的现金并购 − 经营现金流）)，**只计产出落在分子年之内的那部分**（2026-10-15 用户同意）：窗口里建的、分子年之后才投产的产能不从主锚点扣——它的利润不在分子里，扣成本不给收益是单边罚；有名有数的进 \(V_{opt}\)（价值 − 未投资本，三档概率），回报 < r 的按具名项目规则扣 未投 × (1 − ROIC/r)；拆不开时按公司披露的投产时间表分摊（多年规划按规划期线性摊）；无表按该类产能的常规建设期推投产年（写明所取建设期），**MUST NOT** 无表即全计——那正是本条要纠的单边罚。估值基准日之后已付的股息不加回：价格已除息，钱已到股东手里。有缺口时窗口可分配利润记 0（经营现金流已含窗口利润，不双计）；分红、回购不进（钱到了股东手里）；钱可互换，募资的名义用途不单独构成缺口。取数序：卖方现金流预测（≥ 1 家明示资本开支与经营现金流）→ 公司资本开支指引 / 在建工程剩余预算对共识利润 + 折旧（经营现金流 ÷ 净利取最近 3 年实测）→ 都没有：募资写明的扩产金额按缺口，其余 0 并写明。\(G\) 从 \(C_{ex}\) 扣、加进经营股权（RONIC 分母），分子不再扣它的税后收益；扣后低于触发门槛 → 按触发条改回合并口径。没有单列超额现金的票，\(G\) 作类债项从股权价值里扣（按归母比例），**MUST NOT** 因「无现金行」而不扣
- **超额现金** \(C_{ex}\) = 最新扩展口径净现金 − 经营所需现金锚 − 增长期资金缺口；**历史各年** \(C_{ex}(t)=\max(\text{当年扩展口径净现金}-\text{锚}(t),\ 0)\)——低于锚的净负债是正常经营杠杆，不算负现金
- **归母份额**（2026-10-15 补）：分子是归母利润，现金也只取归母那份——进估值、扣分子税后收益、扣 RONIC 分母（归母权益）的都是 \(C_{ex}\) × 归母比例；归母比例 = 有子公司级现金披露时按披露，否则 = 归母权益 ÷（归母权益 + 少数股东权益）。这是所有权，不是可信度，**MUST NOT** 放进 λ 或只作敏感性。触发门槛（≥ 归母权益 15%）用归母份额判
- **经营资本** = 归母权益 + 少数股东权益 + 扩展口径净债务 + 经营所需现金锚（等价于 权益合计 − \(C_{ex}\)；扩展口径净债务已含现金，**MUST NOT** 再减 \(C_{ex}\)）
- **触发**：\(C_{ex}\) ≥ 归母权益 15% 才新加单列行；不足 → 利润、RONIC、历史反解**全部**用合并口径，**MUST NOT** 一半经营口径一半合并口径；Assumptions 一句写读数。**现框架已把净现金按面值单列（腿利润不含利息、或已剔利息）→ 保留原结构**，门槛不拆既有结构；若分子仍含这笔现金的利息（双计），只把利息从分子与回报分母里剔掉，**MUST NOT** 借此重切现金行
- **兜底**：上市 < 5 年 / 业务模式变化 / 数据缺失 → 不拆分，写「周期不完整，现金未单列」

**② 经营口径（单列时三处 MUST 同时换，缺一即双计或双罚）**
1. **稳态经营利润** \(E_{op}\)：前瞻共识分子 = 分子年利润 − 当前 \(C_{ex}\) 的税后收益（收益率 = 最近财年（利息收入 + 理财 / 交易性金融资产持有收益）÷ 平均现金类资产；税率 = 实际所得税率），三档同减同一金额；**历史实测年作分子**（谷底档、自身利润高点坐标等）= 当年归母利润 − **当年自己的** \(C_{ex}(t)\) 税后收益，**MUST NOT** 减今天的
2. **RONIC（稳态新投资回报率；按档；2026-10-15 定）**——原则（用户 2026-10-03 / 10-15）：**卖方与公司公开数据是底牌最高优先级，取最远可见年；历史看不出东西，只在没有卖方共识时才看，且要看林奇分类，高速增长股更不能看历史；商品周期股用机构前瞻商品价（含悲观档），不用历史防峰值。**依据：Koller 终值 RONIC 常取预测期末年的回报。存量 96 只试算（2026-10-15）：历史中位数防峰值 / 增量回报证伪 / 兜底 r 在并购、新业务、扩张期、恢复期公司上一致伤数 20–60%，已撤
   - **取值 = 前瞻经营回报，按档**：该腿分子年（最远一个 ≥ 2 家卖方覆盖、带 L / M / H 的年份）的 L / M / H 经营利润 ÷ 该年初经营股权（归母权益 − \(C_{ex}\)，账面按现框架滚动法推）。即既有 \(E_{n+1}/B_n\) 口径，只多扣超额现金（分子扣其税后收益、分母扣其本身）。三档各取各的。上述前瞻值管**可见年**（分子年与已有过渡年）
   - **稳态回报三段（2026-10-15 定，用户）**：RONIC 只管新投资，现有生意的高回报已在分子里；新投资的超额回报会被竞争磨平（Koller 竞争优势期、Mauboussin 回报衰减），永续段不能沿用前瞻峰值（用户：「既能体现未来 5–10 年维持超高回报率，又能最终回落到正常值」）。按**日历年**走：可见年用前瞻值 → 高回报维持到 \(Y_1\)（RONIC = 前瞻值，增长 = \(g_2\)）→ \(Y_1\) 到 \(Y_2\) 线性回落 → \(Y_2\) 起稳态回报永续。\(Y_1/Y_2\) 是对护城河 / 瓶颈的判断，锚日历不锚卖方覆盖（卖方延伸到更远年时不用改）；用户判断优先，未讨论的票默认 \(Y_1\) = 可见年末。**回落年数 \(Y_2-Y_1\) 看进入门槛（用户 2026-10-16：门槛低的回落很快，如养猪、多晶硅）**：低门槛（扩产快、技术成熟、有钱即可进入）2 年 · 中门槛（客户认证 1–2 年、需工艺积累）4 年 · 高门槛（工艺 / 良率难、多年认证、专利或规模壁垒）6 年；判据看新产能建成周期、客户认证时长、历史上新进入者抢份额的速度、单位产能投资额，门槛档写进 Assumptions，挂轴的按轴上该环节的档；\(Y_2\) 不晚于所挂需求轴的 \(Y_2\)
     - **稳态回报（2026-10-19 改，用户）按序取，不取 max**：① **自身周期可用 → 取自身**：最近一轮完整「谷到谷」周期的经营回报均值（投入资本口径，见下「回报口径」）；生意结构明显变化的，取变化之后那一轮；同业与兜底只作对照，不进值。② 自身周期不可用（亏损期、亚规模、业务模式变化、不足一轮周期）→ 轴的稳态行 / 同一门生意成熟同业中位。③ 同业层也空 → 兜底（先看轴的「稳态兜底」，再看下表）。兜底**只是替补，不是下限**：自身周期低于兜底时照取自身。④ 同时满足「叙事换代」两条判据的走该条。结果仍 ≤ 该档前瞻值、≥ r（前瞻本就 < r 的按「持续失败」）。**用户裁定优先（2026-10-19）**：轴上用户暂定的稳态兜底是用户裁定，挂该环节的腿取它，优先于本条 ①–③。**结构变化的认定（2026-10-19）**：只有卖的东西或客户类型变了才算（如新业务 ≥ 收入三成、主要客户从消费者换成数据中心）；单纯规模变大不算。同业 **MUST** 同生意模式；**只剩一家、且不是同一门生意的同业剔除，落兜底**（2026-10-19）。**同业看竞争场**：回报由国内市场结构、政策、本地融资定的（工程机械、重卡与发动机、建材、银行保险、消费、公用事业），中国公司 **MUST** 优先国内同业，海外同业只作对照；全球同质竞争、客户与定价全球一致的（半导体、光通信、软件与平台）按全球同一门生意取
     - **生意模式兜底**（用户 2026-10-15 拍板；依据 Damodaran 2026-01 美股分行业资本回报 + 成熟同业前瞻读数）：商品化重资产（电池、面板等不挂商品价轴的）11% · 有壁垒的重资产（先进代工、自有晶圆厂的器件厂、设备）15% · 轻资产组装（光模块、电子代工）18% · 轻资产设计（芯片设计）22% · 边际成本近零（软件、平台、IP 授权）30%。**优先看轴（用户 2026-10-19）**：挂轴的腿取兜底时，先看轴上该环节的「稳态兜底」；轴上没有，才按资产形态查本表
     - **进轴（用户 2026-10-15：同一条轴上的票不能互相矛盾）**：同业尺轴（装 \(g_2\) 的轴）另装一行「稳态回报」= 该生意模式成熟同业的穿越周期经营回报中位，同业层为空才填生意模式兜底（按序取，不取 max；兜底不是下限），挂轴的腿**逐格引用**，eval 跨文件强制（同 \(g_2\) 挂轴）；需求情景轴另装一行「高回报期 \(Y_1/Y_2\)」= 用户对瓶颈持续期的判断，挂该轴的腿继承，票内另有用户裁定的从票；一条腿挂多条轴、高回报期不一致时，取讲本环节供需的那条（如光通信链按瓶颈阶段分环节，各环节的年份写在需求轴的环节表；衬底短缺止点不是下游芯片高回报的止点）；\(V_{opt}\) 的成功世界同样继承。**高回报期 MUST 对上该腿自己的产品阶段（用户 2026-10-19）**：挂轴继承的 \(Y_1/Y_2\) 是轴上那个环节的瓶颈判断；腿 / 期权的产品在该环节 \(Y_1\) 时尚未规模出货的，不属于该环节的瓶颈阶段，**MUST** 按产品自己所在的环节取（如光通信链的近封装 / CPO 归封装或引擎环节），找不到对应环节回对话，**MUST NOT** 默认继承母腿。**同一公司内部 MUST 一致**：各腿与期权回落到的常态利润率、稳态回报口径相同；期权已按短缺期利润率回落到常态的，主业分子若同样取自该短缺期，主业利润率也走同一条回落路径（用户 2026-10-19），或写明不同的具名理由。票内只留两样：自身周期（可用时优先，见「稳态回报」按序取）与 ≤ 前瞻的封顶——即本票中档按序值 = min(前瞻, 自身周期可用 ? 自身周期 : 轴稳态)，三档怎么分见「三档各取各的稳态」。不挂同业尺轴的腿照上文三层取
     - **成熟同业的判据**：看生命周期，不看当下周期位置——近 5 个完整财年收入年复合增速 ≤ 10%（5 个年度区间，如 FY2020→FY2025；**MUST NOT** 只取 4 个区间——起点落在 2021 景气峰值会把成熟同业误判为衰退），或林奇分类为 `stalwart` / `slow_grower`；**MUST NOT** 用未来共识增速判（上行期会把同业层清空）。同业剔除本票自身；**MUST** 同一门生意（如激光芯片同业不收工业光纤激光器、综合光电厂）；近 5 年收入负增长的是衰退期、不是成熟期，剔除。读数取**穿越周期**：该同业近 5–10 个完整财年经营回报（同本票公式）的均值，**MUST NOT** 用当期前瞻快照——谷底读低（功率半导体 2026）、高峰读高（AI 设备 2026）都是快照偏差（用户 2026-10-16 同意）；读数不足 5 个完整财年的样本不认。自身周期层同样：数据在公司年报 / 财报里取得到的 **MUST** 补齐 5–10 年再判，不得以「数据源只有 3 年」「历史只有 GAAP」弃用。同生意无成熟样本时，同业层为空，落兜底。**回报口径（用户 2026-10-19）**：自身周期与同业读数 **MUST** 用投入资本口径——分子 = 税后经营利润（不扣利息），分母 = 权益 + 有息负债 + 租赁 + 养老金缺口（税后）− 超额现金（留出经营所需现金）；净现金公司与现行「权益 − 超额现金」等价。账面权益被借债回购、养老金缺口或累计亏损压薄时，账面 ROE 读数不认（例：借债回购的同业账面 148% → 投入资本 37.6%）；同业的金融子公司剔出（如工程机械厂的设备融资子公司）。**与本票前瞻同口径（用户 2026-10-19）**：杠杆、商誉、收购摊销三样，自身周期与同业读数 **MUST** 按本票前瞻回报的处理方式取——前瞻按权益口径（含杠杆）的，投入资本读数按本票当前杠杆折回权益口径；前瞻加回收购摊销的，读数同样加回；前瞻分母含商誉的，读数也含
     - **叙事换代的腿（用户 2026-10-16：「只要回报不要用太离谱的峰值就行了…如果真的未来世界没有这么乐观，卖方应该会下调回报率」）**：同时满足两条——① 自身周期因业务模式变化不可用（如亚规模转型前的历史、新产品线无独立历史）；② 新生意没有 ≥ 5 年读数的同一门生意成熟同业——稳态回报 = min(该档前瞻值, 30%)，不回落、不落兜底。未来世界的回报算不出，跟卖方走，卖方下调时随框架更新修正；30% 是兜底表最高档，挡离谱峰值。两条判据 **MUST** 写进 Assumptions；挂同业尺轴的，轴的「稳态回报」行写本条而不写数。**MUST NOT** 扩到自身周期或成熟同业可用的腿（照走三段）

**③ 经营价值**

- **时点对齐（2026-10-15 改，取代原「分子年 ≥ 当前财年 + 2 才按 r 折回」）**：今天的经营价值 = \(V_{op}/(1+r)^{\tau}\) + 窗口可分配利润 \(/(1+r)^{\tau/2}\)。τ = 估值基准日（超额现金的资产负债表日）到 \(t_n\)（分子年初，不论 RONIC 分母取哪个时点）的年数，按实际月数；窗口可分配利润（2026-10-15 改，用户同意；原「窗口自由现金流」撤）= 窗口内尚未入账的共识利润（归母、与分子同口径，分子扣股权激励的同扣）×（1 − b），b 与 RONIC 分母滚动用的是同一个增长所需留存率（\(g/RONIC\)，g 取该段的 \(g_1\) 或 \(g_2\)）——即账面滚动视同派出的那部分。不用现金流预测：营运资金与季节性是时间差、不是价值，且卖方少有明示，换口径即摆动（存量试算 ±5–15%）；扩产大到经营现金流付不起的，由 ①「增长期资金缺口」用真实资本开支另扣。分红、回购是它的去向，不另加。依据：Gordon 给的是 \(t_n\) 时点的价值，窗口内的利润不在其中——只折不加低估、只加不折高估。边界：分子年已开始（τ < 0）取 τ = 0；分子是不随日历漂移的常态年、跨周期中枢或当期年化（周期股中枢、金铜两段式起点等）不适用；有篮子对（过渡篮 / 终值篮）时 τ 段用过渡篮 r；\(V_{opt}\)、期权腿等折到分子年的，同折 τ，已折到估值基准日的不再动

### 留存去向审计（2026-09-18 定；**MUST** 在选倍数形式前跑完，结论进 Assumptions）

**Step 2 · \(1/(r-g)\)、\(g>0\) 只在下列全部成立时允许**（否则 **MUST NOT**）：① NPPE 下降或持平 ≥ 3 年；② 留存去向 ∈ {A, B} 且金额对得上；③ \(b_{acct}\times ROE \gg\) 实测 NI 增速（留存没复利是观测事实）；④ **资本密度** NPPE / 权益 < 0.5——否则名义增长要按比例扩资本，「通胀增长免费」不成立；⑤ 写到期触发（如 capex 连续两年 > D&A 即回退）。单调区（ROE − r ≥ 3pp）公司满足①–③时 **MUST** 写明「边际 ROIC ≪ 账面」的原因，否则与高 ROE 打架。

**Step 3 · \(g=0\) + \(1/r\)**（2026-10-13 改）：以「经营价值与超额现金」⑤ 为准——经营口径派息率 ≥ 80%（窗口同该节留存三分；周期股取完整周期），或 D 桶且项目价值已单列，是**必要条件**；取 \(g=0\) 还须走 \(g_2\) 来源优先序的「自定」层并写明世界状态。A 桶（还债）期间按 A 桶规则，还清后按 ⑤ 重判。留存 > 20% 且去向是 C / E 却写 g = 0 → 等于假设留存按面值给了股东，**MUST NOT**。

**Step 4 · 隐含 r 对账 MUST 同形式**（研究对话里算，不落盘）：A/H 或本票 vs 篮子的隐含 r 差，两边 **MUST** 用同一个倍数形式算（完整式的 \(E/P\) 项乘了 \(1-g/ROE\)，同一 PE 差只翻译成一半 r 差）。用 \(1/(r-g)\) 读出的「残差 / 折价」先换成完整式重算，消失即为形式假象，**MUST NOT** 命名为「现金陷阱 / 港股附加」。两地残差同号且 > 2pp → 审归篮，不是 g。

**禁止形态**（任一命中 → 回对话）：(i) 留存 > 20%、NPPE 上升，却用 \(1/(r-g)\)、g > 0；(ii) 经营口径留存 > 20%、无命名窗口，却 g = 0 + \(1/r\)（2026-10-13 改为经营口径）；(iii) 对已花 capex 按 \((ROE/r-1)\) 罚；(iv) 分子含省息 + 现金按面值加回；(v) \(g_d \ne g\)；(vi) 未换同形式就把隐含 r 残差命名为折价；(vii) 窗口留存额 ≈ 政策留存额却声称「一次性」而无终点。

### 杠杆门（2026-09-21 定；与留存去向审计同时跑，结论进 Assumptions）

Gordon 用的 ROE 含财务杠杆：ROE = 资产回报 × 权益乘数。篮子 r 按生意性质归、不随单票杠杆动，故杠杆抬高的 ROE 会被当成生意回报进 \(b=g/ROE\)、抬高倍数。银行（PB-ROE，篮 5）与篮 1 / 篮 2 的留存驱动形状不适用本门。

**取数（Step 0 同源，最近财年；中报年化只作对照）**：净债务 = 有息负债 + 租赁负债 + **计入权益的类债工具**（永续债、不可转优先股等；哪些算债哪些算股见下段「归类」；会计口径的读数并列披露）− 现金及短期投资；EBIT = **报表营业利润**（中国准则含投资收益 / 公允价值变动 / 其他收益，与归母分子同口径；**MUST NOT** 用数据商剔除这些项后的「标准化营业利润」——两口径可落在阈值两侧，如 28% vs 62%），EBITDA = EBIT + 折旧摊销；**触发一律按公司合并口径**（分腿票见下段），① 的 ROIC 才逐腿；利息 = 财务费用中的利息支出（不净额化利息收入）**加上附属融资 / 租赁业务计入营业成本的利息**（如附属融资业务的融资利息：该业务的借款同样由合并主体举借，营业成本里的利息与财务费用里的利息对股东是同一种杠杆，2026-10-12 定）。**近门槛双口径（2026-10-12 定）**：任一比率落在阈值 ±20% 内（净债 / EBITDA 2.4–3.6、利息 / EBIT 26.7%–40%），或口径选择（利息范围、EBIT 年份、类债归类）能使触发结果翻转时，**MUST** 两口径都算、默认按触发口径构造，并把两口径读数列进落盘前摘要的边界判断清单；不按触发口径构造 **MUST** 写具名理由。**`cyclical` 两个比率同用中枢分子对应年份的 EBIT / EBITDA**（谷底年塌缩会误触发，如谷底年利息 / EBIT 250%），并列实测年读数。

**类债 / 类股工具的归类（判据：最终是否变成对公司的现金索偿）**：永续债 → 债（永不转股、票息固定、本金永久索偿）；**强制转股优先股 → 股**（到期必转、不还本金；转股前的优先股股息 **MUST** 并入「利息」算利息 / EBIT）；**可选转股的可转债** → 现价 ≥ 转股价 × 1.3（深度价内，持有人几乎必转）算股，否则算债（持有人可要现金）——两口径 **MUST** 并列披露，归类结果与触发价位（转股价 × 1.3 的具体数）写进 Assumptions 作触发器（股价回落到该价位以下 → 改算债、重跑本门）；价内程度（现价 ÷ 转股价）只在对话里读，不落盘（2026-09-27 定）。算股的工具 **MUST** 同时按稀释后股数算每股（与 if-converted 口径一致），**MUST NOT** 只在债这边算股、股数那边不稀释。**上述 1.3× 门槛只管本门触发与否；锚点的每股口径不二选一**：持有人择优，普通股取「扣本金 ÷ 现有股数」与「不扣本金 ÷ 稀释后股数」两者中**较低**的每股价值（价内 = 稀释口径、价外 = 债口径，二者在每股价值 = 转股价处相等；差额 ≈ 本金 × (每股价值 / 转股价 − 1) ÷ 股数）。

**分腿票的触发与动作**：触发按**公司口径**判（债是合并主体借的、利息由合并现金流偿付，某腿的 EBIT 不能单独负担利息——如公司 GAAP EBIT < 0 触发，被定价的那条腿单看只有 6%）。构造为 **unlevered 分子 + 净债（及类债工具）作闭合项**的票：杠杆不进腿的 ROE，① 的机制不存在、② 的去杠杆分子已内建——两条视同满足，Assumptions 一句写明；利率 +100bp 敏感行（按公司总债务）与 ③ 的 EV 口径交叉**仍 MUST 做**。

**权益法被投资方自带债务（2026-10-06 定）**
- **适用条件（全部满足）**：① 该腿是母公司按权益法核算的被投资方；② 被投资方的有息负债列在被投资方自己的报表上；③ 母公司年报附注未披露对该债务的担保
- **术语**：「净债」= 被投资方有息负债 + 租赁负债 − 现金及短期投资（100% 口径，取母公司年报权益法投资附注）。「维持性资本开支」= 母公司年报对该被投资方披露的维持性资本开支；未披露时 = 被投资方折旧摊销 − 收购形成的无形资产摊销，标「推算」；两者都不可得 → 本条输出「待补」，该腿不得落盘。「税率」= 母公司或被投资方披露的长期有效税率；都未披露时 = 被投资方注册地国家（联邦）法定税率 + 州（省）法定税率
- **触发判定**：用被投资方 100% 口径计算「净债 / 调整后 EBITDA」与「利息 / EBIT」，任一超过本节阈值（> 3 或 > 1/3）即触发。母公司合并口径的判定照旧单独做，两者互不替代
- **触发后的构造（MUST）**：
  1. 经济 EBIT = 调整后 EBITDA − 维持性资本开支
  2. 税后经营利润 = 经济 EBIT × (1 − 税率)
  3. 倍数 = Gordon 倍数，r = 该腿篮子 r；留存率与域判定用 ROIC = 税后经营利润 ÷ 经营投入资本，经营投入资本剔除收购商誉与收购形成的无形资产
  4. 收购摊销税盾现值 = 每年收购无形资产摊销 × 税率 × 年金系数（年数 = 剩余摊销年限，折现率 = 该腿篮子 r）。摊销额或剩余年限未披露时：每年摊销额按「维持性资本开支」条的推算口径取（被投资方折旧摊销 − 维持性资本开支），剩余年限 = 收购无形资产余额 ÷ 每年摊销额，均标「推算」。税盾 **MUST NOT** 进永续
  5. 该腿股权价值 = (税后经营利润 × 倍数 + 税盾现值 − 净债) × 持股比例
- **披露（MUST）**：Outputs 加一行对照值 =〔(调整后 EBITDA − 维持性资本开支 − 利息) × (1 − 税率) × 倍数 + 税盾现值〕× 持股比例；同行写差额 = (净债 − 利息 × (1 − 税率) × 倍数) × 持股比例。对照值不进锚点

**触发**（任一成立 → 下列三条 **MUST**）：

\[
\frac{\text{净债务}}{EBITDA} > 3\qquad\text{或}\qquad\frac{\text{利息支出}}{EBIT} > \tfrac{1}{3}
\]

1. **ROE 拆解 + 留存分支改用 ROIC**：Inputs / Outputs 并列 ROE、权益乘数、\(ROIC = EBIT\times(1-t)/(\text{归母权益}+\text{少数股东权益}+\text{净债务})\)（NOPAT 在少数股东之前，分母须同口径含 NCI；分腿票逐腿；分部净资产口径的腿用 分部税前利润 ÷ 分部资产 作粗读，标明口径）。**理由**：门触发 = 杠杆已用满，留存下来的每一元权益不能再按原比例配债，边际回报是不加杠杆的 ROIC，不是账面 ROE。故触发腿的留存分支 **MUST** 用 \(b=g/ROIC\)、域按 ROIC 对 r 判（ROIC < r − 3pp 即峰形区，倍数上限 \(1/r\)，**MUST NOT** 走单调区留存分支）；ROE 侧域判并列披露。**分工**：ROIC 只进 \(g>0\) 的留存项，**MUST NOT** 用它折存量利润的倍数——归母转化率 / 少数股东分走的部分归分子，两处各扣一次不重叠
2. **分子去杠杆**：留存去向审计 A 桶成立（还债路径可命名）→ 分子用还完债后的 EPS、省息不进 g（A 桶既有规则，此处强制）；A 桶不成立（杠杆是稳态）→ 分子不动；无论哪条触发，**MUST** 加一行「利率 +100bp 对分子 EPS 的影响」进敏感区（按公司总债务算；净债触发的票利率敏感度最大；进锚点的 r 不动，见「利率轴」）
3. **换尺判定**：触发且命中 `construction.md` §5b 决策树第 1 条（EBIT ≈ 可分配现金、卖方 / 同业惯用 EV/EBIT）→ 主尺 **MUST** 改 EV/EBIT，Gordon 降交叉；不命中 → Gordon 留主尺，但 §0 **MUST** 一句写明「杠杆门触发、主尺仍 Gordon 的原因」，且 EV 口径读数（EV/EBITDA 或 EV/EBIT 对同业簇）**MUST** 进交叉备注。**MUST NOT** 为规避杠杆门把净债的一部分「分摊」到不进公式的腿

未触发 → 不强制拆解，Assumptions 一句「杠杆门未触发：净债 / EBITDA x.x、利息 / EBIT y%」即可（数字可追溯）。
