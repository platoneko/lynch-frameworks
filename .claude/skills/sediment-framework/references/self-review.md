# 报数前自查（2026-10-19 定，用户）

> 何时读：任何锚点、敏感性、子代理结果拿给用户之前；落盘前。

规则套对、数字复现、跨轴一致只是机械层。用户追问才翻出的错（`300308.SZ` 近封装 2027 下半年才量产却从 2028 回落、期权常态利润率 12% 而主业短缺期利润率永续；`0981.HK` 先进制程早于台积电回落）都出在经济常识层。报数前 **MUST** 逐腿过下面四问；有问题先改，或先写出自己的结论，再交用户裁定。

## 四问

1. **时间线**：每条腿 / 期权的高回报期是否对得上这块业务自己所处的阶段（未量产 / 放量 / 成熟），而不只是它挂在哪条轴上（`rules/retention.md`「稳态回报三段」高回报期对产品阶段）
2. **同一公司内部一致**：各腿与期权的常态利润率、稳态回报、回落时点放在一起比。新产品比老产品更悲观、同一种短缺在一处回落另一处永续，**MUST** 先解释或改掉
3. **开关是否真起作用**：用户关心的参数几乎不动价格时，先找出价值实际落在哪个假设上（例：低 \(g_2\) 下 RONIC 回落几乎不动价格，价值在「分子年利润永续」），讲给用户，不只报「影响很小」
4. **结论靠什么撑**：单一同业 / 单一来源撑起「不回落」「高档 +25%」类结论，或悲观档变高、乐观档变低，先查清原因并写出自己的判断

## 交给用户的方式

- 子代理回报 **MUST** 由主会话按四问审过再转述，不把审查推给用户
- 问用户的每个选项 **MUST** 附自己的推荐与理由，不得只列选项
- **稳态回报与 \(g_2\) 的认可门**：相对已提交版本任一锚点变动 > 10% 的票，落盘前 **MUST** 把该票各档的稳态回报、高回报期 \(Y_1/Y_2\)、\(g_2\) 及来源列给用户认可（已在对话里认可过的注明日期，不重问）；变动 ≤ 10% 的不需逐票认可
- 不论变动大小，这些参数 **MUST** 写进 Outputs 隐含场景列（`construction.md`「7g-sc」）
