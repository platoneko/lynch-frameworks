# 档位构造（A2e）

由 `SKILL.md` 在对话第 6 块定锚、或框架纠正改尺时 **MUST** 加载。  
锚点**语义**真源：`valuation-rules.md`「锚点语义」。本节只规定**怎么造**。

目标：三档散布 **MUST** 可归因到基本面或林奇分类，**MUST NOT** 来自作者手法。  
当前算不出的量（概率、未建模期权）**MUST NOT** 进三档——走 §7 zone+V。

正例样板（现行文件）：`AVGO.US` 表1；`1810.HK` SOTP；`600036.SH` Gordon PB-ROE；`NOK.US` / `QCOM.US` EV/EBIT 腿；`SOFI.US` 候选带；`INTC.US` / `GOOG.US` zone+V。

## 1) L 按 `lynch_primary` 分档

| lynch_primary | L 的分子 | L 的倍数 | MUST 给的实证坐标（≥1） |
|---------------|----------|----------|--------------------------|
| `cyclical` / `turnaround` / `fast_grower` | **退到实测过的坏**：上一轮谷底盈利、消化年、共识下沿。`cyclical`（商品价型）的 M 分子 **MUST** 是中枢盈利；需求周期型制造的 M 用共识——细则与判据见 `valuation-rules.md`「周期票的中枢分子」 | 按 §5 倍数政策（本表不管倍数） | 自身印过的价及日期（**MUST** 带日期、不得是 as-of 当日价；2026-09-27 定）/ 谷底实际 EPS 与当时倍数 / 街上最低 TP |
| `stalwart` / `slow_grower` | 共识下沿（分子稳，主风险 de-rate） | 同上（可退自身历史 p10） | 该分位历史日期与当时价 |
| `asset_play` | — | — | L = 资产地板；盈利尺仍须报出作参照 |

本表只管分子。`cyclical` 分子已退谷底时再压倍数 = 周期算两遍 → 默认 flat 或反向。  
**MUST NOT** 对 `cyclical` / `turnaround` / `fast_grower` 只压倍数不动分子。次类显著改变下行时按更苛刻类构造并在 §1 说明。

**谷底 × Gordon**：见 `valuation-rules.md`「周期票 regime / point 双口径」——point 档走 `recovery_two_stage_pe` / `decay_two_stage_pe`，regime 档配稳态 PE；两口径都算，主价带取轴声明语义；谷底 × \(1/r\) 只作 `deep_discount` 压力坐标。

**地板兜底** \(L=\max(scenario\_L,\ floor)\) 时：

- §3 **MUST** 同时报 `scenario_L` 与 `floor`，标明胜出者
- zone 表 `conservative` 行 **MUST** 写明读的是**资产口径**
- 地板胜出且 \(scenario\_L/M < 0.3\) → **MUST** 回对话：情景过极端，还是不该用盈利尺当主尺

## 2) H = 同年成功上沿，且能独立命名

**自检**：*不提 M，能把这一档说清楚吗？* 「M 再给高一点倍数」≠ 一档。

- 分子取共识/指引上沿（来源与家数）
- 倍数按 §5（`cyclical` 默认 flat/反向）；**MUST NOT** 因是 H 就默认抬倍数
- **MUST NOT** 把多一年复利或未建模第二段塞进 H
- **结局二元、当前无分子的业务 MUST NOT 进 H** → \(V_{opt}\)（§7）；判据是分子存不存在
- H 分子年份晚于 L/M → 走 §3

### 2a) 三档分子 MUST 同源同口径

L 与 H **MUST** 取自**同一分布两端**（同一分析师区间 / 同一情景轴 / 同一组卖方模型）。  
**供给约束数字 MUST NOT 作 H 分子**（产能上限 ≠ 需求上限）；可作档内坐标。

### 2b) 三档倍数 MUST 同源同分位

来自同一分布三个分位（自身历史或同业簇）。  
**卖方 TP 隐含倍数 MUST NOT 作 `pe_h`**——只进 A2d 印证与 §3 交叉。

### 2c) flat-multiple 阶梯检验（MUST 进 eval）

三档倍数全置为 `pe_m`（EV/EBIT 腿用该腿 M 档 m）重算：

- 分子上 **MUST** 已成阶梯（\(eps_L < eps_M < eps_H\)），且 flat 下 \(L<M<H\)
- 某档 flat 塌进相邻或倒序 → **MUST** 回对话重设分子，**MUST NOT** 靠倍数撑开

公司不给指引时，分子零预测退路 **MUST** 先用尽：

1. 共识区间两端（有区间即 2a 同源两端）
2. 自身已实现历史极值（利润率 / 分部 margin 等实测谷底·高点）

### 2c-ex) `stalwart` / `slow_grower` 有条件豁免

de-rate 主导价带可接受，**三条全满足**否则回 2c：

1. 倍数仍同源同分位（2b 不豁免）
2. H 倍数 **MUST NOT** 越自身历史实测顶
3. 任何档倍数 **MUST NOT** 承载未建模业务故事 → 算得出进腿；有上限锚进 \(V_{opt}\)；否则 `待补` + stretched 解释

豁免生效时 §3 **MUST** 声明「de-rate 主导价带」并报 flat 宽度。  
豁免不对称：论证的是**下行**；推不出上行也可只靠倍数——H 门槛更严。

### 2d) 违反了要修，不是标注了就算

某档差距主要来自倍数而非分子 → **MUST** 按 2a/2b/2c 重设分子并走框架纠正；**MUST NOT** 只写警告保留原锚。

## 3) 分子年份与折现 MUST 显式

三档建议同一 `anchor_year`。漂移时：

- 题头 `主尺：` 与 §3 Inputs **MUST** 写明各档年份
- §3 **MUST** 另给「归一到同一年」对照带（按 `r_disc` 折回），跨票比 \(H/M\) 用这条
- **禁止**把换年藏进情景系数——中间量表点名

折现二选一：

- `anchor_year ≥ 当前财年 + 2` → 折现回今日，`r_disc` 与年数进 Inputs
- 不折现 → **MUST** 声明理由 + 折现后对照带（样板：`BE.US`）

**估值时点**：今日 \(t=0\)，分子年 \(t=1\)。`perpetual_pe` / `two_stage_pe` / `recovery_two_stage_pe` 同口径；`two_stage_pe(n=0) ≡ perpetual_pe`。FY+1 不折、FY+2 折一年。详见 `valuation-rules.md`「两段式过渡」。

**表1 报倍数 MUST 用过渡后年份分子**（过渡增长进分子不进倍数）。不背过渡的档：过渡后分子 = 过渡前分子。样板：`AVGO.US` 表1。

## 5) 倍数政策 MUST 显式，且与分子分解开

\[
\frac{L}{M}=\underbrace{\frac{eps_L}{eps_M}}_{\text{分子比}}\times\underbrace{\frac{pe_L}{pe_M}}_{\text{倍数比}}
\]

**跨票比较 MUST 用分子比**；未分解的 \(L/M\) 比的是作者倍数习惯。

| lynch_primary | 默认倍数政策 |
|---------------|--------------|
| `cyclical` | **反向或 flat**（\(pe_L \ge pe_M \ge pe_H\) 或三档同） |
| `fast_grower` / `stalwart` / `turnaround` | 同向可接受；仍 **MUST** 分解报出 |

偏离默认 **MUST** 写理由。样板反向：`603993.SH`。

永续 \(g\)、裁决顺序、中枢分子：**只读** `valuation-rules.md`（「永续增长口径」「构造规则冲突的裁决顺序」「周期票的中枢分子」）。第 6 块 **MUST** 为每腿声明 \(g_2\) 来源层级与是否触顶。

**红线**：

- 分子比 = 1.00 对 `cyclical` / `turnaround` / `fast_grower` = §1 违反
- 两端不同质（L 靠分子、H 靠倍数或反之）→ §3 **MUST** 点明
- 地板胜出档分子比标 `n/a`

### 5b) 倍数生成机制：Gordon vs EV/EBIT

语义：`valuation-rules.md`「永续增长口径」准年金例外。分腿票定锚前 **MUST** 先过本条。

**决策树**：

1. EBIT≈可分配现金，且卖方/同业用 EV/EBIT → 偏 **EV/EBIT**
2. 否则能命名可证伪 \(g\) 与**篮子** → **Gordon**
3. 两者都能 → 主尺取更贴卖方的；另一把**只**进交叉
4. 都不能 → `待补` 或 \(V_{opt}\)，**MUST NOT** 硬编

**经济折旧 Gordon（2026-10-05 定，样本 `000725.SZ`）**：重资产、会计折旧年限远短于资产经济寿命、且资本开支 ÷ 折旧连续 ≥2 年 < 0.6 并有公司指引支撑时，主尺 MAY 改为两段相加，账面 Gordon 降为交叉：
- **永续段**：分子 = 账面利润 + (会计折旧 − 经济折旧) × (1 − t) × 归母份额；经济折旧 = 各类资产原值 ÷ 经济寿命（寿命有具名依据，如同类产线实际运行年数）；照常走 Gordon 与篮子 r
- **尾巴年金**：(经济折旧 − 维护性资本开支) × (1 − t) × 归母份额，按 `annuity_factor`，n = 到老线重置的年数（有具名产线年龄支撑），不得永续化
- 进入条件的资本开支 MAY 剔除有具名完工日期的新建产线（判断的是老线要不要重置），剔除的产线尚未投入的资本 **MUST** 按归母份额从价值中扣除（样本 `000725.SZ` B16 / B20）
- 触发器：资本开支 ÷ 折旧回到 ≥ 0.8，或公司公告新产线 → 回对话复核
- 账面利润里的折旧回落（卖方远年共识的主要增量）**MUST NOT** 同时进永续段分子，否则尾巴算两遍

**短缺租金有期限（2026-10-05 定，样本 `LITE.US`）**：分子年的利润率含具名瓶颈带来的短缺租金、且有具名证据表明瓶颈会在可见年份内转移（产业链时间线、替代路线、同业扩产）时，永续段分子 **MUST** 按常态利润率（本票或同业的非短缺年份实测）重算；超出常态的那部分利润按 `annuity_factor` 算到瓶颈结束年，不得永续化。证伪 / 触发器写具名转段信号。

| 腿质地 | 默认主尺 | 篮子（`valuation-rules.md`「§r 篮子」） |
|--------|----------|------|
| 经营腿 | Gordon | 篮 4 常规经营 10% 默认；商品价函数 → 篮 6；单押 / 条件性 → 篮 7 |
| 银行（命中 A2c-2） | Gordon PB-ROE | 篮 5 |
| 管制公用事业 | Gordon（留存驱动） | 篮 2 |
| 准年金（按量专利 / 特许权） | EV/EBIT 带 | 篮 3（Gordon 有限期只作交叉） |
| 固定合约（量价锁定、IG 对手方）无 m× 锚 | Gordon 有限期年金 | 篮 1 |
| ETF / 多腿 | 逐腿相加；ETF 按指数权重 P 加权 r | 各腿各归 |

**禁双计**：同一腿 **MUST NOT** 既归低 r 篮子抬 PE、又用年金溢价抬 EV/EBIT。  
EV/EBIT 三档 m **MUST** 同源锚梯；「同分位」= 同一锚梯三档。  
每腿 §3 **MUST** 声明 `Gordon` 或 `EV/EBIT` **与篮子名**。样板：`NOK.US`；`QCOM.US` QTL。

交叉量级（不定锚）：篮 1 \(r=6.5\%,g=0\) Gordon PE ≈ 15.4× ↔ 税 13% 时 EV/EBIT ≈ 13×。负 \(g\) Gordon 系统性低于卖方时，优先改主尺为 EV/EBIT，勿换篮子。

## 7) 期权与 zone+V（\(V_{opt}\)）

语义：`valuation-rules.md`「未建模期权」。

### 7a) 双表

| 表 | 内容 | 用途 |
|---|---|---|
| 底牌 | \(L/M/H\)，零概率，期权计 0 | zone 与四个跨票读数 |
| zone+V | \(\text{底牌}_k + p_k\cdot V_{opt}\) | **自有一条 `+V` zone**：卡片「+V」行与日报第三行展示，跨档单独告警（行契约见 `contracts.md`「未建模期权」）；只是不改底牌那一行的切点 |

**向用户描述期权 / 候选带在卡片、日报上怎么显示、告不告警之前 MUST 先读 `contracts.md` 对应行契约**，不得凭本表推断展示行为（2026-10-08 定：曾把「不改底牌切点」误说成「期权不进五档」）。

概率 **MUST NOT** 出现在底牌 / 切点 / zone 边界 / 四比值计算路径；§3 Inputs **无** \(p\) 类字段。

### 7b) 什么落 \(V_{opt}\)

```
算得出分子 → 底牌；不确定性由 L↔H 距离承载
算不出、有已实测上限锚 → V_opt
连上限锚都没有 → 待补 + stretched 解释
```

判据是「当前能不能算出来」。`turnaround` 恢复盈利 **MUST** 进 H（转机前自身印过的盈利）。每票 §1 **MUST** 写明落 \(V_{opt}\) 的理由。

### 7c) 定锚纪律

1. 上限锚 **MUST** 由公开数据闭合（2026-10-03 定）：份数只来自本票具名的量（收入目标 − 共识已含、可换算的产能、合同；换算不成 → 1 份今日实测腿·下限），单位经济按「数据优先级与同业同尺」腿级行（见 `valuation-rules.md`「未建模期权」；样板 `GFS.US` A10 / `TSEM.US` A9）。**MUST NOT** TAM×份额×概率；**MUST NOT** 借同业倍数。份数可模糊、单位经济不可——无公司目标、份数未签时默认 **k=1**，模糊落 \(p_k\)；有公司具名目标时 \(k\) = (目标 − 共识已含规模) ÷ 单位，**MUST** 写明扣除的共识口径。**MUST NOT** 因「无卖方台数」把 \(V_{opt}\) 置 0。
   - **时点**：兑现年 = 公司具名目标年 / 投产日；无具名年份取对齐年份 + 2，标「无时点锚·拍值」。\(V_{opt}=(\text{兑现后锚点}-H)\times(1+r)^{-(t_{兑现}-t_{分子})}\)，\(r\) = 底牌篮子 r；兑现后锚点按第 7 条，所在腿 \(g_2\) 取同业组内值
2. 每项 §1 具名 + 升级门槛 + 证伪触发器
3. 做成腿进底牌时 **MUST** 同时移出 \(V_{opt}\)
4. 已在腿内仅被折价的资产 **MUST NOT** 再进 \(V_{opt}\)
5. **MUST NOT** 与倍数溢价并存
6. 默认 0，但 §3 **MUST** 显式回答
7. **期权腿与档位构造同等披露参数（2026-09-19 定）**：\(V_{opt}\) 走同一把尺，表3 兑现档那格 **MUST** 像表1 单元格一样把链写全——上限锚的物理量 × 单位经济 → 增量利润（税率）→ 兑现后分子 → ROE（分母同底牌口径）→ 倍数（写明 \(r\)、\(g\)、payout；\(r\) 同底牌篮子 r，**MUST NOT** 另取）→ 每股 → \(V_{opt}\) = 兑现后锚点 − H。倍数因 ROE 抬升而重估时 **MUST** 写出「≠ 增量利润 × H 档倍数」的差额来源。只写结果数字（如「PE 12.81×」）不算披露。

### 7d) zone+V 表形态

列：`档 | 底牌 | p_k | p_k·V_opt | 修正后 | 期权隐含场景`。

- 三档 \(p_k\) **MUST** 全显式；\(p_H\) 默认 1.0（偏离须论证）
- 有锚 → §1 具名；无锚允许拍，标「无概率锚·拍值」+ 量级依据
- 场景列按**兑现比例**写可检验量级，**MUST NOT** 复述 L/M/H 场景或只写比例标签（见 7g-sc）
- 表3 讲每档计入多少期权；`+V` 带的五档价格区间与各区间定价了什么另成**表4**（7g）

### 7e) \(V_{opt}/M\) 是披露项

占比大 **MUST NOT** 报红。>100% 时 §0 标**期权主导型**并指向升级门槛。**MUST NOT** 因占比高把期权加权进 \(M\)。

### 7f) 拆概率混进锚点的旧票

机械拆：期权归零得底牌，原值入 \(V_{opt}\)，原 \(p_i\) 改由表二 \(p_k\) 表达。验收：表二三档逐档对上拆前 \(L/M/H\)。  
**拆完 MUST 重跑 2c**——期权移出后底牌可能暴露为纯倍数带；若暴露则按 §1 重设分子，**MUST NOT** 因拆表验收通过就放过。

### 7h) 共识升级候选带

语义：`valuation-rules.md`「共识升级候选带」。

```
算不出分子 → V_opt（7b）
算得出、源不足（单家/指引/待补） → 候选带
都不是 → stretched 解释，什么都不写
```

- 同 `formula_id`，只换「单家/待补」输入；无过渡档原样复制底牌
- Outputs **一行**：`- 候选带（标签）：L′ = **x** · M′ = **y** · H′ = **z** · 门槛 Axx`，另配**表5** 五档表（7g）
- 单家输入按底牌规则传到各档（例：更远年点估计换算成 \(g_1\)、三档共用）时，表5 场景列 **MUST** 写出各档因此隐含的分子，并标明哪些分子无任何来源给过（`AAOI.US` H′：FY27 上沿 × 同一 \(g_1\) → FY28 EPS 约 20，无卖方给过）
- eval 复算 ±0.05，且 \(L'<M'<H'\)
- 不进底牌 zone / 四比值 / `calibration.py`

### 7g-sc) 隐含场景列 = 世界状态

自检：抹掉 EPS / 倍数 / L·M·H / 切点数字后，是否仍是可证伪基本面世界？「下沿世界 / 上沿兑现 / 倍数不抬 / 坐标在 M」→ 不合格。

|------|-----------|
| `deep_discount` | 比 L 还差什么；压力坐标；先查哪几条假设 |

| `neutral` | M 长期化什么；通常打什么折扣/credit |
| `optimistic` | H 成功世界哪件事必须发生；flat 倍数写生意侧上沿 |

| 表5 各区间 | 单家输入兑现到哪一步、各档隐含的分子（无来源者标明）+ 底牌世界（指回表2） |
